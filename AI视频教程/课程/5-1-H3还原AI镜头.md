# 5-1 按拆解方案，用 H3 还原 AI 镜头

## 快速实操：照着提示词做一遍

按 3-1 的逐镜拆解和复刻方案，把短剧样片的 AI 镜头换成阿夏自己的故事，用 AutoDL 上的开源 MiniMax H3 生成出来，拼成一条初版成片。

课前文件：[复刻改编设定.md](../资料/复刻改编设定.md) · [镜头造梦师-外卖员穿越唐朝.mp4](../资料/爆款样片/镜头造梦师-外卖员穿越唐朝.mp4) · 3-1 产物 `成果/3-1/`（拆解报告和复刻方案）

开始前确认：已有 AutoDL 账号、已创建 MINIMAX-H3 应用实例、已把开发者 Token 存到本机私有配置（见下文第 1 步）。没有 GPU 预算的学员，直接看“没有 GPU 预算怎么学”。

### 实操 1

```text
当前工作空间：阿夏的AI片场。
请读 成果/3-1/ 里的拆解报告和复刻方案，以及 资料/复刻改编设定.md，为阿夏做一条 30 秒竖屏短剧的分镜。
要求：
1. 沿用样片的 8 镜结构和每镜时长、景别、运镜，但人物和故事全部换成改编设定里的阿夏；不得出现“外卖员”“公主”“奶茶”。
2. 第 3 镜标题卡写“大唐 · 开元十年”，第 6 镜相机屏幕显示电量耗尽、花字“电量 0%”在 16.4 秒出现——这两处是代码动效，下一课用 HyperFrames 做，这一课只在分镜里标注，不生成。
3. 用 capsule-cinema 技能把分镜整理成可审分镜，先不要生成任何图片或视频。
4. 用 character-three-view 技能的要求写阿夏的角色设定（短发、灰色卫衣、背相机包，AI 原创形象，不像任何真人），生成一张角色参考图；如果当前环境不能生图，告诉我，不要跳过。
5. 用 h3-prompt-writing 技能，把第 1、2、4、5、6、7、8 镜各写成一条 H3 提示词，每条 5 到 6 秒（H3 单次最短 5 秒，成片里再裁短）。
交付到 成果/5-1/：分镜表.md、阿夏-角色参考.png、H3提示词/（每镜一个 txt）。先给我看分镜，等我确认再开机生成。
```

### 实操 2

```text
分镜确认。先只生成一个校准镜头：第 4 镜（唐朝西市全景，阿夏站在人群中）。这一镜人多、场景大，最容易出问题，先用它验证风格和角色。
请用 autodl-app-instance 技能开机，用 minimax-h3 技能生成这一镜，下载后用 ffprobe 核对时长和分辨率，然后立刻关机。AutoDL Token 从本机私有配置读取，不要在对话里显示。
把这次的开机时间、生成耗时、关机时间和估算费用写进 成果/5-1/生成记录.md，校准镜头存为 成果/5-1/镜头/S04-校准.mp4。告诉我实例现在的状态。
```

### 实操 3

```text
校准镜头风格可以：阿夏只出现一个，灰色卫衣和相机包都在。按同样的风格生成剩下 6 个 AI 镜头（第 1、2、5、6、7、8 镜）。
要求：一次开机，把 6 条任务全部提交进队列再等结果，不要生成一条等一条；全部下载并核对时长后立刻关机。旁白用 qwen3-tts 在同一次开机里生成；当前实例不支持就跳过旁白，用 H3 自带的声音，并告诉我。
关机后在本地完成：把每镜裁到分镜规定的时长、统一成 1080×1920 30fps；第 3 镜先放 1.5 秒黑场占位；按分镜拼成 成果/5-1/成片-初版.mp4，加上字幕和第 6 镜以外的花字（第 6 镜花字下一课做），右下角加 @阿夏的AI片场 水印。
用 capsule-cinema 的质量检查跑一遍，结果写进 成果/5-1/QA记录.md。生成记录.md 里补上这次的开关机时间和费用。
```

### 实操 4

```text
我在 AutoDL 控制台核对了实例状态。请再做两件事：
1. 逐镜对照原片和成片，填一张对比表到 QA记录.md：每镜的景别、运镜、时长是否还原；阿夏的发型、卫衣颜色、相机包在每一镜是否一致；有没有出现两个阿夏或多余的人物变形。
2. 把不合格的镜头列成“待返工清单”，写清哪一镜、哪里不对、建议怎么改提示词。这一课不重新生成，下一课只返工清单里最严重的一镜。
```

## 完整方法：理解每一步，迁移到自己的账号

视频复刻学的是“做法”：别人这条短剧是几个镜头、什么景别、怎么运镜、节奏多快。3-1 已经把这些拆成了表格和复刻方案。这一课照着方案，换成阿夏自己的人物和故事，把 AI 镜头真正生成出来。

生成用的是开源模型 MiniMax H3，跑在 AutoDL 租的 GPU 上。它不按条收费，只收 GPU 租金。所以这一课最重要的习惯是：**先出一个镜头验证，确认了再批量；生成完立刻关机。**

| 项目 | 内容 |
| --- | --- |
| 难度 | 3 |
| 时长 | 60 分钟（其中等待生成约 20 分钟） |
| 前置 | 3-1（逐镜拆解与复刻方案） |
| 产出 | 8 镜分镜 + 角色参考图 + 7 条 H3 镜头 + 初版成片 + 生成记录与 QA 记录 |
| 用到的工具 | rea-video 复刻方案（3-1 产物）；capsule-cinema（分镜与质量检查）；open-source-video-gen-skill 的 h3-prompt-writing、minimax-h3、autodl-app-instance、qwen3-tts、character-three-view |

## 1. 这一课的分工

| 谁 | 做什么 |
| --- | --- |
| rea-video（3-1 已完成） | 告诉你原片每镜怎么做的、哪些是 AI、哪些是代码动效 |
| capsule-cinema | 把分镜整理成可审的样子；成片后做质量检查 |
| h3-prompt-writing | 把每镜写成 H3 能听懂的提示词 |
| autodl-app-instance | 开机、等就绪、关机 |
| minimax-h3 | 上传、提交、等待、下载 |
| 你 | 审分镜、看校准镜头、到控制台确认关机 |

Capsule Cinema 自带的 H3 渠道走的是付费接口，这一课不用它生成。它只负责分镜和质检；生成交给 minimax-h3 技能，走 AutoDL。

## 2. 操作步骤

### 第 1 步：准备 AutoDL（只需一次）

1. 注册 [AutoDL](https://www.autodl.com) 并充值少量金额（按秒计费）。
2. 控制台 → 应用实例 → 应用市场选 **MINIMAX-H3**，创建一台实例。实例 ID 不用记，技能会自己找。
3. 账号 → 设置 → **开发者 Token**，创建并复制。
4. 把 Token 存到本机私有文件（在终端运行，`你的Token` 换成实际值）：

```text
mkdir -p ~/.config
echo 'export AUTODL_TOKEN=你的Token' > ~/.config/autodl.env
chmod 600 ~/.config/autodl.env
```

5. 安装 [open-source-video-gen-skill](https://github.com/mini-yifan/open-source-video-gen-skill)：克隆仓库，`pip3 install -r requirements.txt`，再把 `skills/` 下的技能导入 WorkBuddy 的技能页面。它的说明里写的是软链到 ZCode / Cursor 的技能目录，WorkBuddy 的导入方式以你的版本为准。

**为什么 Token 要存文件**：Token 能开关你的 GPU、产生费用。它不应该出现在对话、提示词、截图和仓库里。

**检查点**：对 WorkBuddy 说“检查一下 AutoDL 环境配置”，它运行仓库里的 `scripts/doctor.sh`，能列出你的实例。

### 第 2 步：先审分镜（实操 1）

这一步不开机、不花钱。拿到 `分镜表.md` 后检查：

- 8 镜的时长、景别、运镜和原片一一对应。
- 没有出现“外卖员”“公主”“奶茶”。
- 第 3 镜、第 6 镜花字标成了“代码动效，下一课做”。
- 阿夏的角色参考图是原创形象，不像任何明星或真人。

**为什么每镜写 5 到 6 秒**：H3 单次生成最短 5 秒。短镜头先生成 5 秒，拼接时再裁。

### 第 3 步：校准镜头（实操 2）

只生成第 4 镜。它人多、场景大，最容易出现角色变形、人物重复。这一镜过了，其他镜大概率也能过。

**检查点**：

- 打开 `S04-校准.mp4`：阿夏只有一个，卫衣和相机包都对。
- 打开 `生成记录.md`：有开机、生成、关机时间。
- **自己到 AutoDL 控制台看一眼，实例显示“已关机”。** 不要只听 Agent 说关了。

不满意就改提示词再试，不要直接批量。

### 第 4 步：批量生成并拼接（实操 3）

一次开机，把剩下 6 镜全部提交进队列。GPU 一直在干活，不空转。全部下载完立刻关机，裁剪、拼接、加字幕都是关机后在本机做。

**为什么要“一次开机”**：每次开机都有准备时间。一条一条开关机，准备时间也要付钱。

**检查点**：`成片-初版.mp4` 是 30 秒、1080×1920；第 3 镜是 1.5 秒黑场；右下角是 `@阿夏的AI片场`。

### 第 5 步：逐镜对照，列返工清单（实操 4）

把原片和成片左右并排，逐镜看。最常见的问题：

| 问题 | 例子 |
| --- | --- |
| 角色不一致 | 第 7 镜卫衣变成了黑色；发型变长 |
| 人物重复 | 西市人群里出现第二个“阿夏” |
| 节奏不对 | 某镜裁短后动作没做完就切走 |

这一课只列清单，不重做。下一课只返工最严重的一镜，练习“只改一镜，其他不动”。

## 4. 常见问题

**生成一镜要多久？** 5 秒镜头在服务端大约 2 分钟。6 镜排队并发，总等待十几分钟。等的时候可以先准备字幕。

**为什么生成出来是 5.17 秒、704 宽？** H3 的时长和尺寸按固定块取整。拼接前统一裁剪、缩放就行，技能会自动处理。

**同样的提示词再生成，结果一模一样？** 固定种子下会这样。想换结果，就改一点提示词或参考图。

**忘了关机怎么办？** 立刻到控制台手动关机。养成习惯：每次看完结果，先看控制台。

**能不能用明星的脸做角色？** 不能。6-2 课的限流案例就是这个原因。角色一律 AI 原创。

## 5. 没有 GPU 预算怎么学

跳过实操 2 和实操 3 的生成部分：

1. 照常做实操 1，得到分镜和提示词。
2. 把练习包 `参考结果/5-1/` 复制到 `成果/5-1/`，用作者生成的成片做实操 4 的逐镜对照。
3. 直接进入 5-2。5-2 的代码动效部分不需要 GPU。

## 6. 练习

用同样的 8 镜结构，给选题池③“赛博朋克城市系列第 4 集”写分镜和 H3 提示词，只出一个校准镜头。
