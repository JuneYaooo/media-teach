# 5-1 按拆解方案，用 H3 还原 AI 镜头

## 快速实操：照着提示词做一遍

按 3-1 的逐镜拆解和复刻方案，把短剧样片的 AI 镜头换成阿夏自己的故事，用开源 MiniMax H3 生成出来，拼成一条初版成片。演示用的是“自己在 AutoDL 租 GPU”；不想管机器的，也可以直接调用 API（见第 1 步的“另一种接法”）。

课前文件：[复刻改编设定.md](../资料/复刻改编设定.md) · [镜头造梦师-外卖员穿越唐朝.mp4](../资料/爆款样片/镜头造梦师-外卖员穿越唐朝.mp4) · 3-1 的拆解报告和复刻方案

开始前确认：已有 AutoDL 账号、已创建 MINIMAX-H3 应用实例、已把开发者 Token 存到本机私有配置（见下文第 1 步）。走 API 的学员，确认 API Key 已存到本机私有配置。两样都没有的学员，直接看“没有 GPU 预算怎么学”。

### 实操 1

```text
请读 3-1 的拆解报告和复刻方案，再读阿夏的复刻改编设定，给阿夏做一条 30 秒竖屏短剧的分镜：沿用样片的 8 镜结构、时长、景别和运镜，人物和故事全换成阿夏的，不能出现“外卖员”“公主”“奶茶”。
第 3 镜标题卡“大唐 · 开元十年”和第 6 镜花字“电量 0%”是代码动效，下一课再做，这一课只标注。
用 capsule-cinema 整理成可审分镜；用 character-three-view 画一张阿夏的角色参考图（短发、灰色卫衣、背相机包，AI 原创，不像任何真人）；用 h3-prompt-writing 给其余 7 个 AI 镜头写提示词。
先不要生成视频，等我看完分镜再开机。放到 成果/5-1。
```

### 实操 2

```text
分镜可以。先只生成一个校准镜头：第 4 镜西市全景，人多、场景大，最容易出问题。
用 autodl-app-instance 和 minimax-h3 技能开机生成，下载后立刻关机，Token 不要在对话里显示。记下开关机时间和费用，告诉我实例现在的状态。
```

### 实操 3

```text
校准镜头可以：阿夏只出现一个，灰色卫衣和相机包都在。按同样的风格把剩下 6 个 AI 镜头一次生成完：一次开机，全部排进队列，下载完立刻关机。旁白用 qwen3-tts，也在这次开机里做。
关机后拼成 30 秒的初版成片：第 3 镜先放黑场占位，加上字幕和阿夏的水印，第 6 镜的花字下一课再做。最后用 capsule-cinema 做一遍质量检查，这次的开关机时间和费用也记上。
```

### 实操 4

```text
我去 AutoDL 控制台核对过实例状态了。再帮我逐镜对照原片和成片：景别、运镜、时长有没有还原；阿夏的发型、卫衣、相机包每一镜是否一致；有没有出现两个阿夏或人物变形。
不合格的镜头列成待返工清单，写清哪里不对、提示词怎么改。这一课先不重新生成。
```

## 完整方法：理解每一步，迁移到自己的账号

视频复刻学的是“做法”：别人这条短剧是几个镜头、什么景别、怎么运镜、节奏多快。3-1 已经把这些拆成了表格和复刻方案。这一课照着方案，换成阿夏自己的人物和故事，把 AI 镜头真正生成出来。

生成用的是开源模型 MiniMax H3。它有两种接法：

| 接法 | 怎么收费 | 好处 | 要注意 |
| --- | --- | --- | --- |
| 自己在 AutoDL 租 GPU（本课演示） | 只收 GPU 租金，按秒计费，10 秒 1080p 约 ¥0.3 | 量大时最便宜 | 要开关机；本地跑的是量化版 H3-Base，不含官方的 2K 重生成 |
| 直接调 API | 按次计费，历史参考价 5 秒 768p 约 ¥2.50，以平台当日价格为准 | 不用部署、不用关机；官方 API 带完整提示理解和 2K 输出 | 单条贵；Key 同样不能出现在对话和截图里 |

不管哪种接法，这一课最重要的习惯都是：**先出一个镜头验证，确认了再批量。** 自己租 GPU 的，还要记得生成完立刻关机。

| 项目 | 内容 |
| --- | --- |
| 难度 | 3 |
| 时长 | 60 分钟（其中等待生成约 20 分钟） |
| 前置 | 3-1（逐镜拆解与复刻方案） |
| 产出 | 8 镜分镜 + 角色参考图 + 7 条 H3 镜头 + 初版成片 + 生成记录与 QA 记录 |
| 用到的工具 | rea-video 复刻方案（3-1 产物）；capsule-cinema（分镜与质量检查）；open-source-video-gen-skill 的 h3-prompt-writing、minimax-h3、autodl-app-instance、qwen3-tts、character-three-view |

## 1. 这一课的分工

| 谁 | 做什么 |
| --- | --- |
| rea-video（3-1 已完成） | 告诉你原片每镜怎么做的、哪些是 AI、哪些是代码动效 |
| capsule-cinema | 把分镜整理成可审的样子；成片后做质量检查 |
| h3-prompt-writing | 把每镜写成 H3 能听懂的提示词 |
| autodl-app-instance | 开机、等就绪、关机 |
| minimax-h3 | 上传、提交、等待、下载 |
| 你 | 审分镜、看校准镜头、到控制台确认关机 |

Capsule Cinema 自带的 H3 渠道走的是按次计费的 API。演示里不用它生成，只用它做分镜和质检，生成交给 minimax-h3 技能，走 AutoDL。如果你选“直接调 API”，就反过来：生成也交给 Capsule Cinema，open-source-video-gen-skill 不用装。

阿夏版 8 镜（实操 1 的目标，供核对）：

| 镜 | 时间 | 原片 | 阿夏版 | 做法 |
| --- | --- | --- | --- | --- |
| 1 | 0–3 秒 | 外卖箱冒金光 | 深夜电脑屏幕发出强光，吞没画面 | H3 |
| 2 | 3–6.5 秒 | 雨夜摔倒 | 阿夏趴在剪辑台上睡着，屏幕白光扩散 | H3 |
| 3 | 6.5–8 秒 | 标题卡“大唐 · 贞观三年” | 标题卡“大唐 · 开元十年” | 代码动效（5-2） |

## 2. 操作步骤

### 第 1 步：准备 AutoDL（只需一次）

1. 注册 [AutoDL](https://www.autodl.com) 并充值少量金额（按秒计费）。
2. 控制台 → 应用实例 → 应用市场选 **MINIMAX-H3**，创建一台实例。实例 ID 不用记，技能会自己找。
3. 账号 → 设置 → **开发者 Token**，创建并复制。
4. 把 Token 存到本机私有文件（在终端运行，`你的Token` 换成实际值）：

```text
mkdir -p ~/.config
echo 'export AUTODL_TOKEN=你的Token' > ~/.config/autodl.env
chmod 600 ~/.config/autodl.env
```

5. 安装 [open-source-video-gen-skill](https://github.com/mini-yifan/open-source-video-gen-skill)：克隆仓库，`pip3 install -r requirements.txt`，再把 `skills/` 下的技能导入 WorkBuddy 的技能页面。它的说明里写的是软链到 ZCode / Cursor 的技能目录，WorkBuddy 的导入方式以你的版本为准。

**为什么 Token 要存文件**：Token 能开关你的 GPU、产生费用。它不应该出现在对话、提示词、截图和仓库里。

**检查点**：对 WorkBuddy 说“检查一下 AutoDL 环境配置”，它运行仓库里的 `scripts/doctor.sh`，能列出你的实例。

#### 另一种接法：不租 GPU，直接调用 API

不想注册 AutoDL、不想管开关机，可以让 Capsule Cinema 直接调 H3 的 API。两个渠道选一个：

| 渠道 | 去哪拿 Key | 本机配置里的变量名 | 说明 |
| --- | --- | --- | --- |
| MiniMax 官方 API | [MiniMax 开放平台](https://platform.minimaxi.com) | `MINIMAX_API_KEY` | 完整 H3 系统，输出 2K；Capsule Cinema 里指定 `video_engine=minimax-h3` |
| RunningHub | [RunningHub](https://www.runninghub.cn) | `RUNNINGHUB_API_KEY` | 跑的是开源 H3-Base 工作流，支持文生视频、首尾帧、多图参考 |

Key 的存放方式和上面的 AutoDL Token 一样：写进本机私有文件，不出现在对话里。具体文件位置按 Capsule Cinema 的 [安装说明](https://raw.githubusercontent.com/JuneYaooo/cheap-claude-video/main/docs/install.md)。

接下来的实操照常做，只要把提示词里“用 autodl-app-instance 和 minimax-h3 技能开机生成”换成“用 capsule-cinema 的 H3 渠道生成”，并删掉开关机相关的要求（“立刻关机”“一次开机”“开关机时间”）。按次计费，校准镜头这一步更不能省：一镜不过就批量，等于整批花钱返工。

### 第 2 步：先审分镜（实操 1）

这一步不开机、不花钱。拿到分镜后检查：

- 8 镜的时长、景别、运镜和原片一一对应。
- 没有出现“外卖员”“公主”“奶茶”。
- 第 3 镜、第 6 镜花字标成了“代码动效，下一课做”。
- 阿夏的角色参考图是原创形象，不像任何明星或真人。

**为什么提示词里每镜是 5 到 6 秒**：H3 单次生成最短 5 秒。h3-prompt-writing 会让短镜头先生成 5 秒，拼接时再裁。

### 第 3 步：校准镜头（实操 2）

只生成第 4 镜。它人多、场景大，最容易出现角色变形、人物重复。这一镜过了，其他镜大概率也能过。

**检查点**：

- 打开校准镜头：阿夏只有一个，卫衣和相机包都对。
- 打开生成记录：有开机、生成、关机时间和费用。
- **自己到 AutoDL 控制台看一眼，实例显示“已关机”。** 不要只听 Agent 说关了。

不满意就改提示词再试，不要直接批量。

### 第 4 步：批量生成并拼接（实操 3）

一次开机，把剩下 6 镜全部提交进队列。GPU 一直在干活，不空转。全部下载完立刻关机，裁剪、拼接、加字幕都是关机后在本机做。

**为什么要“一次开机”**：每次开机都有准备时间。一条一条开关机，准备时间也要付钱。

**检查点**：初版成片是 30 秒竖屏；第 3 镜是黑场占位；水印是 `@阿夏的AI片场`。

### 第 5 步：逐镜对照，列返工清单（实操 4）

把原片和成片左右并排，逐镜看。最常见的问题：

| 问题 | 例子 |
| --- | --- |
| 角色不一致 | 第 7 镜卫衣变成了黑色；发型变长 |
| 人物重复 | 西市人群里出现第二个“阿夏” |
| 节奏不对 | 某镜裁短后动作没做完就切走 |

这一课只列清单，不重做。下一课只返工最严重的一镜，练习“只改一镜，其他不动”。

## 3. 自查清单

- [ ] 分镜先审后生成
- [ ] 先出校准镜头，确认后才批量
- [ ] 每次生成结束都到 AutoDL 控制台确认已关机
- [ ] Token 没出现在对话、截图、仓库里
- [ ] 成片里没有原片的人物、台词和水印
- [ ] 生成记录里有每次的开关机时间和费用
- [ ] QA 记录里有逐镜对比和待返工清单

## 4. 常见问题

**生成一镜要多久？** 5 秒镜头在服务端大约 2 分钟。6 镜排队并发，总等待十几分钟。等的时候可以先准备字幕。

**为什么生成出来是 5.17 秒、704 宽？** H3 的时长和尺寸按固定块取整。拼接前统一裁剪、缩放就行，技能会自动处理。

**同样的提示词再生成，结果一模一样？** 固定种子下会这样。想换结果，就改一点提示词或参考图。

**忘了关机怎么办？** 立刻到控制台手动关机。养成习惯：每次看完结果，先看控制台。

**租 GPU 和调 API 怎么选？** 一个月只出几条，直接调 API 省事；每周都要批量出镜头，租 GPU 更便宜。算账时别只比单次价格：租 GPU 还有开机等待、空转、失败重跑的时间成本。

**能不能用明星的脸做角色？** 不能。6-2 课的限流案例就是这个原因。角色一律 AI 原创。

## 5. 没有 GPU 预算怎么学

既不租 GPU、也不调 API 时，跳过实操 2 和实操 3 的生成部分：

1. 照常做实操 1，得到分镜和提示词。
2. 把练习包 `参考结果/5-1/` 复制到 `成果/5-1/`，用作者生成的成片做实操 4 的逐镜对照。
3. 直接进入 5-2。5-2 的代码动效部分不需要 GPU。
