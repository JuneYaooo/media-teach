## 完整方法：理解每一步，迁移到自己的账号

4-1 只是一份脚本。这一课把它做成视频，而且做法是“克隆”：Hypit 先看懂对标视频里每个字幕、卡片、音效是跟着哪个词出现的，把这些关系写成一份可编辑的工作流。换台词时，画面跟着新台词自己重新排。工作流做好以后，换钩子、换配色只改一处，就能出一条新视频。

## 1. Hypit 是什么，为什么走代码视频路线

[Hypit](https://github.com/hypit-ai/hypit) 是一个开源的“视频克隆”工具，给 Agent 用。它的核心思路是：视频里的每个画面变化，都对齐到台词里的某个词，而不是对齐到某一秒。所以台词改了，画面会跟着走。

排行榜这类视频，画面本来就是卡片、文字和动效，不需要 AI 生成画面。走代码视频路线有三个好处：

- 不花视频生成的钱，本地就能渲染。
- 每次结果稳定，便于反复改。
- 没有 AI 人物，就没有肖像和“像不像别人”的风险。

需要花钱的只有配音（如果用付费语音服务）。

## 2. 操作步骤

### 第 1 步：安装 Hypit（只需一次）

Hypit 由两部分组成：技能（教 Agent 怎么做）和命令行工具（真正干活）。

1. 安装技能。在终端运行：

```text
npx skills add hypit-ai/hypit -g
```

   如果 WorkBuddy 没有自动识别到，就在 WorkBuddy 的“技能”页面里，把安装好的 `hypit` 技能文件夹手动导入。具体入口以你的 WorkBuddy 版本为准。

2. 命令行工具不用自己装。第一次使用时 Agent 会检查并帮你安装 `@hypit/hypit`。需要 Node.js 22 以上和 ffmpeg，01 入门课已经装好。

**检查点**：在 WorkBuddy 里问“hypit 版本是多少”，它能运行 `hypit version` 并回答。

### 第 2 步：克隆工作流，换成阿夏的脚本

发实操 1。Hypit 会先“看”参考视频：抽画面、读字幕、找出每个卡片和音效对应的词，然后搭工作流。

它可能会问你两件事：

- **用什么语音服务配音。** 告诉它你已经配置的服务。没有的话，先让它出无配音的字幕版，课后再补。
- **有没有费用。** Hypit 本身免费，不加水印；模型服务按各家价格收费。代码视频路线只有配音可能收费。

**为什么要它先写下“理解”**：克隆不是逐帧照抄。让它先说清“这条视频为什么抓人、哪个画面跟着哪个词”，你能提前发现它理解错的地方。

### 第 3 步：检查水印和字幕（实操 2）

打开 `阿夏版-排行榜.mp4`，重点看两处：

| 检查什么 | 怎么查 |
| --- | --- |
| 左上角水印 | 参考视频全程有 `@AI工具铺子` 水印。克隆时它容易被当作版式的一部分一起复刻下来。必须换成 `@阿夏的AI片场` |
| 字幕和配音 | 字幕逐字等于 4-1 脚本；每句字幕和声音同时出现 |

留着别人的水印发出去，等于在你的视频里给别人打广告，还可能被判搬运。

实操 2 是作者针对自己那次结果写的。你的结果如果已经换好水印，就只做字幕核对。

### 第 4 步：出变体（实操 3）

工作流做好以后，变体只改一个地方：

- **换钩子**：同一条内容，开头不同，测试哪个开头留人更好。
- **换配色和贴图**：形成阿夏自己的视觉风格。

**检查点**：三条视频除了改的那一处，其他完全一样。如果变体里别的地方也变了，让它说明原因。

### 第 5 步：在 Studio 里看时间线（可选）

Hypit 自带 Studio 预览，可以看到每个组件在时间线上的位置。对 Agent 说“打开 Studio 让我看时间线”即可。

## 3. 自查清单

- [ ] 没有调用视频或图片生成模型

## 4. 常见问题

**Hypit 说要 WhisperX，这是什么？** 一个把语音转成“每个词在第几秒”的工具。克隆时需要它把参考视频的画面和台词对上。可以本地装，也可以用托管服务，Agent 会说明两种方式的工作量，让你选。

**能不能直接克隆别人的整条视频发出去？** 不能。克隆的是做法（结构、节奏、版式），内容、素材、标识都要换成自己的。这一课用的样片是课程自制的；真实使用时，对别人的作品也只学结构。

**变体有什么用？** 同一条内容，换个开头发在不同时段或不同平台，看哪个数据好。下次就用赢的那个开头。

**WorkBuddy 里装不上 hypit 技能怎么办？** Hypit 官方支持 Claude Code、Codex 等编程 Agent。WorkBuddy 导入失败时，可以先在这些工具里跑这一课，产物放回 `成果/4-2/`，后面的课照常用。

## 5. 进阶：克隆带 AI 人物镜头的爆款（选学，录屏不演示）

排行榜不需要 AI 画面。如果你要克隆的是有 AI 人物出镜的视频，Hypit 需要一个视频生成服务。课程推荐的低成本方式是用 [comfyui-hypit-bridge](https://github.com/Ero-Cat/comfyui-hypit-bridge)，把 AutoDL 上部署的开源 MiniMax H3 接成 Hypit 的生成服务：

1. 在 AutoDL 上准备一台装好 MiniMax H3 的 ComfyUI 实例（显存 24GB 以上；创建方法见 5-1 课）。
2. 本机装好 Node.js 20+、Hypit 命令行工具和 ffmpeg。
3. 按 comfyui-hypit-bridge 的说明，克隆仓库并构建它的几个包，安装到你的视频项目里。
4. 复制 `hypit.runtime.example.json` 为 `hypit.runtime.json`，把里面的地址改成你的 ComfyUI 面板地址。这个文件只留在本地，不要上传。
5. 运行 `hypit doctor` 确认连上，再让 Agent 用 H3 生成需要的人物镜头。
6. 生成完立刻到 AutoDL 控制台关机。GPU 按秒计费，空转也收钱。

这条路线每家实例的配置不同，以你实际试跑为准。
