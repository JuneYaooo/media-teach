00 总纲：用 AI 跑通一个自媒体账号

做自媒体最费时间的那些活儿：翻同行主页找对标、盯数据猜哪条爆了、一帧帧看爆款怎么剪的、憋标题和开头、发之前担心违规，这门课教你交给 AI 去做，你来拿主意、做核对。

工具是 WorkBuddy（腾讯的桌面 AI 助手）加一组开源技能。你用中文说清要什么，找资料、算数、看视频、出文件交给它。不用会编程，也不用打开终端。

适合谁：已经在做或准备做抖音、小红书、视频号、快手、B 站的博主和运营。拍实拍、做口播、做图文、做 AI 短片都能用；只有模块⑤（用 AI 生成画面）是选学。

建议顺序：01 必须先学，第一个技能和看图 Key 都在这一课装好，其他技能学到那课再装。之后按模块顺序学最顺，前一课的结果就是后一课的输入。只想学某一课也行，把提示词里“上一课的结果”换成你手上已有的材料，比如没做 1-1，就直接告诉它你的 3 个对标账号。

拍实拍、做口播的：模块⑤可以跳过。4-1 写好标题、开头和脚本后，自己拍、用剪映等工具剪，再接 6-1 审核。3-1 照样有用，可以看清对标每一镜的景别、节奏和花字时机。

两个“复刻”有什么不同

  • 爆款复刻（④）：学套路。钩子、结构、节奏不变，换成你自己的选题。
  • 视频复刻（⑤）：学做法。按逐镜拆解的结果，把镜头、花字、剪辑还原出来，但故事和人物换成你自己的。

名词小抄

词 意思
技能（Skill） 一本写给 AI 的操作手册：某类活儿怎么干、结果长什么样、哪些事不能做。装上以后 WorkBuddy 就会按它做
Agent 能自己动手的 AI 助手，会打开网页、读文件、运行技能。这门课里就是 WorkBuddy
工作空间 你给 WorkBuddy 指定的那个文件夹。它只在里面读写，结果都存在这里
多模态模型 会看图、看视频的 AI 模型。看封面、拆视频、读后台截图都靠它
Key 调用某个模型或平台的“密码”，按用量扣你的钱。只填进本机文件，不发给任何人
Token 和 Key 类似，用来操作 AutoDL 这类平台的账户（比如开关 GPU），同样不能外泄
API 平台开放给程序调用的接口。“直接调 API”就是不自己部署，按次付钱用平台的模型
GPU 显卡。生成 AI 视频要用，没有可以按小时租（AutoDL），或者直接调 API
基线 一个账号平时的一般水平，用来判断某条作品是不是超常发挥
置信度 技能对自己结论有多大把握。低的要你回去看一眼再信
完整度 这次分析有没有缺步骤（比如没 Key 没看图）。标了“部分”的结论只能当参考

AI 视频生成的路线

这一节只和做 AI 画面、代码动画的号有关，拍实拍的可以跳过。需要“生成画面”的地方（4-2、5-1、5-2），有三种做法：

路线 怎么做 花多少钱 适合谁
H3 · 自己租 GPU 开源视频模型 MiniMax H3 部署在 AutoDL 上，Agent 自动开机、生成、下载、关机 只付 GPU 租金，10 秒 1080p 约 ¥0.3（以 AutoDL 实际计费为准） 量大、想压成本、愿意折腾部署
H3 · 直接调 API 不部署，用 MiniMax 官方 API 或 RunningHub 按次生成 按次计费，历史参考价 5 秒 768p 约 ¥2.50，以平台当日价格为准 只偶尔出几条、不想管机器
代码视频 用 HyperFrames / Hypit 写网页动画再渲染成视频：排行榜、花字、标题卡、字幕 不需要 GPU，几乎不花钱 没有生成预算；教程、榜单、知识类内容

贯穿全课的核对习惯

  • 数字要有出处：倍数、粉丝、时间点，都要能在报告、后台截图或原片里找到。技能算数，AI 只解读。
  • 看完整度：技能缺了某一层（没搜到、没 Key、没看图）必须标出来，标了“部分”的结论只能当参考。
  • 回原片看：拆解报告说第几秒出现什么，拖到那一秒看一眼。
  • 不照抄：复刻学的是结构和做法，不是别人的台词、角色和水印。
  • 不自动发布：课程只做到“可以发布的作品包”，发不发由你决定。
