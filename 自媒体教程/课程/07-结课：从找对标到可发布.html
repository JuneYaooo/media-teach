课前文件：对标快照-2026-11-07 · AI工具铺子-AI配音工具排行榜.srt · 本周说明.md

实操 1：雷达找本周爆款

当前工作空间：阿夏的AI片场。
新一周的对标数据到了。请使用 benchmark-outlier-radar 技能，用 资料/结课-新一周/对标快照-2026-11-07/ 里的 3 个文件生成雷达周报，基准日 2026-11-07。对照上周的周报 成果/1-2/（没有就用 参考结果/1-2/），说出本周新出现的异常爆款，选出 1 条最值得复刻的，并说明它和我们已经拆过的哪条爆款套路相同。互动率异常的条目先标“待核对”，不要选。
周报保存为 成果/07/01-雷达周报.md，选题结论保存为 成果/07/01-本周选题.md。

实操 2：确认套路

当前工作空间：阿夏的AI片场。
请使用 social-account-doctor 技能，拆 资料/结课-新一周/AI工具铺子-AI配音工具排行榜.srt：钩子在第几秒结束，分几段，每段多长，结尾怎么引导互动。和 成果/3-2/ 的爆款拆解卡（没有就用 参考结果/3-2/）逐段对比：结构相同的写“沿用”，不同的写清差别。
保存为 成果/07/02-套路对比.md。

实操 3：写阿夏的版本

当前工作空间：阿夏的AI片场。
请使用 social-account-doctor 技能，按 成果/07/02-套路对比.md 确认的结构，把 资料/账号档案.md 选题池里的“新手做 AI 视频的 3 个坑”写成约 20 秒的倒数榜单脚本：钩子 → 第 3、第 2 个坑快速过 → 转折 → 揭晓第 1 个坑 → 互动结尾。
要求：不照抄对标原句；标题不用“全网第一”“最强”这类说法，不承诺收益；结尾互动不留联系方式、不引导私信。给 3 个标题和 3 个封面大字。
脚本保存为 成果/07/03-脚本.md，标题封面保存为 成果/07/03-标题封面.md。

实操 4：复用工作流出片

当前工作空间：阿夏的AI片场。
请使用 Hypit 技能，打开 成果/4-2/ 里阿夏版本的排行榜工作流（没有就用 参考结果/4-2/），复制一份到 成果/07/04-工作流/，只把文案、字幕和榜单内容换成 成果/07/03-脚本.md，版式、配色和动效保持不变。榜单从 5 项改成 3 项，时长相应缩短。水印用 @阿夏的AI片场。在开头 0–3 秒画面上加“AI 生成”提示。
渲染成片保存为 成果/07/04-成片.mp4，并逐字核对字幕和配音是否一致，核对结果写进 成果/07/04-出片记录.md。

实操 5：审核并打包

当前工作空间：阿夏的AI片场。
请使用 self-media-compliance-review 技能，审核 成果/07/04-成片.mp4 和 成果/07/03-标题封面.md，目标平台抖音和小红书，报告保存为 成果/07/05-审核报告.md。
如果有 High 或 Blocker，先按建议修改再复审，不要打包。全部降到 Low 或 Pass 后，把成片、选定的标题和封面大字、发布文案（含“本片由 AI 生成”声明和内容标注选“含有AI生成内容”的提醒）、审核报告放进 成果/07/作品包/，再写一份 成果/07/作品包/README.md，逐个列出每个文件来自哪一步、由哪个文件生成。

完整方法：理解每一步，迁移到自己的账号

前面每一课都在练一个动作。真实运营时，这些动作是一条链：雷达告诉你学谁，拆解告诉你学什么，复刻把它变成你的作品，审核决定能不能发。这一课的重点不是某一步做得多好，而是每一步的产物能不能直接交给下一步。走顺一次，以后每周换数据、换选题就能重复。

步骤 对应课程 输入 产出

2. 操作步骤

第 1 步：雷达只给信号，选题要你判断

实操 1 的周报会标出几条倍数很高的作品。选之前先看两件事：

  • 互动率：倍数高但点赞、评论极少的，可能是投流或数据录错，标“待核对”，不选；
  • 和你有没有关系：选和阿夏表现最好的类型（教程、排行榜）一致的那条。

本周 AI工具铺子又出了一条排行榜爆款，套路和 3-2 拆过的那条一样。这就是复刻成本最低的选择。

第 2 步：套路一样，就不用从头拆

同一个账号的爆款常常是同一个套路换了内容。实操 2 只做对比：哪些段落一样（沿用），哪些不一样（调整）。这比从头拆一遍快得多。

第 3 步：写脚本时守住三条线

  • 学结构，不抄句子；
  • 标题不夸大、不承诺收益；
  • 结尾互动不留联系方式。

这三条在 4-1 和 6-1 都出现过。写的时候就守住，审核时就不用返工。

第 4 步：复用工作流，只换内容

4-2 已经做好了阿夏版本的排行榜工作流，这次只换文案和榜单。版式、配色、动效都不动，出片快，账号风格也统一。

想复刻短剧类的爆款（比如本周镜头造梦师的第二集），就走另一条路：用 5-2 保存的配方，换新的改编设定出片。

第 5 步：审核通过才打包

作品包是交给“发布的人”的，可能是你自己，也可能是团队里的运营。所以：

  • 有 High 或 Blocker 就不进包；
  • README 写清每个文件的来源，出了问题能顺着找回去；
  • 发布文案里提醒内容标注选“含有AI生成内容”。规则会变，以平台最新公告为准。

3. 自查清单

  • 选中的爆款不是互动率异常的那条
  • 套路对比写清了“沿用”和“调整”
  • 脚本没有照抄对标原句，标题没有极限词和收益承诺
  • 成片水印是 @阿夏的AI片场，开头有“AI 生成”提示
  • 字幕和配音逐字一致
  • 审核报告没有未解决的 High 和 Blocker
  • 作品包 README 列出了每个文件的来源

4. 常见问题

前面有课没做，能直接学这一课吗？ 能。缺哪课，就把 参考结果/ 里对应的文件夹复制到 成果/ 下，比如把 参考结果/4-2 复制成 成果/4-2。

每周都要把五步全走一遍吗？ 不一定。雷达每周跑；套路已经熟悉的爆款可以跳过拆解；工作流和配方攒多了，出片会越来越快。审核每条都要做。

作品包里为什么不直接放发布按钮？ 课程不做自动发布。发布前最后看一眼，由人决定。

5. 练习

用你自己账号这一周的对标数据，按五步走一遍，交出一个作品包。做完数一数：哪一步最花时间，下周能不能用已有的文件省掉它。

学完之后

  • 每周固定时间跑一次雷达（1-2），把周报存下来，下周对比；
  • 攒工作流和配方（4-2、5-2），每条新视频尽量从已有的开始改；
  • 每条发布前都审一次（6-1），被限流时按 6-2 的方法排查；
  • 想找更多工具，看 awesome-ai-media-cn。
