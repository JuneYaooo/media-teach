# 3-1 逐镜拆爆款：每一镜是怎么拍、怎么做的 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/3-1-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 6 分 15 秒 – 7 分 15 秒（安装等待已加速） |
| 前置产物 | 无（1-2 的“本周待拆”只在旁白里提到） |
| 用到的素材 | `资料/爆款样片/镜头造梦师-外卖员穿越唐朝.mp4` 及同名 `.srt`、`资料/复刻改编设定.md`（`$WS/资料/` = `录屏方案/演示素材/` 的副本） |
| 这一段要教会 | ① rea-video 的工作原理（讲义流程图：切镜头 → 信号取证 → 看画面 → 听声音 → 合并判断 → 看图复核 → 报告和方案）；② 读报告：依据、置信度、待确认；③ 怎么核对：抽两镜回原片看；④ 复刻方案按场景合并生成单元，换成自己的人物和故事；⑤ 第一次用 rea-video 先装：用讲义的安装提示词让 WorkBuddy 装，到“已安装”确认开关开着 |

**不录**：Douyin_TikTok_Download_API 下载第三方视频的过程。讲义里有文字说明，录屏只用课程自制的本地样片（代替学员自己的对标爆款）。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/阿夏的AI片场
rm -rf "$WS/成果/3-1"
mkdir -p 录屏方案/_work/3-1/raw
command -v ffmpeg && python3 --version   # ffmpeg 录前就要有，免得 S0 多出一段装 ffmpeg 的等待
```

- “专家·技能·连接器”→“技能”→“已安装”：如果已有 `rea-video`，先卸载（S0 要现场装）。只卸载技能本身，ffmpeg、Python 和本机已有的看图模型配置保留。
- 在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表清空或收起；确认统一模型。
- 预先用 QuickTime 打开一次样片再关闭，确认能播放。
- 若 rea-video 需要看图模型密钥，只从本机既有配置读取，画面里不能出现 `.env` 内容。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

### S0 安装技能（原始片段 `3-1-S0.mp4`）

讲义“你要准备什么”里的安装提示词，原样演示一遍。安装等待在剪辑时加速。

1. 开始录制。点“新建任务”，确认工作空间为 `阿夏的AI片场`。
2. 点击输入框，粘贴（原样）：

```text
帮我安装 rea-video 技能：https://github.com/JuneYaooo/rea-video。它要用到 ffmpeg，我电脑上没有的话先告诉我，我同意后再装。装之前先告诉我它要装哪些东西、会不会联网或花钱，我确认后再装。需要 Key 时停下来，告诉我写到哪，我自己填，不要在对话里显示。
```

3. 停 2 秒。**标记 M0-1**。发送。它列出要装的东西、会不会联网或花钱、等你确认时 **标记 M0-2**，停 2 秒。然后粘贴并发送：

```text
确认，装吧。
```

4. 等待安装（不动鼠标）。请求执行命令时点“允许”。出现“安装完成”一类说明时 **标记 M0-3**。
5. 左侧栏点“专家·技能·连接器”→“技能”→“已安装”，找到 `rea-video`，鼠标停在开关旁 2 秒。**标记 M0-4**。看不到时：暂停录制，镜头外重启 WorkBuddy，恢复录制后补拍这一步。
6. 结束录制。

> 安装中途它停下来要 Key、要装缺的运行环境、或说已经装过：照实录下，按讲义回复（同意装运行环境；Key 在镜头外填），写进 report.md。

### S1 提交拆解任务（原始片段 `3-1-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点“新建任务”，确认输入框下方显示 `阿夏的AI片场`。
3. 点击输入框，粘贴（原样）：

```text
用 rea-video 拆一下这条爆款：资料里那条《外卖员穿越唐朝》样片。我想知道每一镜是实拍、AI 生成、代码动效还是录屏，判断依据和把握有多大；花字什么时候出现、什么样式；配音配乐从哪来。拿不准的镜头请看图复核，还是拿不准就标“待确认”并写清缺什么证据。给我一份中文逐镜报告，放到 成果/3-1。
```

4. 停 3 秒。**标记 M1-1**。
5. 点发送。回复里出现运行 `rea-video decompose` 的提示时，**标记 M1-2**。
6. 等待生成完成（可能 5–15 分钟）。出现中文拆解报告的文件卡片时，**标记 M1-3**。
7. 停 2 秒，结束录制。

### S2 看分镜联系表和报告开头（原始片段 `3-1-S2.mp4`）

1. 开始录制。
2. 在工作区文件列表打开 `成果/3-1` 里 rea-video 生成的分镜联系表图片，停 5 秒。**标记 M2-1**。
3. 点击中文拆解报告的文件卡片，停在开头 4 秒。**标记 M2-2**。
4. 滚动到逐镜表，停 6 秒，让 8 镜都在画面里（放不下就分两屏，每屏 4 秒）。**标记 M2-3**。
5. 停在第 3 镜那一行 4 秒。**标记 M2-4**。
6. 停在第 6 镜那一行 4 秒。**标记 M2-5**。
7. 结束录制。

### S3 回原片抽查（原始片段 `3-1-S3.mp4`）

1. 录前准备：用 QuickTime 打开样片，窗口调成 720×1000 放在屏幕右侧；WorkBuddy 窗口缩到左侧，右侧预览区停在拆解报告的逐镜表。
2. 开始录制。
3. 在终端（不入画，或用快捷键触发）执行，让 QuickTime 跳到 6.6 秒并暂停：

```sh
osascript -e 'tell application "QuickTime Player" to set current time of front document to 6.6'
```

停 3 秒；再依次跳到 7.0、7.5 秒各停 2 秒，让“大唐 · 贞观三年”逐字出现的过程可见。**标记 M3-1**。
4. 跳到 16.0 秒，停 3 秒（花字还没出现）。**标记 M3-2**。
5. 跳到 16.4 秒，停 4 秒（黄色“0 格信号”出现）。**标记 M3-3**。
6. 结束录制。

**此时按“C. 分支”判断是否录 S4、S5。**

### S4 告诉它哪里判错（仅主线，原始片段 `3-1-S4.mp4`）

1. 开始录制，WorkBuddy 恢复 1440×900，回到同一任务。
2. 点击输入框，粘贴（下面是两处都错时的写法；只错一处就删掉没错的那句。这段不在讲义里，讲义只教“哪一镜、看到什么、应该是什么”的说法）：

```text
我对着原片查了两处：第 3 镜“大唐 · 贞观三年”是纯黑背景上逐字打出的标题卡，是代码动效，不是 AI 生成；第 6 镜的黄色花字“0 格信号”在 16.4 秒左右才出现，不是镜头开始的 16.0 秒。请改正报告，拿不准就重新抽帧确认，并在末尾加一段“人工复核记录”。
```

3. 停 3 秒。**标记 M4-1**。
4. 点发送，等待完成。**标记 M4-2**。
5. 结束录制。

### S5 看改后报告（仅主线，原始片段 `3-1-S5.mp4`）

1. 开始录制。
2. 打开（或刷新）拆解报告，停在第 3 镜那一行 4 秒。**标记 M5-1**。
3. 停在第 6 镜那一行 4 秒。**标记 M5-2**。
4. 滚动到末尾“人工复核记录”，停 5 秒。**标记 M5-3**。
5. 结束录制。

### S6 写复刻方案（原始片段 `3-1-S6.mp4`）

1. 开始录制，同一任务。
2. 点击输入框，粘贴（原样）：

```text
根据这份报告写一份复刻方案，我想做成自己的版本：剪辑师阿夏熬夜剪片时穿越到唐朝西市，人物和故事按资料里的复刻改编设定。AI 镜头连在一起的尽量合并成一次生成，代码能做的花字和标题卡单独列出来，声音单独列。只学做法，不用原片的角色、台词和水印。
```

3. 停 3 秒。**标记 M6-1**。
4. 点发送，等待完成。出现复刻方案的文件卡片时，**标记 M6-2**。
5. 结束录制。

### S7 看复刻方案（原始片段 `3-1-S7.mp4`）

1. 开始录制。
2. 点击复刻方案，停在生成单元（分组）部分 6 秒。**标记 M7-1**。
3. 滚动到第 1 个 H3 生成单元（含中文提示词和参考图清单），停 6 秒。**标记 M7-2**。
4. 滚动到代码镜头（标题卡）那一节，停 4 秒。**标记 M7-3**。
5. 滚动到声音一节，停 4 秒。**标记 M7-4**。
6. 结束录制。

## C. 分支

S2 结束后检查：

```sh
grep -n -E "^\| *3 *\|" "$WS"/成果/3-1/*.md
grep -n -E "0 ?格信号" "$WS"/成果/3-1/*.md
```

- **主线**（录 S4、S5）：第 3 镜的“制作方式”写成 AI 生成 / AI 视频，或标为“待确认”且倾向 AI；或“0 格信号”的时间写成 16.0 秒（或未写具体时间）。
- **分支 B**（跳过 S4、S5）：第 3 镜已判为代码动效 / 代码模板渲染，且“0 格信号”时间在 16.3–16.5 秒。剪辑表镜头 10–11 换成分支 B 镜头；S6 的提示词照常发送。
- 只错其中一处：S4 提示词删掉没错的那一句再发送，旁白同步删掉对应句子，在 report.md 写明。
- 出现别的明显错误（如镜头数不是 8、把整片判为实拍）：照实录，在 report.md 写明，录完由人决定是否补纠正。
