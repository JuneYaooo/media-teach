# 5-1 按拆解方案，用 H3 还原 AI 镜头 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `AI视频教程/录屏/5-1-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 5 分 30 秒 – 6 分 30 秒 |
| 前置产物 | `$WS/成果/3-1/`（拆解报告、复刻方案） |
| 用到的素材 | `资料/复刻改编设定.md`、`资料/爆款样片/镜头造梦师-外卖员穿越唐朝.mp4` |
| 用到的技能 | capsule-cinema（分镜、质量检查）；open-source-video-gen-skill：character-three-view、h3-prompt-writing、autodl-app-instance、minimax-h3、qwen3-tts |
| 外部条件 | AutoDL 账号、MINIMAX-H3 应用实例、`~/.config/autodl.env` 中的 `AUTODL_TOKEN`；本课预计 GPU 费用几元以内 |
| 这一段要教会 | ① 先审分镜再花钱；② 先出一个校准镜头；③ 一次开机批量提交，下载完立刻关机，到控制台亲眼确认；④ 逐镜对照原片，列返工清单 |

## 预期结果

- `成果/5-1/`：`分镜表.md`、`阿夏-角色参考.png`、`H3提示词/`（7 个 txt）、`镜头/S04-校准.mp4` 及其他 6 镜、`成片-初版.mp4`（30 秒，1080×1920，第 3 镜 1.5 秒黑场）、`生成记录.md`、`QA记录.md`（含逐镜对比表和待返工清单）。
- 阿夏版 8 镜见讲义第 1 节表格；不得出现“外卖员”“公主”“奶茶”。
- 设计中的核对点：角色一致性（发型、灰色卫衣、相机包、只出现一个阿夏）；任务结束后实例已关机。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/阿夏的AI片场
rm -rf "$WS/成果/5-1"
[ -d "$WS/成果/3-1" ] || cp -R "$WS/参考结果/3-1" "$WS/成果/3-1"
mkdir -p 录屏方案/_work/5-1/raw
```

录前检查（都不录）：

1. `ls -l ~/.config/autodl.env` 存在且权限为 `-rw-------`。**不要 cat 这个文件，不要让 Token 出现在任何画面。**
2. 在 open-source-video-gen-skill 仓库目录运行 `bash scripts/doctor.sh --probe`，能列出实例，且实例当前为关机状态。
3. 浏览器提前登录 AutoDL 控制台，打开“应用实例”列表。调整窗口和滚动位置，使画面里**只有实例列表的名称和状态两列**：顶部导航（含账号名、余额）滚出画面或用窗口裁切挡在录制区域外。做不到就不录控制台，改用 C 节的终端方案。
4. WorkBuddy：关闭预览标签页；任务列表只留本课；确认上述技能已启用。

## B. 录制步骤

### S1 出分镜，不花钱（原始片段 `5-1-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点“新建任务”，确认工作空间 `阿夏的AI片场`。
3. 粘贴（原样）：

```text
当前工作空间：阿夏的AI片场。
请读 成果/3-1/ 里的拆解报告和复刻方案，以及 资料/复刻改编设定.md，为阿夏做一条 30 秒竖屏短剧的分镜。
要求：
1. 沿用样片的 8 镜结构和每镜时长、景别、运镜，但人物和故事全部换成改编设定里的阿夏；不得出现“外卖员”“公主”“奶茶”。
2. 第 3 镜标题卡写“大唐 · 开元十年”，第 6 镜相机屏幕显示电量耗尽、花字“电量 0%”在 16.4 秒出现——这两处是代码动效，下一课用 HyperFrames 做，这一课只在分镜里标注，不生成。
3. 用 capsule-cinema 技能把分镜整理成可审分镜，先不要生成任何图片或视频。
4. 用 character-three-view 技能的要求写阿夏的角色设定（短发、灰色卫衣、背相机包，AI 原创形象，不像任何真人），生成一张角色参考图；如果当前环境不能生图，告诉我，不要跳过。
5. 用 h3-prompt-writing 技能，把第 1、2、4、5、6、7、8 镜各写成一条 H3 提示词，每条 5 到 6 秒（H3 单次最短 5 秒，成片里再裁短）。
交付到 成果/5-1/：分镜表.md、阿夏-角色参考.png、H3提示词/（每镜一个 txt）。先给我看分镜，等我确认再开机生成。
```

4. 停 3 秒。**标记 M1-1**。
5. 点发送，等待完成。出现 `分镜表.md`、`阿夏-角色参考.png` 文件卡片时 **标记 M1-2**。
6. 打开 `分镜表.md`，停在 8 镜表格 5 秒。**标记 M1-3**。滚到第 3、6 镜“代码动效，下一课做”的标注，停 3 秒。**标记 M1-4**。
7. 打开 `阿夏-角色参考.png`，停 3 秒。**标记 M1-5**。
8. 打开 `H3提示词/` 里第 4 镜的 txt，停 3 秒。**标记 M1-6**。结束录制。

### S2 校准镜头（原始片段 `5-1-S2.mp4`）

1. 开始录制。
2. 粘贴（原样）：

```text
分镜确认。先只生成一个校准镜头：第 4 镜（唐朝西市全景，阿夏站在人群中）。这一镜人多、场景大，最容易出问题，先用它验证风格和角色。
请用 autodl-app-instance 技能开机，用 minimax-h3 技能生成这一镜，下载后用 ffprobe 核对时长和分辨率，然后立刻关机。AutoDL Token 从本机私有配置读取，不要在对话里显示。
把这次的开机时间、生成耗时、关机时间和估算费用写进 成果/5-1/生成记录.md，校准镜头存为 成果/5-1/镜头/S04-校准.mp4。告诉我实例现在的状态。
```

3. 停 3 秒。**标记 M2-1**。
4. 点发送。回复里出现开机成功 / ComfyUI 就绪时 **标记 M2-2**；出现提交任务时 **标记 M2-3**；出现下载完成与 ffprobe 核对时 **标记 M2-4**；出现关机完成时 **标记 M2-5**。
5. 等待完成，打开 `S04-校准.mp4` 播放一遍。**标记 M2-6**。
6. 打开 `生成记录.md`，停 4 秒。**标记 M2-7**。结束录制。

### S3 控制台确认关机（原始片段 `5-1-S3.mp4`）

1. 切到已准备好的浏览器窗口（只露实例名称和状态）。刷新。
2. 开始录制。停 4 秒，状态为“已关机”。**标记 M3-1**。
3. 结束录制。若画面露出账号信息，删掉本片段重录。

**此时按“C. 分支”判断校准结果。**

### S4 批量生成并拼接（原始片段 `5-1-S4.mp4`）

1. 开始录制，回到 WorkBuddy 同一任务。
2. 粘贴（原样）：

```text
校准镜头风格可以：阿夏只出现一个，灰色卫衣和相机包都在。按同样的风格生成剩下 6 个 AI 镜头（第 1、2、5、6、7、8 镜）。
要求：一次开机，把 6 条任务全部提交进队列再等结果，不要生成一条等一条；全部下载并核对时长后立刻关机。旁白用 qwen3-tts 在同一次开机里生成；当前实例不支持就跳过旁白，用 H3 自带的声音，并告诉我。
关机后在本地完成：把每镜裁到分镜规定的时长、统一成 1080×1920 30fps；第 3 镜先放 1.5 秒黑场占位；按分镜拼成 成果/5-1/成片-初版.mp4，加上字幕和第 6 镜以外的花字（第 6 镜花字下一课做），右下角加 @阿夏的AI片场 水印。
用 capsule-cinema 的质量检查跑一遍，结果写进 成果/5-1/QA记录.md。生成记录.md 里补上这次的开关机时间和费用。
```

3. 停 3 秒。**标记 M4-1**。
4. 点发送。出现“6 条任务已全部提交”或队列信息时 **标记 M4-2**；出现关机完成时 **标记 M4-3**；出现成片文件卡片时 **标记 M4-4**。
5. 打开 `成片-初版.mp4` 播放完整 30 秒。**标记 M4-5**。
6. 打开 `生成记录.md`，停在本次开关机时间和费用 4 秒。**标记 M4-6**。结束录制。

### S5 再次确认关机（原始片段 `5-1-S5.mp4`）

同 S3。**标记 M5-1**。

### S6 逐镜对照与返工清单（原始片段 `5-1-S6.mp4`）

1. 开始录制，回到 WorkBuddy 同一任务。
2. 粘贴（原样）：

```text
我在 AutoDL 控制台核对了实例状态。请再做两件事：
1. 逐镜对照原片和成片，填一张对比表到 QA记录.md：每镜的景别、运镜、时长是否还原；阿夏的发型、卫衣颜色、相机包在每一镜是否一致；有没有出现两个阿夏或多余的人物变形。
2. 把不合格的镜头列成“待返工清单”，写清哪一镜、哪里不对、建议怎么改提示词。这一课不重新生成，下一课只返工清单里最严重的一镜。
```

3. 停 3 秒。**标记 M6-1**。
4. 点发送，等待完成。打开 `QA记录.md`，停在逐镜对比表 5 秒。**标记 M6-2**。滚到“待返工清单”，停 5 秒。**标记 M6-3**。
5. 结束录制。

### 剪辑素材（不录，终端生成）

```sh
cd "$WS"
# 原片 / 复刻 同步并排
ffmpeg -y -i 资料/爆款样片/镜头造梦师-外卖员穿越唐朝.mp4 -i 成果/5-1/成片-初版.mp4 \
  -filter_complex "[0:v]scale=-2:900[a];[1:v]scale=-2:900[b];[a][b]hstack=inputs=2[v]" \
  -map "[v]" -an 录屏方案/_work/5-1/原片-复刻.mp4
```

（命令里的相对输出路径按 `实践手册.md` 改成仓库下 `录屏方案/_work/5-1/` 的绝对路径。）

## C. 分支

**校准结果（S3 后判断）**：播放 `S04-校准.mp4`。

- **主线**：阿夏只出现一个，灰色卫衣和相机包都在 → 照常录 S4（实操 3 第一句与画面相符）。
- **校准不合格**（出现两个阿夏、卫衣颜色不对、相机包缺失等）：不录 S4，先录一段 `5-1-S3b.mp4`，粘贴下面的话（把 `<问题>` 换成实际问题，写进 report.md），等它重新生成并关机，再录 S3 一次；直到合格后再录 S4。剪辑时在镜头 9 后插入镜头 9C。

```text
校准镜头不合格：<问题>。请只改第 4 镜的提示词，重新开机生成一次校准镜头，下载核对后立刻关机，并把这次也记进生成记录.md。
```

**关机核对（S3、S5 都要做）**：

- 控制台显示“已关机” → 主线。
- Agent 说已关机但控制台仍在运行：录下这一画面，立即在控制台手动关机，在 report.md 写明；剪辑时用镜头 10D 替换镜头 10。
- 控制台无法在不露账号信息的情况下拍摄：不录控制台，改在终端（WorkBuddy 右侧“打开终端”）运行 `python3 <open-source-video-gen-skill 路径>/skills/autodl-app-instance/scripts/autodl_app.py list`，只保留状态列入画；输出里如有实例 UUID 以外的账号信息，不录。

**数字以实际为准**：GPU 用时、费用、各镜实际时长和设计不同时，旁白改成实际值，并在 report.md 列出。

## F. 验收

- [ ] 全片没有出现 Token、账号名、余额、手机号等任何账号信息（逐帧抽查控制台和终端片段）。
- [ ] 控制台“已关机”至少出现两次（校准后、批量后）。
- [ ] 有一段原片 ｜ 复刻同步并排。
- [ ] 生成记录里的开关机时间和费用被放大展示。
- [ ] report.md 写明 GPU 总用时和费用，录完后再到控制台确认一次已关机。
- [ ] 每个章节不短于 15 秒（收尾除外）；无其他课标签页、无关会话、弹窗。
- [ ] 时长在 5:30–6:30 之间。
