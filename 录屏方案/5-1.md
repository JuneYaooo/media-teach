# 5-1 用 AI 生成镜头：把分镜变成画面 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/5-1-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 6 分 15 秒 – 7 分 15 秒（安装等待已加速） |
| 前置产物 | `$WS/成果/3-1/`（拆解报告、复刻方案） |
| 用到的素材 | `资料/复刻改编设定.md`、`资料/爆款样片/镜头造梦师-外卖员穿越唐朝.mp4`（`$WS/资料/` = `录屏方案/演示素材/` 的副本） |
| 用到的技能 | capsule-cinema（分镜、质量检查）；open-source-video-gen-skill：character-three-view、h3-prompt-writing、autodl-app-instance、minimax-h3、qwen3-tts |
| 外部条件 | AutoDL 账号、MINIMAX-H3 应用实例、`~/.config/autodl.env` 中的 `AUTODL_TOKEN`；本课预计 GPU 费用几元以内 |
| 这一段要教会 | ① 整条流程（讲义流程图：复刻方案 → 可审分镜和角色图 → H3 提示词 → 开机出校准 → 确认 → 整批 → 关机 → 对照）；② 先审分镜再花钱；③ 先出一个校准镜头；④ 一次开机批量提交，下载完立刻关机，到控制台亲眼确认；⑤ 自己租 GPU 和调 API 怎么选；⑥ 逐镜对照原片，列返工清单；⑦ 本课是选学（做 AI 画面的号才需要）；第一次用先装两个技能，到“已安装”确认开关开着 |

## 预期结果

- `成果/5-1/` 里：分镜、阿夏角色参考图、7 条 H3 提示词、校准镜头及其他 6 镜、初版成片（30 秒竖屏，第 3 镜黑场占位）、生成记录、QA 记录（含逐镜对比表和待返工清单）。文件名由 Agent 决定。
- 阿夏版 8 镜见 `录屏方案/演示素材/复刻改编设定.md` 和 `课程规划/01-练习包与课程数据设计.md`；不得出现“外卖员”“公主”“奶茶”。
- 设计中的核对点：角色一致性（发型、灰色卫衣、相机包、只出现一个阿夏）；任务结束后实例已关机。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/阿夏的AI片场
rm -rf "$WS/成果/5-1"
[ -d "$WS/成果/3-1" ] || cp -R "/Users/june2/code/github/media-teach/录屏方案/_work/3-1/成果" "$WS/成果/3-1"
mkdir -p 录屏方案/_work/5-1/raw
```

录前检查（都不录）：

1. `ls -l ~/.config/autodl.env` 存在且权限为 `-rw-------`。**不要 cat 这个文件，不要让 Token 出现在任何画面。** 没有这个文件时，按讲义“准备 AutoDL”第 4 步在镜头外准备：让 WorkBuddy 建好私有文件并打开，人只在打开的文件里粘贴 Token。整个过程不录。
2. 在 open-source-video-gen-skill 仓库目录运行 `bash scripts/doctor.sh --probe`，能列出实例，且实例当前为关机状态。
3. 浏览器提前登录 AutoDL 控制台，打开“应用实例”列表。调整窗口和滚动位置，使画面里**只有实例列表的名称和状态两列**：顶部导航（含账号名、余额）滚出画面或用窗口裁切挡在录制区域外。做不到就不录控制台，改用 C 节的终端方案。
4. WorkBuddy：关闭预览标签页；任务列表只留本课。做完第 1–3 条检查后，“专家·技能·连接器”→“技能”→“已安装”：如果已有 open-source-video-gen-skill 的各技能（character-three-view、h3-prompt-writing、autodl-app-instance、minimax-h3、qwen3-tts 等）和 `capsule-cinema`，先卸载（S0 要现场装）。只卸载技能本身，`~/.config/autodl.env` 和 Python 环境保留。S0 录完后，镜头外再做一次第 2 条检查。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

### S0 安装技能（原始片段 `5-1-S0.mp4`）

讲义“你要准备什么”里的安装提示词，原样演示一遍。安装等待在剪辑时加速。

1. 开始录制。点“新建任务”，确认工作空间为 `阿夏的AI片场`。
2. 点击输入框，粘贴（第 1 条，原样）：

```text
帮我安装 open-source-video-gen-skill 技能：https://github.com/mini-yifan/open-source-video-gen-skill。装之前先告诉我它要装哪些东西、会不会联网或花钱，我确认后再装。需要 Key 或 Token 时停下来，告诉我写到哪，我自己填，不要在对话里显示。
```

3. 停 2 秒。**标记 M0-1**。发送。它列出要装的东西、会不会联网或花钱、等你确认时 **标记 M0-2**，停 2 秒。然后粘贴并发送：

```text
确认，装吧。
```

4. 等待安装（不动鼠标）。请求执行命令时点“允许”。出现“安装完成”一类说明时 **标记 M0-3**。
5. 点击输入框，粘贴（第 2 条，原样）：

```text
帮我安装 Capsule Cinema 技能：https://github.com/JuneYaooo/cheap-claude-video。装之前先告诉我它要装哪些东西、会不会联网或花钱，我确认后再装。需要 Key 时停下来，告诉我写到哪，我自己填，不要在对话里显示。
```

6. 停 2 秒，发送。它列出要装的东西、等你确认时，粘贴并发送：

```text
确认，装吧。
```

7. 等待安装（不动鼠标）。请求执行命令时点“允许”。出现“安装完成”一类说明时 **标记 M0-4**。
8. 左侧栏点“专家·技能·连接器”→“技能”→“已安装”，找到 `h3-prompt-writing`、`minimax-h3`、`autodl-app-instance`、`capsule-cinema`，鼠标停在开关旁 2 秒。**标记 M0-5**。看不到时：暂停录制，镜头外重启 WorkBuddy，恢复录制后补拍这一步。
9. 结束录制。

> 安装中途它停下来要 Key、要装缺的运行环境、或说已经装过：照实录下，按讲义回复（同意装运行环境；Key 在镜头外填），写进 report.md。

### S1 出分镜，不花钱（原始片段 `5-1-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点“新建任务”，确认工作空间 `阿夏的AI片场`。
3. 粘贴（原样）：

```text
读 3-1 的复刻方案，给我做一份可审的分镜：沿用原片的镜头结构、时长、景别和运镜，人物和故事换成我的：剪辑师阿夏熬夜剪片时穿越到唐朝西市，详细设定在资料里的复刻改编设定。原片的角色、台词、标志性道具都不能出现。代码能做的花字和标题卡只标注，下一课做。用 capsule-cinema 整理分镜，用 character-three-view 给主角出一张参考图（AI 原创，不像任何真人），用 h3-prompt-writing 给需要 AI 生成的镜头写提示词。先不要生成视频，放到 成果/5-1。
```

4. 停 3 秒。**标记 M1-1**。
5. 点发送，等待完成。出现分镜和角色参考图的文件卡片时 **标记 M1-2**。
6. 打开分镜，停在 8 镜表格 5 秒。**标记 M1-3**。滚到第 3、6 镜“代码动效，下一课做”的标注，停 3 秒。**标记 M1-4**。
7. 打开角色参考图，停 3 秒。**标记 M1-5**。
8. 打开第 4 镜的 H3 提示词，停 3 秒。**标记 M1-6**。结束录制。

### S2 校准镜头（原始片段 `5-1-S2.mp4`）

1. 开始录制。
2. 粘贴（原样）：

```text
分镜可以。先只生成一个校准镜头：第 4 镜西市全景，人多、场景大，最容易出问题。用 autodl-app-instance 和 minimax-h3 开机生成，下载后立刻关机，Token 不要在对话里显示。记下开关机时间和费用，告诉我实例现在的状态。
```

3. 停 3 秒。**标记 M2-1**。
4. 点发送。回复里出现开机成功 / ComfyUI 就绪时 **标记 M2-2**；出现提交任务时 **标记 M2-3**；出现下载完成时 **标记 M2-4**；出现关机完成时 **标记 M2-5**。
5. 等待完成，打开校准镜头播放一遍。**标记 M2-6**。
6. 打开生成记录，停 4 秒。**标记 M2-7**。结束录制。

### S3 控制台确认关机（原始片段 `5-1-S3.mp4`）

1. 切到已准备好的浏览器窗口（只露实例名称和状态）。刷新。
2. 开始录制。停 4 秒，状态为“已关机”。**标记 M3-1**。
3. 结束录制。若画面露出账号信息，删掉本片段重录。

**此时按“C. 分支”判断校准结果。**

### S4 批量生成、拼接、逐镜对照（原始片段 `5-1-S4.mp4`）

1. 开始录制，回到 WorkBuddy 同一任务。
2. 粘贴（原样）：

```text
校准镜头可以。按同样的风格把剩下的 AI 镜头一次生成完：一次开机，全部排进队列，下载完立刻关机。关机后拼成初版成片，代码镜头先放黑场占位，加上字幕和我的水印。再逐镜对照原片：景别、运镜、时长有没有还原，主角每一镜是否一致，有没有人物重复或变形。不合格的列成待返工清单，写清哪里不对、提示词怎么改。这次的开关机时间和费用也记上。
```

3. 停 3 秒。**标记 M4-1**。
4. 点发送。出现“6 条任务已全部提交”或排队信息时 **标记 M4-2**；出现关机完成时 **标记 M4-3**；出现成片文件卡片时 **标记 M4-4**。
5. 打开初版成片，播放完整 30 秒。**标记 M4-5**。
6. 打开生成记录，停在本次开关机时间和费用 4 秒。**标记 M4-6**。
7. 打开逐镜对照，停在对比表 5 秒。**标记 M6-2**。滚到“待返工清单”，停 5 秒。**标记 M6-3**。结束录制。

### S5 再次确认关机（原始片段 `5-1-S5.mp4`）

同 S3。**标记 M5-1**。

## C. 分支

**校准结果（S3 后判断）**：播放校准镜头。

- **主线**：阿夏只出现一个，灰色卫衣和相机包都在 → 照常录 S4。
- **校准不合格**（出现两个阿夏、卫衣颜色不对、相机包缺失等）：不录 S4，先录一段 `5-1-S3b.mp4`，粘贴下面的话（把 `<问题>` 换成实际问题，写进 report.md），等它重新生成并关机，再录 S3 一次；直到合格后再录 S4。剪辑时在镜头 9 后插入镜头 9C。

```text
校准镜头不合格：<问题>。只改第 4 镜的提示词，再开机生成一次，下载后立刻关机，这次也记上。
```

**关机核对（S3、S5 都要做）**：

- 控制台显示“已关机” → 主线。
- Agent 说已关机但控制台仍在运行：录下这一画面，立即在控制台手动关机，在 report.md 写明；剪辑时用镜头 10D 替换镜头 10。
- 控制台无法在不露账号信息的情况下拍摄：不录控制台，改在终端（WorkBuddy 右侧“打开终端”）运行 `python3 <open-source-video-gen-skill 路径>/skills/autodl-app-instance/scripts/autodl_app.py list`，只保留状态列入画；输出里如有实例 UUID 以外的账号信息，不录。

**没有 AutoDL、只有 H3 的 API Key**：整课改走 API 接法。实操 2 提示词里“用 autodl-app-instance 和 minimax-h3 开机生成，下载后立刻关机”换成“用 capsule-cinema 的 H3 渠道生成”；实操 3 里“一次开机，全部排进队列，下载完立刻关机”换成“全部一起提交”，“开关机时间和费用”改成“费用”；其余文字不变；不录控制台，剪辑时删掉镜头 10 和所有“关机”角标，旁白里“生成完立刻关机”改成“先出一镜，确认了再批量”。在 report.md 写明用的是哪个渠道和实际费用。

**数字以实际为准**：GPU 用时、费用、各镜实际时长和设计不同时，旁白改成实际值，并在 report.md 列出。
