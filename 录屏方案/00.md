## A. 录前重置

```sh
REPO=/Users/june2/code/github/media-teach
cd "$REPO" && python3 scripts/build_site.py      # 确保网站是最新文案
# 解压一份全新的练习包，专门给本段展示（录制工作区里已经有各课结果，不能用）
rm -rf ~/WorkBuddy录制/展示用 && mkdir -p ~/WorkBuddy录制/展示用
cd ~/WorkBuddy录制/展示用 && unzip -q "$REPO/自媒体教程/自媒体教程-练习包.zip"
mkdir -p "$REPO/录屏方案/_work/00/raw"
```

浏览器（建议 Chrome）：

```sh
open -na "Google Chrome" --args --incognito --window-size=1440,900 --window-position=0,25 \
  "file:///Users/june2/code/github/media-teach/index.html"
```

- 用**无痕窗口**，学习进度（浏览器本地存储）是空的，首页不会出现“继续学习”。
- 不显示书签栏；只开这一个标签页；缩放 100%（字太小可调 110%，整段一致）。

Finder：新开一个窗口，1440×900，列表视图，打开 `~/WorkBuddy录制/展示用/阿夏的AI片场`，先最小化。

## B. 录制步骤

下面的按钮和标题文字以 `scripts/build_site.py` 生成的页面为准。与本规格写法不一致时，按画面上实际文字操作，并在 report.md 记录差异，同时把旁白里提到的按钮名改成实际文字。

### S1 首页（原始片段 `00-S1.mp4`）

1. 开始录制。停在首页顶部 3 秒（能看到大标题、“开始入门课”和“下载练习包”按钮）。**标记 M1-1**。
2. 鼠标慢慢移到“开始前准备”区块，停 4 秒。**标记 M1-2**。
3. 慢慢向下滚动到“先学入门课”区块，停 3 秒（能看到 01 和 00 两张卡片）。**标记 M1-3**。
4. 继续向下滚动，经过六个模块的课程列表：在“① 找对标”标题处停 2 秒（**标记 M1-4**），继续滚到“④ 爆款复刻”和“⑤ 视频复刻”两组同时可见处停 4 秒（**标记 M1-5**），再滚到“⑥ 违规审核”和“07 结课”停 2 秒（**标记 M1-6**）。
5. 结束录制。

### S2 练习包（原始片段 `00-S2.mp4`）

1. 开始录制。滚回首页顶部，鼠标移到“下载练习包”按钮上停 3 秒（**不点击**，避免出现下载栏）。**标记 M2-1**。
2. 切到 Finder 窗口（`~/WorkBuddy录制/展示用/阿夏的AI片场`），停 3 秒，能看到 `资料`、`成果`、`参考结果`、`开始前请读.txt`。**标记 M2-2**。
3. 依次单击选中 `资料`、`成果`、`参考结果`（不展开），各停 2 秒。分别 **标记 M2-3、M2-4、M2-5**。
4. 双击展开 `资料`，停 3 秒，能看到 `账号档案.md`、`爆款样片` 等。**标记 M2-6**。
5. 结束录制。

### S3 一节课里有什么（原始片段 `00-S3.mp4`）

以 1-1 为例。

1. 开始录制，切回浏览器。滚到“① 找对标”，点击 **1-1 扫同赛道，筛出真对标** 卡片。
2. 课程页打开后停在顶部 3 秒，能看到“时长 / 难度 / 前置 / 产出”和“怎么学”。**标记 M3-1**。
3. 向下滚到“实操录屏”区块，停 3 秒（能看到视频和章节按钮）。**标记 M3-2**。
4. 向下滚到“快速实操”里“实操 1”的提示词代码块，鼠标移到“复制”按钮上停 3 秒（可以点一下，按钮变成“已复制”）。**标记 M3-3**。
5. 继续滚到“实操 2”标题停 2 秒。**标记 M3-4**。
6. 向下滚到“本次任务结果与核对”，停 4 秒。**标记 M3-5**。
7. 结束录制。

### S4 标记学完（原始片段 `00-S4.mp4`）

1. 开始录制。在 1-1 课程页滚到“标记本课已学完”按钮，点击，按钮状态改变，停 3 秒。**标记 M4-1**。
2. 点页面左上角站点名回到首页。首页出现“继续学习”提示、模块进度变化，停 4 秒。**标记 M4-2**。
3. 结束录制。
