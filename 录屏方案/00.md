```sh
REPO=/Users/june2/code/github/media-teach
cd "$REPO" && python3 scripts/build_site.py      # 确保网站是最新文案
mkdir -p "$REPO/录屏方案/_work/00/raw"
```

浏览器（建议 Chrome，需联网，流程图从 CDN 加载）：

```sh
open -na "Google Chrome" --args --incognito --window-size=1440,900 --window-position=0,25 \
  "file:///Users/june2/code/github/media-teach/index.html"
```

- 用**无痕窗口**，学习进度是空的，首页不会出现“继续学习”。
- 不显示书签栏；只开这一个标签页；缩放 100%（字太小可调 110%，整段一致）。
- 录前先打开一次 1-1 课程页，确认流程图已渲染成图（不是一段代码文字）。没渲染出来就停下，写进 report.md。

## B. 录制步骤

下面的按钮和标题文字以 `scripts/build_site.py` 生成的页面为准。与本规格写法不一致时，按画面上实际文字操作，在 report.md 记录差异，并把旁白里提到的按钮名改成实际文字。

### S1 首页（原始片段 `00-S1.mp4`）

1. 开始录制。停在首页顶部 3 秒（能看到大标题、“开始入门课”和“开始前准备”按钮）。**标记 M1-1**。
2. 鼠标慢慢移到“开始前准备”区块，停 5 秒。**标记 M1-2**。
3. 慢慢向下滚动到“先学入门课”区块，停 3 秒（能看到 01 和 00 两张卡片）。**标记 M1-3**。
4. 继续向下滚动，经过六个模块的课程列表：在“① 找对标”标题处停 2 秒（**标记 M1-4**），滚到“④ 爆款复刻”和“⑤ 视频复刻（选学）”同时可见处停 4 秒（**标记 M1-5**），再滚到“⑥ 违规审核”和“07 结课”停 2 秒（**标记 M1-6**）。
5. 结束录制。

### S2 一节课里有什么（原始片段 `00-S2.mp4`）

以 1-1 为例。

1. 开始录制。滚到“① 找对标”，点击 **1-1 用 AI 全网找对标** 卡片。
2. 课程页打开后停在顶部 3 秒，能看到概览（时长 / 难度 / 前置 / 产出）和“怎么学”。**标记 M2-1**。
3. 向下滚到“它是怎么工作的”，停在流程图 5 秒。**标记 M2-2**。
4. 向下滚到“你要准备什么”，停 3 秒。**标记 M2-3**。
5. 向下滚到“实操 1”的提示词代码块，鼠标停在 `<你的主页链接>` 附近 2 秒，再移到“复制”按钮点一下（按钮变成“已复制”），停 2 秒。**标记 M2-4**。
6. 向下滚到“怎么核对结果”，停 4 秒。**标记 M2-5**。
7. 结束录制。

### S3 标记学完（原始片段 `00-S3.mp4`）

1. 开始录制。在 1-1 课程页滚到“标记本课已学完”按钮，点击，按钮状态改变，停 3 秒。**标记 M3-1**。
2. 点页面左上角站点名回到首页。首页出现“继续学习”提示和模块进度变化，停 4 秒。**标记 M3-2**。
3. 结束录制。
