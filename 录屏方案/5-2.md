# 5-2 复刻花字和动效镜头，单镜返工后存成配方 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/5-2-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 5 分 30 秒 – 6 分 30 秒 |
| 前置产物 | `$WS/成果/3-1/`（拆解报告中第 3、6 镜花字参数）、`$WS/成果/5-1/`（成片-初版、镜头、分镜表、QA记录） |
| 用到的素材 | `资料/爆款样片/镜头造梦师-外卖员穿越唐朝.mp4` |
| 用到的技能 | hyperframes（核心 4 个技能）；autodl-app-instance、minimax-h3（只返工一镜）；capsule-cinema（质量检查、保存配方） |
| 外部条件 | 同 5-1（AutoDL 实例、`~/.config/autodl.env`）；返工一镜预计 GPU 费用 1 元以内 |
| 这一段要教会 | ① 文字类镜头用代码做，精确到 0.1 秒；② 花字时间以拆解报告为准；③ 返工只动一镜，用校验值证明其他没动；④ 配方存方法不存内容 |

## 预期结果

- `成果/5-2/`：`hyperframes项目/`、`镜头/S03-标题卡.mp4`（1.5 秒，纯黑底，金色宋体“大唐 · 开元十年”逐字出现）、`镜头/S06-花字.mp4`（4.5 秒，成片 16.4 秒弹出黄色抖动“电量 0%”）、`成片-v2.mp4`、`花字对照.md`、`返工记录.md`（含校验值、开关机时间、费用、QA 结果）、`成片.mp4`、`配方说明.md`；Capsule Cinema 配方目录中新增“AI 短剧”配方。
- 设计中的核对点（设计文档第七节）：原片花字在 16.4 秒出现，Agent 容易放到镜头起点 16.0 秒；颜色为黄色带抖动。

## B. 录制步骤

### S1 做两个动效镜头（原始片段 `5-2-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点“新建任务”，确认工作空间 `阿夏的AI片场`。
3. 粘贴（原样）：

```text
当前工作空间：阿夏的AI片场。
请使用 hyperframes 技能，按 成果/3-1/ 拆解报告里第 3 镜和第 6 镜的花字参数（字体、颜色、出场方式、出现时间），为阿夏的短剧做两个代码动效镜头：
1. 第 3 镜：1.5 秒，1080×1920，纯黑背景，“大唐 · 开元十年”金色宋体逐字打出，节奏和原片一致，配一声钟响。
2. 第 6 镜：4.5 秒，用 成果/5-1/镜头/ 里第 6 镜的 H3 画面做背景，在成片时间 16.4 秒（本镜第 0.4 秒）弹出黄色抖动花字“电量 0%”，样式参照原片“0 格信号”。
不调用任何生成模型。HyperFrames 项目放在 成果/5-2/hyperframes项目/，渲染结果存到 成果/5-2/镜头/S03-标题卡.mp4 和 成果/5-2/镜头/S06-花字.mp4。
然后把这两镜替换进 成果/5-1/成片-初版.mp4（第 3 镜黑场占位换成标题卡），导出 成果/5-2/成片-v2.mp4。写一份 成果/5-2/花字对照.md：原片和阿夏版两处花字的字体、颜色、描边、出现秒数、动画方式逐项对比。
```

4. 停 3 秒。**标记 M1-1**。
5. 点发送。回复中出现 HyperFrames 预览或渲染进度时 **标记 M1-2**。等待完成，出现 `S03-标题卡.mp4` 等文件卡片时 **标记 M1-3**。
6. 打开 `S03-标题卡.mp4` 播放一遍。**标记 M1-4**。
7. 打开 `S06-花字.mp4` 播放一遍。**标记 M1-5**。
8. 打开 `花字对照.md`，停在对比表 5 秒。**标记 M1-6**。结束录制。

### S1 后取帧（不录，终端）

```sh
cd "$WS/成果/5-2"
for t in 16.3 16.5; do ffmpeg -y -ss $t -i 成片-v2.mp4 -frames:v 1 ~/5-2-v2-$t.png; done
ffmpeg -y -ss 16.5 -i "$WS/资料/爆款样片/镜头造梦师-外卖员穿越唐朝.mp4" -frames:v 1 ~/5-2-ref-16.5.png
```

（输出路径按 `实践手册.md` 改到 `录屏方案/_work/5-2/`。）

**此时按“C. 分支”判断是否录 S2。**

### S2 修正花字时间和颜色（仅主线，原始片段 `5-2-S2.mp4`）

1. 开始录制，回到同一任务。
2. 粘贴（原样；如 C 节要求删去不符的半句，按删改后的文字粘贴）：

```text
我对照了 成果/3-1/ 拆解报告和 花字对照.md，第 6 镜花字出现在成片 16.0 秒，原片是 16.4 秒，而且颜色是白色，原片是黄色带抖动。请按拆解报告修正：出现时间改为成片 16.4 秒，黄色，带抖动，描边和原片一致。重新渲染 S06-花字.mp4，替换进成片，更新 花字对照.md。抽 16.3 秒和 16.5 秒两帧给我看。
```

3. 停 3 秒。**标记 M2-1**。
4. 点发送，等待完成。回复中出现 16.3 秒和 16.5 秒两帧时，停 5 秒。**标记 M2-2**。
5. 打开更新后的 `花字对照.md`，停 4 秒。**标记 M2-3**。结束录制。

### S3 只返工一镜（原始片段 `5-2-S3.mp4`）

1. 开始录制，回到同一任务。
2. 先打开 `成果/5-1/QA记录.md`，滚到待返工清单，停 3 秒。**标记 M3-1**。
3. 粘贴（原样）：

```text
现在只返工一个镜头：成果/5-1/QA记录.md 待返工清单里最严重的那一镜。
请按清单里的问题改这一镜的 H3 提示词，用 autodl-app-instance 开机、minimax-h3 只重新生成这一镜，下载核对后立刻关机，开关机时间和费用写进 成果/5-2/返工记录.md。
替换进成片时，其他镜头一律不动：替换前后对其他镜头的文件算一次校验值，写进返工记录，证明它们没被重新生成或改动。导出最终版 成果/5-2/成片.mp4，用 capsule-cinema 的质量检查再跑一遍，结果补进返工记录。
```

4. 停 3 秒。**标记 M3-2**。
5. 点发送。出现开机、关机完成时分别 **标记 M3-3**、**M3-4**。等待完成。
6. 打开 `返工记录.md`，停在提示词修改前后 4 秒（**标记 M3-5**），再停在校验值对比表 5 秒（**标记 M3-6**）。
7. 结束录制。

### S4 控制台确认关机（原始片段 `5-2-S4.mp4`）

同 5-1 的 S3。**标记 M4-1**。

### S5 存配方（原始片段 `5-2-S5.mp4`）

1. 开始录制，回到同一任务。
2. 粘贴（原样）：

```text
这条短剧的做法我满意了。请用 capsule-cinema 技能，参考 成果/5-2/成片.mp4 和本次的分镜、H3 提示词、花字参数、返工记录，整理一份“AI 短剧”视频配方草稿。
配方只保存可复用的方法：8 镜结构和每镜时长、景别运镜规则、校准镜头先行、H3 提示词写法、代码动效花字样式、质量检查项、返工经验。不要保存这一期的故事、台词、角色名、Token 或临时文件。
先告诉我准备保存哪些内容，我确认后再写入配方。另存一份人能读的说明到 成果/5-2/配方说明.md。
```

3. 停 3 秒。**标记 M5-1**。
4. 点发送。它列出“准备保存的内容”清单后，停 5 秒。**标记 M5-2**。
5. 检查清单里没有本期台词、“阿夏”名字、Token、临时路径。没有就粘贴下面这句并发送（有则先粘贴“清单里去掉 <具体项>，其余确认。”，写进 report.md）：

```text
确认，按这个清单写入配方。
```

6. 等待完成。打开 `配方说明.md`，停 5 秒。**标记 M5-3**。结束录制。

### 剪辑素材（不录，终端生成）

```sh
cd "$WS"

  -map "[v]" -an 录屏方案/_work/5-2/初版-终版.mp4
```

（路径同上，改为仓库下绝对路径。）

## C. 分支

S1 后打开 `5-2-v2-16.3.png`、`5-2-v2-16.5.png`、`5-2-ref-16.5.png`：

- **主线**（录 S2）：16.3 秒那帧已经有“电量 0%”（出现过早），且花字不是黄色。实操 2 原样粘贴。
- **只错一项**：只出现过早、颜色已是黄色 → 删去实操 2 中“而且颜色是白色，原片是黄色带抖动”和“黄色，带抖动，”；只有颜色不对、时间正确 → 删去“第 6 镜花字出现在成片 16.0 秒，原片是 16.4 秒，”和“出现时间改为成片 16.4 秒，”。删改后的全文写进 report.md。
- **分支 B**（跳过 S2）：16.3 秒无字、16.5 秒有黄色花字。剪辑表镜头 7–8 换成分支 B 镜头。
- 出现了别的明显错误（字写错、标题卡用了非宋体等）：照实录下，写进 report.md，不临时追加指令。

S3 关机核对同 5-1 的 C 节（控制台仍在运行 → 录下、手动关机、用 5-1 的 10D 式镜头）。

## F. 验收
