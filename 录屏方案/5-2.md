# 5-2 用 HyperFrames 做花字模板，再把做法存成配方 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/5-2-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 6 分 – 7 分 |
| 前置产物 | `$WS/成果/3-1/`（拆解报告中第 3、6 镜花字参数）、`$WS/成果/5-1/`（初版成片、各镜、分镜、QA 记录） |
| 用到的素材 | `资料/爆款样片/镜头造梦师-外卖员穿越唐朝.mp4`（`$WS/资料/` = `录屏方案/演示素材/` 的副本） |
| 用到的技能 | hyperframes（核心 4 个技能，不用 Pro 功能）；autodl-app-instance、minimax-h3（只返工一镜）；capsule-cinema（质量门、单镜返工、保存配方） |
| 外部条件 | 同 5-1（AutoDL 实例、`~/.config/autodl.env`）；返工一镜预计 GPU 费用 1 元以内 |
| 这一段要教会 | ① 原理（讲义流程图：花字参数 → HTML/CSS 模板 → 逐帧渲染 → 替换 → 质量门 → 单镜返工 → 配方）；② 文字类镜头用代码做，做成可换字模板；③ 怎么核对花字时间：前后各抽一帧；④ 返工只动一镜，证明其他没动；⑤ 配方存方法不存内容 |

## 预期结果

- `成果/5-2/` 里：HyperFrames 项目、第 3 镜标题卡（1.5 秒，纯黑底，金色宋体“大唐 · 开元十年”逐字出现）、第 6 镜花字镜头（成片 16.4 秒弹出黄色抖动“电量 0%”）、替换花字后的成片、花字对照表、返工记录（含校验值、开关机时间、费用、QA 结果）、最终版成片、配方说明；Capsule Cinema 配方目录中新增“AI 短剧”配方。文件名由 Agent 决定。
- 核对点：原片花字在 16.4 秒出现，最容易被放到镜头起点 16.0 秒；颜色为黄色带抖动。只在真的出错时演示纠正，**不要诱导**。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

### S1 做两个动效镜头（原始片段 `5-2-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点“新建任务”，确认工作空间 `阿夏的AI片场`。
3. 粘贴（原样）：

```text
用 hyperframes 照 3-1 报告里的花字参数，给我的成片做代码动效镜头，不调用任何生成模型：第 3 镜标题卡“大唐 · 开元十年”，第 6 镜花字“电量 0%”，叠在 5-1 生成的第 6 镜画面上。样式和出现时间照原片。做成以后能换文字反复用的模板，渲染后替换进 5-1 的初版成片，再列一张表对比原片和我的版本：文字、样式、出现时间。放到 成果/5-2。
```

4. 停 3 秒。**标记 M1-1**。
5. 点发送。回复中出现 HyperFrames 预览或渲染进度时 **标记 M1-2**。等待完成，出现两个镜头的文件卡片时 **标记 M1-3**。
6. 打开第 3 镜标题卡，播放一遍。**标记 M1-4**。
7. 打开第 6 镜花字镜头，播放一遍。**标记 M1-5**。
8. 打开花字对照表，停 5 秒。**标记 M1-6**。结束录制。

### S1 后取帧（不录，终端）

```sh
cd "$WS/成果/5-2"
V2="<替换花字后的成片>.mp4"   # 换成 Agent 实际生成的文件名
for t in 16.3 16.5; do ffmpeg -y -ss $t -i "$V2" -frames:v 1 ~/5-2-v2-$t.png; done
ffmpeg -y -ss 16.5 -i "$WS/资料/爆款样片/镜头造梦师-外卖员穿越唐朝.mp4" -frames:v 1 ~/5-2-ref-16.5.png
```

（输出路径按 `实践手册.md` 改到 `录屏方案/_work/5-2/`。）

**此时按“C. 分支”判断是否录 S2。**

### S2 告诉它花字哪里不对（仅主线，原始片段 `5-2-S2.mp4`）

1. 开始录制，回到同一任务。
2. 粘贴（这段不在讲义里，讲义只教“前后各抽一帧、说清哪里不对”；如 C 节要求删去不符的半句，按删改后的文字粘贴）：

```text
第 6 镜的花字和原片对不上：现在成片 16.0 秒就出来了，原片是 16.4 秒；颜色是白色，原片是黄色带抖动。按拆解报告改过来，替换进成片，再抽 16.3 秒和 16.5 秒两帧给我看。
```

3. 停 3 秒。**标记 M2-1**。
4. 点发送，等待完成。回复中出现 16.3 秒和 16.5 秒两帧时，停 5 秒。**标记 M2-2**。
5. 打开更新后的花字对照表，停 4 秒。**标记 M2-3**。结束录制。

### S3 质检，只返工一镜（原始片段 `5-2-S3.mp4`）

1. 开始录制，回到同一任务。
2. 先打开 5-1 的 QA 记录，滚到待返工清单，停 3 秒。**标记 M3-1**。
3. 粘贴（原样）：

```text
用 capsule-cinema 给成片做一遍质量检查。然后只返工 5-1 待返工清单里最严重的那一镜：按清单改提示词，只重新生成这一镜，下载后立刻关机。替换时其他镜头一律不动，并证明它们没被改过。导出最终版成片，再质检一次，把返工改了什么、花了多少钱记下来。
```

4. 停 3 秒。**标记 M3-2**。
5. 点发送。出现开机、关机完成时分别 **标记 M3-3**、**M3-4**。等待完成。
6. 打开返工记录，停在提示词修改前后 4 秒（**标记 M3-5**），再停在“其他镜头没动”的证明（如校验值对比）5 秒（**标记 M3-6**）。
7. 打开质检记录，停在返工前后两次结果 4 秒。**标记 M3-7**。
7. 结束录制。

### S4 控制台确认关机（原始片段 `5-2-S4.mp4`）

同 5-1 的 S3。**标记 M4-1**。

### S5 存配方（原始片段 `5-2-S5.mp4`）

1. 开始录制，回到同一任务。
2. 粘贴（原样）：

```text
这条的做法我满意了。用 capsule-cinema 把这次的做法整理成一份配方：只存可复用的方法，比如镜头结构、校准镜头先行、提示词写法、花字样式、质检项和返工经验；这一期的故事、台词、角色名和任何密钥都不要存。先告诉我准备存哪些内容，我确认后再写入，另外给我一份人能看懂的配方说明。
```

3. 停 3 秒。**标记 M5-1**。
4. 点发送。它列出“准备保存的内容”清单后，停 5 秒。**标记 M5-2**。
5. 检查清单里没有本期台词、“阿夏”名字、Token、临时路径。没有就粘贴下面这句并发送（有则先粘贴“清单里去掉 <具体项>，其余确认。”，写进 report.md）：

```text
确认，按这个清单写入配方。
```

6. 等待完成。打开配方说明，停 5 秒。**标记 M5-3**。结束录制。

### 剪辑素材（不录，终端生成）

```sh
cd "$WS"

  -map "[v]" -an 录屏方案/_work/5-2/初版-终版.mp4
```

（路径同上，改为仓库下绝对路径。）

## C. 分支

S1 后打开 `5-2-v2-16.3.png`、`5-2-v2-16.5.png`、`5-2-ref-16.5.png`：

- **主线**（录 S2）：16.3 秒那帧已经有“电量 0%”（出现过早），且花字不是黄色。实操 2 原样粘贴。
- **只错一项**：只出现过早、颜色已是黄色 → 删去实操 2 中“；颜色是白色，原片是黄色带抖动”；只有颜色不对、时间正确 → 删去“现在成片 16.0 秒就出来了，原片是 16.4 秒；”。删改后的全文写进 report.md。
- **分支 B**（跳过 S2）：16.3 秒无字、16.5 秒有黄色花字。剪辑表镜头 7–8 换成分支 B 镜头。
- 出现了别的明显错误（字写错、标题卡用了非宋体等）：照实录下，写进 report.md，不临时追加指令。

S3 关机核对同 5-1 的 C 节（控制台仍在运行 → 录下、手动关机、用 5-1 的 10D 式镜头）。
