选题说明：第 1、2 期是排行榜配方擅长的“榜单”，素材都在实测笔记里；第 3 期来自账号档案的选题池，是剧情类，对这个配方是新题材，又没有素材，用来演示“标出来、先放下”。07 要用“新手做 AI 视频的 3 个坑”，这里不用，避免重复。完整做第 2 期（翻车），因为它和 4-1 那条（排名和费用）内容区别最大。

## 预期结果

- 3 份可审分镜，每期标出和配方不一样、需要拿主意的地方；第 3 期被标成“配方第一次碰到 / 缺素材”。
- `成果/4-2/` 里：第 2 期的成片、质检记录、交付包、渠道和花费说明。文件名由 Agent 决定。
- 写回清单：几条候选经验和冲突点；只写入你同意的 1 条，写完跑过配方校验。
- 常见偏差（出现了才纠正）：第 2 期分镜出现笔记里没有的缺点或数字；第 3 期没被标出来；写回清单里混进这一期的事实（模型名、价格、文案）。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

### S1 排选题，逐期出分镜（原始片段 `4-2-S1.mp4`）

1. 开始录制。WorkBuddy 首页停 2 秒，点“新建任务”，确认工作空间 `阿夏的AI片场`。
2. 点击输入框，粘贴（原样）：

```text
用“工具排行榜”配方排一组选题，一共 3 期：同样 10 秒，5 个 AI 视频模型各花多少钱；5 个 AI 视频模型最容易翻车的地方；赛博朋克城市系列 第 4 集。每期的素材是 前两期用资料里的阿夏实测笔记，第 3 期只有选题、没有素材。逐期给我看分镜，先不要生成图片、视频和配音，也不要调用任何计费接口。每期标出和配方不一样、需要我拿主意的地方，哪期的题材是这个配方第一次碰到的也标出来。
```

3. 停 3 秒。**标记 M1-1**。
4. 点发送，等待完成（加速）。打开第 1 期分镜，停 4 秒。**标记 M1-2**。
5. 打开第 2 期分镜，停在分镜表 5 秒（**标记 M1-3**），再停在“需要你拿主意”的标注 4 秒（**标记 M1-4**）。
6. 打开第 3 期分镜，停在“配方第一次碰到 / 缺素材”的标注 5 秒。**标记 M1-5**。
7. 在右侧预览区新标签页打开 `资料/阿夏实测笔记.md`，停在“缺点”列 4 秒。**标记 M1-6**。
8. 结束录制。

**此时按“C. 分支”检查分镜，决定是否录 S1b。**

### S1b 让它改第 2 期（仅主线，原始片段 `4-2-S1b.mp4`）

1. 开始录制，回到同一任务。粘贴 C 节对应的那句，停 3 秒。**标记 M1b-1**。
2. 发送，等待完成，打开更新后的第 2 期分镜，停在改过的那一镜 5 秒。**标记 M1b-2**。
3. 结束录制。

### S2 挑一期，做完、质检、交付（原始片段 `4-2-S2.mp4`）

1. 开始录制，回到同一任务。
2. 粘贴（原样）：

```text
做第 2 期，一期做完再做下一期。配方第一次碰到的题材，先试一个代表镜头给我看，我确认后再做整期。每期做完跑质检，有问题只返工那一镜，其他镜头和音频不动。每期单独一个交付包，放到 成果/4-2。最后告诉我每期用了哪些渠道、花了多少钱、返工了哪几镜。
```

3. 停 3 秒。**标记 M2-1**。
4. 点发送。**先问再花钱**：
   - 它在调用配音前报了渠道和预计费用、等你确认：停 3 秒（**标记 M2-2**），粘贴并发送“可以，按你报的费用做。”。
   - 它没报费用就要开始调用配音：点停止，粘贴并发送下面这句（不在讲义里），再按上一条确认：

```text
先告诉我这期配音用哪个渠道、大概花多少钱，我同意再做。
```

   - 它要调用图片或视频生成：先别同意，回一句“这期卡片和字幕用本地渲染，不调用图片和视频生成。”，照实写进 report.md。
5. 等待完成（加速）。回复里出现“渠道、花费、返工了哪几镜”的段落时停 4 秒。**标记 M2-3**。
6. 点第 2 期成片，在右侧预览播放前 8 秒后暂停。**标记 M2-4**。
7. 打开质检记录，停 4 秒（**标记 M2-5**）；在工作区文件列表展开 `成果/4-2/` 的交付包，停 3 秒（**标记 M2-6**）。
8. 结束录制。
9. 另在终端生成剪辑素材（不录）：

```sh
V1="$WS/成果/4-1/<阿夏版成片>.mp4"; V2="$WS/成果/4-2/<第 2 期成片>.mp4"   # 换成实际文件名
ffmpeg -y -i "$V1" -i "$V2" \
  -filter_complex "[0:v]scale=-2:900[a];[1:v]scale=-2:900[b];[a][b]hstack=inputs=2[v]" \
  -map "[v]" -t 8 录屏方案/_work/4-2/4-1期-第2期.mp4
```

### S3 把经验写回配方（原始片段 `4-2-S3.mp4`）

1. 开始录制，回到同一任务。
2. 粘贴（原样）：

```text
这几期里做得好的经验，挑出值得写进“工具排行榜”配方的，先列给我看，和配方原有规则冲突的地方标出来，我同意后再写。只写方法，不写这几期的事实、文案、素材和密钥。
```

3. 停 3 秒。**标记 M3-1**。
4. 点发送，等待它列出候选经验和冲突点。停在清单上 5 秒。**标记 M3-2**。
5. 按 C 节挑 1 条，粘贴并发送（`<k>` 换成实际序号，写进 report.md）：

```text
只写第 <k> 条，其他先不写。
```

6. 等待写入和配方校验完成。回复里出现“已写入 / 校验通过”一类说明时停 4 秒。**标记 M3-3**。
7. 结束录制。
8. 镜头外把写回后的“工具排行榜”配方复制一份到 `录屏方案/_work/4-2/配方备份/`（07 用）。

## C. 分支

只纠正真实出现的问题，**不要为了配合脚本去诱导或伪造错误**。

S1 后检查第 2 期分镜（翻车）：每个模型的“翻车点”都要能在实测笔记“缺点”列找到；第 3 期要被标成新题材或缺素材。

```sh
grep -rn -E "完全免费|一分钱不花|全网第一|最强|必翻车|一键(生成|出)大片" "$WS/成果/4-2" 2>/dev/null
```

| 检查 | S1b 追问（把 `<>` 换成原文） |
| --- | --- |
| 第 2 期有笔记里找不到的缺点或数字 | `第 2 期分镜里“<那句说法>”在我的实测笔记里找不到，笔记里写的是 <笔记原文>。改成笔记里能对上的说法，别的不动。` |
| 第 3 期没被标出来 | `第 3 期是剧情，和这个配方的榜单做法不一样，也没有素材，标出来，这期先不做。` |

- **主线**：任一项出现 → 录 S1b，剪辑用镜头 7–8。
- **分支 B**：第 2 期都对得上笔记、第 3 期已被标出 → 不录 S1b，剪辑用镜头 7B。

S2 质检：报告了问题并只返工了一镜 → 镜头 11 旁白按实际改；全过 → 用原旁白。

S3 写回清单：选**一条明显是做法、不含这一期事实**的（例如“缺点句控制在 12 个字以内，卡片停留够读完”“翻车类选题开头先放最惨的结果”，以实际为准）。

| 清单情况 | 怎么回 |
| --- | --- |
| 有干净的做法类经验 | `只写第 <k> 条，其他先不写。` |
| 某条混进了这一期的事实（模型名、价格、原文案） | `第 <j> 条是这期的内容，不是方法，不写。只写第 <k> 条，其他先不写。`（剪辑用镜头 14 的主线旁白） |
| 它标了和原有规则冲突 | 照实录，选不冲突的那条；镜头 14 旁白按实际说明冲突点 |

走了哪条、发了哪句、实际花费，写进 report.md。
