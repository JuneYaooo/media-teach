# 4-2 用 Hypit 克隆爆款工作流，批量出变体 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/4-2-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 5 分 30 秒 – 6 分 30 秒 |
| 前置产物 | `$WS/成果/4-1/` 里的阿夏版脚本 |
| 用到的素材 | `资料/爆款样片/AI工具铺子-AI视频工具排行榜.mp4`、同名 `.srt` |
| 用到的技能 | hypit（Hypit 技能 + `@hypit/hypit` 命令行） |
| 这一段要教会 | ① 克隆的是“画面跟着哪个词走”的工作流，不是逐帧照抄；② 代码视频路线不调用生成模型；③ 原作者水印必须换掉；④ 工作流做好后，变体只改一处 |

## 预期结果

- `成果/4-2/` 里：Hypit 工作流源文件、第一版成片、变体 A、变体 B、核对记录。文件名由 Agent 决定。
- 设计中预期的错误：克隆出的成片左上角仍是 `@AI工具铺子` 水印（设计文档第八节）。
- 不调用任何视频或图片生成模型；唯一可能的费用是配音。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/阿夏的AI片场
rm -rf "$WS/成果/4-2"
[ -d "$WS/成果/4-1" ] || cp -R "$WS/参考结果/4-1" "$WS/成果/4-1"
mkdir -p 录屏方案/_work/4-2/raw
```

- 录前在终端确认工具可用（不录）：`hypit version`、`node -v`（≥22）、`ffmpeg -version`。
- 录前确认一项语音服务已在 Hypit 中配置并试跑通过（试跑时选定，写进 report.md）。WhisperX 用本地或托管均可，提前准备好，避免录制中安装。
- WorkBuddy：关闭预览标签页；任务列表只留本课；确认 hypit 技能已启用。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

### S1 提交克隆任务（原始片段 `4-2-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点“新建任务”，确认工作空间 `阿夏的AI片场`。
3. 点击输入框，粘贴（原样）：

```text
请用 hypit 技能，参考 AI工具铺子 那条排行榜样片，克隆它的工作流，内容换成 4-1 写好的阿夏版脚本。
这条走代码视频，只用卡片、字幕和动效，不调用任何视频或图片生成模型。动手前先说说你对参考视频的理解：字幕和卡片是跟着哪个词出现的。
配音用我已经配好的语音服务，没有就先停下来问我。账号标识用 @阿夏的AI片场。做完放到 成果/4-2，告诉我用了哪些服务、花了多少钱。
```

4. 停 3 秒。**标记 M1-1**。
5. 点发送。回复里出现 Hypit 对参考视频的理解（如“排行榜卡片在说到名次时切换”）时，停 4 秒，**标记 M1-2**。
6. 如果它询问语音服务或费用，点击输入框粘贴下面这句（`<服务名>` 换成试跑时选定的服务，写进 report.md），**标记 M1-3**：

```text
配音用已经配置好的 <服务名>。代码视频路线，不要调用视频或图片生成模型。按你报的费用执行。
```

7. 等待生成完成。出现成片文件卡片时 **标记 M1-4**。回复里出现“用了哪些服务、费用”的段落时停 3 秒，**标记 M1-5**。结束录制。

### S2 看第一版成片（原始片段 `4-2-S2.mp4`）

1. 开始录制。点击第一版成片的文件卡片，在右侧预览播放。
2. 播放到第 1 秒暂停，停 4 秒（左上角水印可见）。**标记 M2-1**。
3. 继续播放到第 20 秒（第 1 名揭晓）暂停 3 秒。**标记 M2-2**。
4. 结束录制。
5. 另在终端导出原片对应帧备用（不录）：

```sh
ffmpeg -y -ss 1 -i "$WS/资料/爆款样片/AI工具铺子-AI视频工具排行榜.mp4" -frames:v 1 录屏方案/_work/4-2/ref-1s.png
V1="$WS/成果/4-2/<第一版成片>.mp4"   # 换成 Agent 实际生成的文件名
ffmpeg -y -ss 1 -i "$V1" -frames:v 1 录屏方案/_work/4-2/v1-1s.png
```

**此时按“C. 分支”判断是否录 S3–S4。**

### S3 换水印、核对字幕（仅主线，原始片段 `4-2-S3.mp4`）

1. 开始录制，回到同一任务。
2. 粘贴（原样）：

```text
成片左上角还是原作者的 @AI工具铺子 水印，必须换成 @阿夏的AI片场，位置和大小不变，重新导出。
再逐句核对一下：字幕要和 4-1 脚本的口播一字不差，并且和配音对齐。核对结果记下来。
```

3. 停 3 秒。**标记 M3-1**。
4. 点发送，等待完成。**标记 M3-2**。结束录制。

### S4 看改后成片和核对记录（仅主线，原始片段 `4-2-S4.mp4`）

1. 开始录制。打开重新导出的成片，播放到第 1 秒暂停 4 秒。**标记 M4-1**。
2. 打开核对记录，停在字幕逐句核对结果 4 秒。**标记 M4-2**。
3. 结束录制。

### S5 出两个变体（原始片段 `4-2-S5.mp4`）

1. 开始录制。
2. 粘贴（原样）：

```text
在同一个工作流上出 2 个变体，其他内容都不动：
- 变体 A 只换开头钩子，改成“5 个 AI 视频模型我都测了，第一名 10 秒只要 3 毛钱”；
- 变体 B 只换配色和贴图：主色改成阿夏的灰蓝色，榜单旁加一个阿夏的卡通头像（短发、灰色卫衣，用简单图形画，不调生图模型）。
三条都检查一遍水印和字幕，最后给我一张三条视频的对比表。
```

3. 停 3 秒。**标记 M5-1**。
4. 点发送，等待完成。**标记 M5-2**。结束录制。

### S6 三条对比（原始片段 `4-2-S6.mp4`）

1. 开始录制。打开三条视频的对比表，停 5 秒。**标记 M6-1**。
2. 打开变体 A，播放前 3 秒后暂停。**标记 M6-2**。
3. 打开变体 B，播放到第 5 秒暂停 3 秒。**标记 M6-3**。
4. 结束录制。
5. 另在终端把三条成片拼成并排对照（不录，剪辑用）：

```sh
cd "$WS/成果/4-2"
ffmpeg -y -i <第一版>.mp4 -i <变体A>.mp4 -i <变体B>.mp4 \
  -filter_complex "[0:v]scale=-2:900[a];[1:v]scale=-2:900[b];[2:v]scale=-2:900[c];[a][b][c]hstack=inputs=3[v]" \
  -map "[v]" -t 8 ~/media-teach-4-2-三联.mp4
```

（输出路径按 `实践手册.md` 改到 `录屏方案/_work/4-2/`。）

## C. 分支

S2 结束后检查水印：

```sh
grep -rn "AI工具铺子" "$WS/成果/4-2" --include="*.svml" --include="*.svs" --include="*.html" --include="*.json" | grep -v "参考" | head
open 录屏方案/_work/4-2/v1-1s.png
```

- **主线**（录 S3、S4）：grep 有输出，或 `v1-1s.png` 左上角能看到 `@AI工具铺子`。
- **分支 B**（跳过 S3、S4）：两项都没有，水印已是 `@阿夏的AI片场`。剪辑表镜头 9–11 换成分支 B 镜头。S5 照常录；核对记录由 S5 生成。
- 第一版就调用了视频或图片生成模型（回复或费用说明里出现生成模型名称）：照实录下，在 report.md 写明，录完由人决定是否重录。
- 没有配置成功的语音服务、只出了字幕版：照实录，旁白镜头 7 改为“这次先出了字幕版，配音服务配好后再补。”，在 report.md 写明。
