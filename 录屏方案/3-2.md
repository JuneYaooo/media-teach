# 3-2 拆钩子、文案结构和评论区 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/3-2-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 4 分钟 – 5 分钟 |
| 前置产物 | 无（1-2 的“本周待拆”只在旁白里提到） |
| 用到的素材 | `资料/爆款样片/AI工具铺子-AI视频工具排行榜.mp4` 及同名 `.srt`、`AI工具铺子-标题封面.md`、`AI工具铺子-评论区.csv` |
| 这一段要教会 | ① 钩子时长以字幕时间轴为准；② 结构按段算起止和占比；③ 评论区要数条数，不凭印象；④ 分清“可以学”和“不能照抄” |

## 预期结果（标准答案）

- 钩子 0–2.5 秒（字幕第 1 条结束于 `00:00:02,500`）。
- 结构：钩子 0–2.5 / 快速过榜 2.5–15.0 / 转折 15.0–18.0 / 揭晓 18.0–22.0 / 引导互动 22.0–25.0。
- 评论 120 条：求教程 38、问下载和显卡 27、质疑恰饭 19、想看实测 15、其他 21；最高赞“显卡 8G 能跑吗”312 赞。
- 预期错误：钩子写成 0–3 秒；写“评论区大多在质疑广告”。

## B. 录制步骤

### S1 先看一遍原片（原始片段 `3-2-S1.mp4`）

1. 用 QuickTime 打开样片，窗口 720×1000 居中。
2. 开始录制，从头播放到 5 秒后暂停（钩子和第一个榜单卡片可见）。**标记 M1-1**（钩子字幕在画面上的时刻）。
3. 拖到 23 秒，停 3 秒（“评论区扣 1”）。**标记 M1-2**。
4. 关闭 QuickTime，结束录制。

### S2 提交拆解任务（原始片段 `3-2-S2.mp4`）

1. 开始录制。WorkBuddy 首页停 2 秒，点“新建任务”，确认工作空间 `阿夏的AI片场`。
2. 点击输入框，粘贴（原样）：

```text
请使用 social-account-doctor 技能的 crack（拆爆款）模式，拆这条对标爆款：AI工具铺子《免费的 AI 视频工具排行榜，第一名居然是它》。素材都在本地，不用联网：视频 资料/爆款样片/AI工具铺子-AI视频工具排行榜.mp4，字幕是同名 .srt，标题和封面在资料/爆款样片/AI工具铺子-标题封面.md，评论区在资料/爆款样片/AI工具铺子-评论区.csv。
请输出：
1. 4 维钩子（视觉、文字、口播、剧情），写清钩子从第几秒到第几秒，依据是哪一条字幕；
2. 结构骨架：每一段的起止秒、作用、台词，并算出各段占全片时长的比例；
3. 标题公式和封面公式；
4. 评论区：按主题分类，给出每类条数和占比，各举 2 条原话，说明观众真正关心什么；
5. 复用提示：哪些可以学（结构、节奏），哪些不能照抄（原句、工具名、水印）。
保存为成果/3-2/爆款拆解卡.md；评论分类明细另存成果/3-2/评论分类.csv，每条评论一行，加一列“主题”。钩子库这次不用存。
```

3. 停 3 秒。**标记 M2-1**。
4. 点发送，等待生成完成。出现 `爆款拆解卡.md` 卡片时，**标记 M2-2**。
5. 结束录制。

### S3 看拆解卡（原始片段 `3-2-S3.mp4`）

1. 开始录制。
2. 点击 `爆款拆解卡.md`，停在 4 维钩子部分 6 秒。**标记 M3-1**。
3. 滚动到结构骨架表，停 6 秒。**标记 M3-2**。
4. 滚动到评论区结论，停 6 秒。**标记 M3-3**。
5. 结束录制。

### S4 核对字幕和评论条数（原始片段 `3-2-S4.mp4`）

1. 开始录制。
2. 在工作区文件列表点开 `资料/爆款样片/AI工具铺子-AI视频工具排行榜.srt`，右侧预览停在第 1 条字幕 5 秒。**标记 M4-1**。
3. 在右侧预览区点“+”打开新标签页，点“打开终端”。粘贴并回车：

```text
python3 -c "import csv,collections;r=list(csv.DictReader(open('成果/3-2/评论分类.csv',encoding='utf-8-sig')));k=[c for c in r[0] if '主题' in c][0];c=collections.Counter(x[k] for x in r);print(len(r),'条');[print(n,t) for t,n in c.most_common()]"
```

4. 停 5 秒，让各主题条数在画面上。**标记 M4-2**。
5. 结束录制。

**此时按“C. 分支”判断是否录 S5。**

### S5 发纠正指令（仅主线，原始片段 `3-2-S5.mp4`）

1. 开始录制，回到同一任务。
2. 点击输入框，粘贴（原样）：

```text
我核对了两处：
1. 字幕第 1 条在 00:00:02,500 结束，钩子是 0–2.5 秒，不是 0–3 秒。结构表各段的起止和占比请按字幕时间轴重算；
2. 评论分类.csv 里“质疑广告/恰饭”只有 19 条（约 16%），不能写“评论区大多在质疑广告”。求教程 38 条，加上问怎么下载、要什么显卡 27 条，一共 65 条（约 54%），这才是观众最关心的。
请修改成果/3-2/爆款拆解卡.md，并在末尾加“这条爆款给阿夏的 3 个启发”，每条对应拆解卡里的一处证据。
```

3. 停 3 秒。**标记 M5-1**。
4. 点发送，等待完成。**标记 M5-2**。
5. 结束录制。

### S6 看改后拆解卡和复用提示（原始片段 `3-2-S6.mp4`）

1. 开始录制。
2. 打开（或刷新）`爆款拆解卡.md`，停在结构骨架表 5 秒。**标记 M6-1**。
3. 滚动到评论区结论，停 5 秒。**标记 M6-2**。
4. 滚动到“复用提示”，停 5 秒。**标记 M6-3**。
5. 滚动到“给阿夏的 3 个启发”，停 5 秒。**标记 M6-4**（分支 B 无此节时跳过）。
6. 结束录制。

## C. 分支

S3 结束后检查：

```sh
grep -n -E "0 ?[-–~到] ?3 ?(秒|s)|前 ?3 ?秒" "$WS/成果/3-2/爆款拆解卡.md"
grep -n -E "大多|大部分|主要是?.*(质疑|广告|恰饭)" "$WS/成果/3-2/爆款拆解卡.md"
```

并看 S4 终端输出：“质疑广告/恰饭”类是否 19 条。

- **主线**（录 S5）：钩子写成 0–3 秒（或结构首段到 3.0 秒）；或评论区结论说大多数 / 主要在质疑广告；或分类条数与标准答案差 3 条以上。
- **分支 B**（跳过 S5）：钩子 0–2.5 秒，评论结论指向“怎么用、能不能跑”，各类条数与标准答案相差不超过 2 条。剪辑表镜头 9–10 换成分支 B 镜头；S6 照录（无“3 个启发”一节时跳过 M6-4）。
- 只错其中一处：S5 提示词删掉没错的那一条再发送，旁白同步删改，在 report.md 写明。
- 分类口径不同（如把“扣 1”和“求教程”分开）导致条数不同：以实际为准改旁白里的数字，合并口径后仍对不上才走主线。
