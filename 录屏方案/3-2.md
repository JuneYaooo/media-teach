# 3-2 拆钩子和结构：爆款为什么让人看下去 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/3-2-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 4 分钟 – 5 分钟 |
| 前置产物 | 无（旁白说明：演示用自制样片代替 1-2 选出的真实爆款，避免在课程里传播他人作品） |
| 用到的素材 | `资料/爆款样片/AI工具铺子-AI视频工具排行榜.mp4` 及同名 `.srt`、`AI工具铺子-标题封面.md`、`AI工具铺子-评论区.csv` |
| 外部条件 | 多模态 Key 已配（看封面和开头） |
| 这一段要教会 | ① crack 怎么工作：钩子拆 4 层并给权重，≥0.5 是主驱动；② 骨架、封面、标题都落到公式词典编号；③ 评论要数条数；④ 一句话复用建议；⑤ 钩子库只在你说要时才存 |

## 演示参考值（核对用）

- 钩子 0–2.5 秒（字幕第 1 条结束于 `00:00:02,500`）。
- 结构：钩子 0–2.5 / 快速过榜 2.5–15.0 / 转折 15.0–18.0 / 揭晓 18.0–22.0 / 引导互动 22.0–25.0。
- 评论 120 条：求教程 38、问下载和显卡 27、质疑恰饭 19、想看实测 15、其他 21；最高赞“显卡 8G 能跑吗”312 赞。
- 常见偏差（出现了才纠正）：钩子写成 0–3 秒；“评论区大多在质疑广告”；4 层权重都 ≥0.5。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

### S1 先看一遍原片（原始片段 `3-2-S1.mp4`）

1. 用 QuickTime 打开样片，窗口 720×1000 居中。
2. 开始录制，从头播放到 5 秒后暂停。**标记 M1-1**（钩子字幕在画面上的时刻）。
3. 拖到 23 秒，停 3 秒（“评论区扣 1”）。**标记 M1-2**。
4. 关闭 QuickTime，结束录制。

### S2 提交拆解任务（原始片段 `3-2-S2.mp4`）

1. 开始录制。WorkBuddy 首页停 2 秒，点“新建任务”，确认工作空间 `阿夏的AI片场`。
2. 点击输入框，粘贴（原样）：

```text
用 social-account-doctor 拆一下这条爆款：资料里 AI工具铺子 的排行榜样片，评论在 同一个文件夹里的评论区文件。我想知道开头的钩子由哪几层组成、哪一层是主驱动，正文是什么骨架，封面和标题套的什么公式，评论区观众最想要什么，每类有多少条。最后用一句话告诉我最值得抄的一个动作。结果放到 成果/3-2。
```

3. 停 3 秒。**标记 M2-1**。
4. 点发送，等待生成完成。它问“要不要存进钩子库”时，停 4 秒，**标记 M2-2**。
5. 粘贴并发送（原样）：

```text
存。按主驱动分类，以后我拆别的爆款也往里加。
```

6. 等待完成，出现拆解卡文件卡片时，**标记 M2-3**。结束录制。

### S3 看拆解卡（原始片段 `3-2-S3.mp4`）

1. 开始录制。点击拆解卡。
2. 停在 4 层钩子和权重部分 6 秒。**标记 M3-1**。
3. 滚到骨架和分段时间，停 6 秒。**标记 M3-2**。
4. 滚到封面公式、标题公式、标签，停 5 秒。**标记 M3-3**。
5. 滚到评论需求，停 6 秒。**标记 M3-4**。
6. 滚到一句话复用建议，停 4 秒。**标记 M3-5**。
7. 结束录制。

### S4 演示核对（原始片段 `3-2-S4.mp4`）

1. 开始录制。
2. 在工作区文件列表点开 `资料/爆款样片/AI工具铺子-AI视频工具排行榜.srt`，右侧预览停在第 1 条字幕 5 秒。**标记 M4-1**。
3. 在右侧预览区打开终端，粘贴并回车（统计原始评论，不依赖 Agent 的产物）：

```text
python3 -c "import csv;r=list(csv.DictReader(open('资料/爆款样片/AI工具铺子-评论区.csv',encoding='utf-8-sig')));print(len(r),'条评论');print('含“教程”',sum('教程' in x['content'] for x in r));print('含“广告/恰饭”',sum(('广告' in x['content']) or ('恰饭' in x['content']) for x in r))"
```

4. 停 5 秒。**标记 M4-2**。
5. 结束录制。

**此时按“C. 分支”判断是否录 S5。**

### S5 指出问题（仅主线，原始片段 `3-2-S5.mp4`）

1. 开始录制，回到同一任务。
2. 粘贴实际问题对应的追问（见 C），停 3 秒。**标记 M5-1**。
3. 点发送，等待完成。打开更新后的拆解卡，停在被修改的部分 5 秒。**标记 M5-2**。
4. 结束录制。

## C. 分支（演示核对）

只纠正真实出现的问题，**不要为了配合脚本去诱导或伪造错误**。可以一次写多条，用分号连起来：

| 检查 | 出现问题时的追问 |
| --- | --- |
| 钩子起止和字幕对不上（如写成 0–3 秒） | `字幕第 1 条在 2.5 秒结束，钩子是 0–2.5 秒，各段时间按字幕重算。` |
| 评论结论没条数撑（如“大多在质疑广告”） | `“质疑广告/恰饭”只有 19 条（约 16%），不能说“大多”；按每类条数重写评论结论。` |
| 4 层权重有两层以上 ≥0.5，或没写主驱动 | `4 层钩子的权重请重新判断，只能有一层是主驱动，说清为什么是它。` |
| 骨架、封面、标题没落到公式编号 | `骨架、封面和标题请对应到公式词典里的编号。` |

- **主线**：上表任一项出现 → 录 S5，剪辑用镜头 9–10。
- **分支 B**：钩子 0–2.5 秒、评论结论有条数、只有一个主驱动、公式有编号 → 不录 S5，剪辑用镜头 9B–10B。
- 分类口径不同（如把“扣 1”和“求教程”合并）导致条数不同：以实际为准改旁白数字，在 report.md 写明。
