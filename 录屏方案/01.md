## 基本信息

| 项目 | 内容 |

| 输出文件 | `自媒体教程/录屏/01-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 4 分 15 秒 – 5 分 15 秒（安装等待已加速） |

## 预期结果

- 实操 2：social-account-doctor 由 WorkBuddy 按 `install.md` 装好，先说明目录再装，需要 Key 时停下来；“已安装”里能看到它，开关开着。对话里没有 Key 明文。
- 实操 3：它打开 `$DEMO_HOME`，说明能看到哪些字段（粉丝、作品列表、点赞评论收藏），或说明看不到的原因。**这个结论决定 1-1 用什么数据源，写进 report.md。**

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/阿夏的AI片场
REPO=/Users/june2/code/github/media-teach
# 演示工作空间：演示素材复制到 $WS/资料（全课程只在这里建一次；重录 01 时只清 成果/01）
mkdir -p "$WS/资料" "$WS/成果"
[ -f "$WS/资料/账号档案.md" ] || cp -R "$REPO/录屏方案/演示素材/." "$WS/资料/"
rm -rf "$WS/成果/01"
mkdir -p "$REPO/录屏方案/_work/01/raw"
```

`$DEMO_HOME`：录前由人提供一个可以公开展示的抖音主页链接（例如课程作者自己的账号），写进 report.md。没有提供时停下来问，不要自己找别人的账号。

在 WorkBuddy 里：

1. “专家·技能·连接器”→“技能”→“已安装”：如果已有 `social-account-doctor`，先卸载，并删除它上次装到的技能目录（路径以上次 Agent 说明的为准）。其他技能（benchmark-outlier-radar 等）不在本课装，各课录前自己处理。
2. 关闭右侧预览区所有标签页；左侧任务列表清空或收起。
3. 看图模型的 Key（实操 1）：录前在镜头外按讲义申请好，硅基流动或 Gemini 二选一，把 Key、接口地址、模型名三样存在本机安全位置；用的哪条路线写进 report.md（不写 Key）。**录制中不得出现在画面上**，申请过程不录。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

讲义实操 1（申请看图模型 Key）不录屏，剪辑时用镜头 4 的说明卡代替。

### S1 选择工作空间（原始片段 `01-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点左上角“新建任务”。鼠标慢慢移到输入框下方的工作空间按钮，点击。
3. 菜单里点“打开本地文件夹”。
4. 文件选择窗口里按 `Cmd+Shift+G`，粘贴下面的路径并回车，再点“打开”：

```text
~/WorkBuddy录制/阿夏的AI片场
```

5. 输入框下方显示 `阿夏的AI片场`，鼠标停在文件夹名旁 3 秒。**标记 M1-1**。
6. 结束录制。

### S2 让 WorkBuddy 安装 social-account-doctor（原始片段 `01-S2.mp4`、`01-S2b.mp4`）

1. 开始录制。点“新建任务”，确认工作空间为 `阿夏的AI片场`。
2. 点击输入框，粘贴（原样）：

```text
请帮我安装 social-account-doctor 技能，安装说明在：
https://raw.githubusercontent.com/JuneYaooo/social-account-doctor/main/docs/install.md
装之前先告诉我打算装到哪里，我确认后再装。需要填 API Key 时停下来，告诉我写到哪个文件的哪一行，我自己填，不要在对话里显示任何 Key。
```

3. 停 3 秒。**标记 M2-1**。
4. 发送，等它回复安装目录和理由。回复出现目录路径时 **标记 M2-2**，停 3 秒。
5. 点击输入框，粘贴并发送：

```text
确认，就装到这个目录。
```

6. 等待安装（不动鼠标）。WorkBuddy 请求执行命令时点“允许”；它说缺 Python 等环境、问要不要装时，回复“同意”。出现“请填写 Key / 写到 .env”一类提示时 **标记 M2-3**，停 3 秒。
7. **暂停录制**。镜头外打开它说的 `.env`，填好 `VIDEO_ANALYSIS_API_KEY`、`VIDEO_ANALYSIS_BASE_URL`、`VIDEO_ANALYSIS_MODEL_NAME`；用的是国内模型（硅基流动）时再加一行 `VIDEO_ANALYSIS_USE_VIDEO_URL=0`；`TIKHUB_API_KEY` 留空。保存、关闭编辑器。确认屏幕上没有 Key 残留。
8. 恢复录制（新片段 `01-S2b.mp4`）。如果它没有自己继续，在输入框粘贴并发送：

```text
Key 填好了，继续装完，检查一下能不能用。
```

9. 出现“安装完成”一类说明时 **标记 M2-4**。如提示需要重启：镜头外退出并重新打开 WorkBuddy。
10. 左侧栏点“专家·技能·连接器”→“技能”→“已安装”，找到 `social-account-doctor`，鼠标停在开关旁 3 秒。**标记 M2-5**。
11. 结束录制。

### S3 确认能打开平台网页（原始片段 `01-S3.mp4`）

1. 开始录制。点“新建任务”，确认工作空间为 `阿夏的AI片场`。
2. 点击输入框，粘贴（把 `<你的主页链接>` 换成 `$DEMO_HOME` 的实际链接，其余原样）：

```text
打开 <你的主页链接>，告诉我你能看到哪些信息：粉丝数、作品列表、每条作品的点赞评论收藏。看不到的说明原因，不要猜。
```

3. 停 3 秒。**标记 M3-1**。
4. 发送。它打开网页时 **标记 M3-2**。等待完成，回复列出能看到的字段时 **标记 M3-3**，停 4 秒。
5. 结束录制。把结论（能看到哪些字段 / 看不到的原因）写进 report.md 的“浏览器能力”一栏。

> 画面里出现网页时保持整页，不放大头像和作品画面。如果网页要求登录：不登录，照实录下它的说明。

### S4 第一个技能任务：账号定位（原始片段 `01-S4.mp4`）

1. 开始录制。在同一任务里点击输入框，粘贴（原样）：

```text
用 social-account-doctor 看一下我的账号：资料文件夹里的账号档案和作品数据。用一句话帮我写出账号定位：做什么内容、什么形式、给谁看、和同类比有什么不一样。数字和判断都要能在主页上找到，看不到的标出来。结果放到 成果/01。
```

> 与讲义实操 4 的区别：演示账号没有真实主页，`<你的主页链接>` 换成了“资料文件夹里的账号档案和作品数据”。

2. 停 3 秒。**标记 M4-1**。
3. 发送，等待完成。回复里出现读取技能的提示时 **标记 M4-2**；出现文件卡片时 **标记 M4-3**。
4. 点开文件，停在定位那一句 4 秒。**标记 M4-4**。
5. 结束录制。

### S5 核对定位（原始片段 `01-S5.mp4`）

1. 在 Finder 打开 `$WS/资料/账号档案.md`（用任一 Markdown 预览，窗口 1440×900）。开始录制。
2. 停在账号定位、内容类型那几行 4 秒。**标记 M5-1**。
3. 切到 Finder，打开 `$WS/成果/01/`，选中定位文件，停 3 秒。**标记 M5-2**。
4. 结束录制。

**此时按“C. 分支”判断是否录 S6。**

### S6 纠正（仅主线，原始片段 `01-S6.mp4`）

1. 开始录制，回到 S4 的任务。按 C 节模板写一句纠正，粘贴，停 3 秒。**标记 M6-1**。
2. 发送，等待完成。打开更新后的文件，停在改动处 4 秒。**标记 M6-2**。
3. 结束录制。

## C. 分支

S4 结束后对照账号档案读定位那一句：

```sh
F=$(ls -t "$WS/成果/01/"*.md | head -1)
cat "$F"
grep -n -E "定位|内容类型|作品类型|粉丝" "$WS/资料/账号档案.md" | head
```

- **主线（录 S6）**：满足任一条：
  - 定位里有账号档案和作品数据里找不到的说法（例如写了没做过的内容类型、编了受众数据）；
  - 粉丝数写成 6,240（那是累计新增关注，没扣 440 个取关），或其他数字与资料不符；
  - 没有标出“看不到”的部分，却给出了需要后台数据才能下的判断。

  纠正模板（按实际问题选一句）：
  - “定位里说我做 <X>，资料里找不到这类作品，请只按资料里有的内容写，没依据的删掉。”
  - “粉丝写的是 6,240，资料里粉丝是 5,800，6,240 是累计新增关注，没扣取关。请改正，并写清数字来自哪个文件。”
- **分支 B（跳过 S6）**：定位每一处都能在资料里找到。剪辑表镜头 16–17 换成 16B–17B。
