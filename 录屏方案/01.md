# 01 入门：装好技能，配好 Key — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/01-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 4 分 30 秒 – 5 分 30 秒（安装等待已加速） |
| 前置产物 | 无 |
| 用到的素材 | `$WS/资料/账号档案.md`、`$WS/资料/自己账号-作品数据.csv`（演示账号的资料，实操 4 用）；benchmark-outlier-radar 的 GitHub ZIP；social-account-doctor 的安装说明链接；`$DEMO_HOME`（实操 3 用的公开抖音主页，见 A 节） |
| 这一段要教会 | ① 技能是什么、WorkBuddy 怎么用技能（流程图）；② 选自己的文件夹为工作空间；③ 检查环境；④ 两种装技能的方法；⑤ 多模态 Key 自己填进 `.env`，不进对话；⑥ 确认 WorkBuddy 能打开平台网页；⑦ 第一个技能任务：账号定位一句话，并核对 |

## 预期结果

- 环境检查表：Python、Node.js、ffmpeg、git 四行，每行有实际版本号。
- benchmark-outlier-radar 通过“上传技能”装好；social-account-doctor 由 WorkBuddy 按 `install.md` 装好，先说明目录再装，需要 Key 时停下来。
- 实操 3：它打开 `$DEMO_HOME`，说明能看到哪些字段（粉丝、作品列表、点赞评论收藏），或说明看不到的原因。**这个结论决定 1-1 用什么数据源，写进 report.md。**
- 实操 4：`成果/01/` 里有一句账号定位，内容能在账号档案和作品数据里找到依据（AI 短片 + AI 视频工具教程，面向想学 AI 视频的新手一类）。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/阿夏的AI片场
REPO=/Users/june2/code/github/media-teach
# 演示工作空间：演示素材复制到 $WS/资料（全课程只在这里建一次；重录 01 时只清 成果/01）
mkdir -p "$WS/资料" "$WS/成果"
[ -f "$WS/资料/账号档案.md" ] || cp -R "$REPO/录屏方案/演示素材/." "$WS/资料/"
rm -rf "$WS/成果/01"
mkdir -p "$REPO/录屏方案/_work/01/raw" ~/WorkBuddy录制/技能包
# 提前下载 benchmark-outlier-radar 的 ZIP（镜头外完成，画面里只演示网页上的下载按钮）
curl -L -o ~/WorkBuddy录制/技能包/benchmark-outlier-radar-main.zip \
  https://github.com/JuneYaooo/benchmark-outlier-radar/archive/refs/heads/main.zip
```

`$DEMO_HOME`：录前由人提供一个可以公开展示的抖音主页链接（例如课程作者自己的账号），写进 report.md。没有提供时停下来问，不要自己找别人的账号。

在 WorkBuddy 里：

1. “专家·技能·连接器”→“技能”→“已安装”：如果已有 `benchmark-outlier-radar`、`social-account-doctor`，先卸载，并删除 social-account-doctor 上次装到的技能目录（路径以上次 Agent 说明的为准）。
2. 关闭右侧预览区所有标签页；左侧任务列表清空或收起。
3. 准备好多模态模型的 Key、接口地址、模型名，存在本机安全位置；**录制中不得出现在画面上**。

浏览器（S3 用）：无痕窗口，1440×900，打开 `https://github.com/JuneYaooo/benchmark-outlier-radar`，先最小化。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

### S1 选择工作空间（原始片段 `01-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点左上角“新建任务”。鼠标慢慢移到输入框下方的工作空间按钮，点击。
3. 菜单里点“打开本地文件夹”。
4. 文件选择窗口里按 `Cmd+Shift+G`，粘贴下面的路径并回车，再点“打开”：

```text
~/WorkBuddy录制/阿夏的AI片场
```

5. 输入框下方显示 `阿夏的AI片场`，鼠标停在文件夹名旁 3 秒。**标记 M1-1**。
6. 结束录制。

### S2 检查电脑环境（原始片段 `01-S2.mp4`）

1. 开始录制。在同一任务里点击输入框，粘贴（原样）：

```text
帮我检查一下这台电脑的 Python、Node.js、ffmpeg 和 git 装没装、版本够不够（Python 要 3.10 以上，Node.js 要 22 以上）。列个表给我看，缺的先别装，告诉我怎么装就行。
```

2. 停 3 秒。**标记 M2-1**。
3. 发送。WorkBuddy 请求执行命令时点“允许”。回复里出现版本表时 **标记 M2-2**。
4. 停 3 秒，结束录制。

### S3 网页下载技能包（原始片段 `01-S3.mp4`）

1. 切到浏览器（benchmark-outlier-radar 仓库页）。开始录制，停 2 秒。
2. 点绿色“Code”按钮，鼠标停在“Download ZIP”上 3 秒。**标记 M3-1**。（不点击；ZIP 已在录前下载好。）
3. 按 Esc 收起菜单，结束录制。

### S4 上传技能（原始片段 `01-S4.mp4`）

1. 切回 WorkBuddy。开始录制。
2. 左侧栏点“专家·技能·连接器”，再点顶部“技能”。停 2 秒。
3. 点右上角“添加技能”→“上传技能”。
4. 文件选择窗口按 `Cmd+Shift+G`，粘贴下面的路径并回车，点“打开”：

```text
~/WorkBuddy录制/技能包/benchmark-outlier-radar-main.zip
```

5. 等检测结果出现，停 4 秒。**标记 M4-1**。
6. 点安装 / 确认。
7. 点“已安装”，找到 `benchmark-outlier-radar`，鼠标停在开关旁 3 秒。**标记 M4-2**。
8. 结束录制。

> 如果上传后提示找不到 `SKILL.md`（GitHub ZIP 多了一层文件夹），停止录制：镜头外解压后把里面的文件夹重新压缩（根目录直接是 `SKILL.md`），用新文件重录 S4，并在 report.md 记一句，交人决定是否补进讲义。

### S5 让 WorkBuddy 安装 social-account-doctor（原始片段 `01-S5.mp4`、`01-S5b.mp4`）

1. 开始录制。点“新建任务”，确认工作空间为 `阿夏的AI片场`。
2. 点击输入框，粘贴（原样）：

```text
请帮我安装 social-account-doctor 技能，安装说明在：
https://raw.githubusercontent.com/JuneYaooo/social-account-doctor/main/docs/install.md
装之前先告诉我打算装到哪里，我确认后再装。需要填 API Key 时停下来，告诉我写到哪个文件的哪一行，我自己填，不要在对话里显示任何 Key。
```

3. 停 3 秒。**标记 M5-1**。
4. 发送，等它回复安装目录和理由。回复出现目录路径时 **标记 M5-2**，停 3 秒。
5. 点击输入框，粘贴并发送：

```text
确认，就装到这个目录。
```

6. 等待安装（不动鼠标）。WorkBuddy 请求执行命令时点“允许”。出现“请填写 Key / 写到 .env”一类提示时 **标记 M5-3**，停 3 秒。
7. **暂停录制**。镜头外打开它说的 `.env`，填好 `VIDEO_ANALYSIS_API_KEY`、`VIDEO_ANALYSIS_BASE_URL`、`VIDEO_ANALYSIS_MODEL_NAME`，保存、关闭编辑器。确认屏幕上没有 Key 残留。
8. 恢复录制（新片段 `01-S5b.mp4`）。如果它没有自己继续，在输入框粘贴并发送“Key 已经填好了，请继续安装并检查是否装好。”
9. 出现“安装完成”一类说明时 **标记 M5-4**。如提示需要重启：镜头外退出并重新打开 WorkBuddy。
10. 进入“技能”→“已安装”，找到 `social-account-doctor`，鼠标停在开关旁 3 秒。**标记 M5-5**。
11. 结束录制。

### S6 确认能打开平台网页（原始片段 `01-S6.mp4`）

1. 开始录制。点“新建任务”，确认工作空间为 `阿夏的AI片场`。
2. 点击输入框，粘贴（把 `<你的主页链接>` 换成 `$DEMO_HOME` 的实际链接，其余原样）：

```text
打开 <你的主页链接>，告诉我你能看到哪些信息：粉丝数、作品列表、每条作品的点赞评论收藏。看不到的说明原因，不要猜。
```

3. 停 3 秒。**标记 M6-1**。
4. 发送。它打开网页时 **标记 M6-2**。等待完成，回复列出能看到的字段时 **标记 M6-3**，停 4 秒。
5. 结束录制。把结论（能看到哪些字段 / 看不到的原因）写进 report.md 的“浏览器能力”一栏。

> 画面里出现网页时保持整页，不放大头像和作品画面。如果网页要求登录：不登录，照实录下它的说明。

### S7 第一个技能任务：账号定位（原始片段 `01-S7.mp4`）

1. 开始录制。在同一任务里点击输入框，粘贴（原样）：

```text
用 social-account-doctor 看一下我的账号：资料文件夹里的账号档案和作品数据。用一句话帮我写出账号定位：做什么内容、什么形式、给谁看、和同类比有什么不一样。数字和判断都要能在主页上找到，看不到的标出来。结果放到 成果/01。
```

> 与讲义实操 4 的区别：演示账号没有真实主页，`<你的主页链接>` 换成了“资料文件夹里的账号档案和作品数据”。

2. 停 3 秒。**标记 M7-1**。
3. 发送，等待完成。回复里出现读取技能的提示时 **标记 M7-2**；出现文件卡片时 **标记 M7-3**。
4. 点开文件，停在定位那一句 4 秒。**标记 M7-4**。
5. 结束录制。

### S8 核对定位（原始片段 `01-S8.mp4`）

1. 在 Finder 打开 `$WS/资料/账号档案.md`（用任一 Markdown 预览，窗口 1440×900）。开始录制。
2. 停在账号定位、内容类型那几行 4 秒。**标记 M8-1**。
3. 切到 Finder，打开 `$WS/成果/01/`，选中定位文件，停 3 秒。**标记 M8-2**。
4. 结束录制。

**此时按“C. 分支”判断是否录 S9。**

### S9 纠正（仅主线，原始片段 `01-S9.mp4`）

1. 开始录制，回到 S7 的任务。按 C 节模板写一句纠正，粘贴，停 3 秒。**标记 M9-1**。
2. 发送，等待完成。打开更新后的文件，停在改动处 4 秒。**标记 M9-2**。
3. 结束录制。

## C. 分支

S7 结束后对照账号档案读定位那一句：

```sh
F=$(ls -t "$WS/成果/01/"*.md | head -1)
cat "$F"
grep -n -E "定位|内容类型|作品类型|粉丝" "$WS/资料/账号档案.md" | head
```

- **主线（录 S9）**：满足任一条：
  - 定位里有账号档案和作品数据里找不到的说法（例如写了没做过的内容类型、编了受众数据）；
  - 粉丝数写成 6,240（那是累计新增关注，没扣 440 个取关），或其他数字与资料不符；
  - 没有标出“看不到”的部分，却给出了需要后台数据才能下的判断。

  纠正模板（按实际问题选一句）：
  - “定位里说我做 <X>，资料里找不到这类作品，请只按资料里有的内容写，没依据的删掉。”
  - “粉丝写的是 6,240，资料里粉丝是 5,800，6,240 是累计新增关注，没扣取关。请改正，并写清数字来自哪个文件。”
- **分支 B（跳过 S9）**：定位每一处都能在资料里找到。剪辑表镜头 16–17 换成 16B–17B。
