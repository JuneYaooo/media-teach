# 1-1 扫同赛道，筛出真对标 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `AI视频教程/录屏/1-1-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 2 分 45 秒 – 3 分 45 秒（整体规划写约 5 分钟；按本段旁白量实际约 3 分钟，以完整讲清为准，不为凑时长拖慢） |
| 前置产物 | 01 已装好 social-account-doctor（无文件依赖） |
| 用到的素材 | `资料/候选对标/候选对标-账号概况.csv`、`资料/候选对标/候选对标-近期作品.csv`、`资料/账号档案.md`、`资料/自己账号-作品数据.csv` |
| 这一段要教会 | ① 真对标看四个维度：赛道、内容形态、粉丝量级、更新节奏；② 离线数据要在提示词里说清“不联网搜索”，并要求标完整度；③ 识别“关键词像、内容不像”的干扰项；④ 每条理由都要能回到表里找到原值 |

**本段不演示 MediaCrawler 或任何采集操作。** 画面和旁白都不出现采集工具。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/阿夏的AI片场
rm -rf "$WS/成果/1-1"
mkdir -p 录屏方案/_work/1-1/raw
```

在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表只留本课或收起；确认 `social-account-doctor` 在“已安装”中开启；确认统一模型。

表格软件（S3 用）：用 Numbers（没有就 Excel）预先打开 `$WS/资料/候选对标/候选对标-账号概况.csv`，窗口 1440×900，列宽调到能看全 `account`、`followers`、`posts_per_week`、`main_content` 四列，然后最小化。

## B. 录制步骤

### S1 提交找对标任务（原始片段 `1-1-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点“新建任务”，确认输入框下方显示 `阿夏的AI片场`。
3. 点击输入框，粘贴（原样）：

```text
当前工作空间：阿夏的AI片场。
请使用 social-account-doctor 技能的“找对标”流程，帮“阿夏的AI片场”从候选账号里筛出真对标。
本次不联网搜索，候选数据已提供：资料/候选对标/候选对标-账号概况.csv 和 资料/候选对标/候选对标-近期作品.csv。阿夏的情况见 资料/账号档案.md 和 资料/自己账号-作品数据.csv。这次没有封面图，不做封面和画面判断。
逐个判断 4 个候选是不是真对标，从赛道、内容形态、粉丝量级、更新节奏四方面写理由，每条理由注明来自哪个文件的哪一列。选出 2–3 个真对标，每个写一条“阿夏最值得学的一点”；排除的写清排除原因。
按技能规则在报告开头标注完整度，说明本次没有做平台搜索和多模态分析。
保存到 成果/1-1/对标清单.md。
```

4. 停 3 秒。**标记 M1-1**。
5. 发送。回复里出现“读取技能 / 使用 social-account-doctor”一类提示时 **标记 M1-2**。
6. 等待完成。出现 `对标清单.md` 文件卡片时 **标记 M1-3**。
7. 停 2 秒，结束录制。

> 如果 Agent 回复“需要 TikHub Key / 需要先搜索”而没有继续：这一步重录前先检查提示词是否粘贴完整；完整的话照实记录，在同一任务里粘贴“候选数据已经在资料里，本次不搜索，直接用这两个 CSV 判断。”继续，并写进 report.md。

### S2 看对标清单（原始片段 `1-1-S2.mp4`）

1. 开始录制。点击 `对标清单.md` 文件卡片，右侧预览打开。
2. 停在报告开头完整度标注 4 秒。**标记 M2-1**。
3. 滚动到真对标部分，停在三个对标的表格或段落 5 秒。**标记 M2-2**。
4. 滚动到写“AI美女日常”的位置（不论它被放在对标还是排除里），停 5 秒。**标记 M2-3**。
5. 结束录制。

### S3 回表格看原值（原始片段 `1-1-S3.mp4`）

1. 切到表格窗口。开始录制，停在表头 2 秒。
2. 点击“AI美女日常”那一行的 `main_content` 单元格，停 3 秒。**标记 M3-1**。
3. 依次点击同一行的 `followers`（520000）、`posts_per_week`（14）单元格，各停 2 秒。**标记 M3-2**。
4. 点击“镜头造梦师”那一行的 `followers`（42000），停 2 秒。**标记 M3-3**。
5. 关闭表格（不保存），结束录制。

**此时按“C. 分支”判断是否录 S4。**

### S4 纠正干扰项（仅主线，原始片段 `1-1-S4.mp4`）

1. 开始录制，回到 S1 的任务。点击输入框，粘贴（原样）：

```text
请复核“AI美女日常”：候选对标-账号概况.csv 里它的 main_content 是 AI 生成美女跳舞、换装，粉丝 52 万，每周更新 14 条；阿夏做的是 AI 叙事作品，粉丝 5,800。它标题里带“AI视频”“AI短片”只是关键词重合，不是同一种内容。请把它移到“排除”，理由引用 main_content、followers、posts_per_week 三列的原值。
再检查其余每条理由能不能在表里找到对应数据，找不到的删掉，或标成“推断”。更新 成果/1-1/对标清单.md。
```

2. 停 3 秒。**标记 M4-1**。
3. 发送，等待完成。
4. 打开更新后的 `对标清单.md`，滚到“排除”部分，停在“AI美女日常”的排除理由 5 秒。**标记 M4-2**。
5. 结束录制。

### S5 看“值得学的一点”（原始片段 `1-1-S5.mp4`）

1. 开始录制。在 `对标清单.md` 里滚到三个真对标的“值得学的一点”，停 5 秒。**标记 M5-1**。
2. 结束录制。

## C. 分支

S2 结束后检查清单：

```sh
F="$WS/成果/1-1/对标清单.md"
grep -n "AI美女日常" "$F"
grep -n -E "520,?000|52 ?万" "$F"
grep -n -E "(每周|posts_per_week).{0,8}14|14 ?条" "$F"
```

再打开文件看“AI美女日常”出现在哪个标题下面。

- **主线**（录 S4）：满足任一条——“AI美女日常”被列为对标；或被排除但理由里没有引用表中的原值（没有 520,000 / 52 万，也没有 14 条周更或 main_content 的内容描述），只写了“不太相关”“赛道不同”这类笼统说法。
- **分支 B**（跳过 S4）：“AI美女日常”被排除，理由引用了 main_content、粉丝量级、周更中的至少两项原值。剪辑表镜头 8–9 换成分支 B 镜头。
- 真对标选错（例如漏掉 AI工具铺子）：照实录，写进 report.md，录完由人决定是否补纠正。
- 报告开头没有完整度标注：不单独纠正，在镜头 5 的旁白后加一句“开头这里应该写清楚完整度”，并写进 report.md。
