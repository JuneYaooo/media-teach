# 6-2 账号限流排查 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `AI视频教程/录屏/6-2-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 4 分钟 – 5 分钟 |
| 前置产物 | 无 |
| 用到的素材 | `资料/审核样例/限流作品说明.md`、`资料/审核样例/限流通知截图.png` |
| 用到的技能 | self-media-compliance-review（01 课已安装） |
| 这一段要教会 | ① 从通知原文出发；② 每个原因写明证据来源；③ 平台规则和创作者经验分开，经验只是线索；④ 先整改再谈申诉，申诉成功率实事求是 |

## 预期结果

- 通知原文：“你的作品《当 AI 让她演古装》可能涉及侵犯他人肖像权，已限制推荐。如有异议可在 7 日内申诉。”
- 首要原因：AI 换脸使用某知名女演员肖像，标题含演员名（作品说明里写作“XX”）。
- 次要可能：10-08、10-09 连发 6 条、3 条画面相似，应标为“创作者经验 / 待验证”。
- 整改排在申诉之前；未授权使用真人脸时，申诉成功可能很低。
- 全程不出现真实演员姓名（素材里本来就没有）。

## B. 录制步骤

### S1 先看通知和作品说明（原始片段 `6-2-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 在工作区文件列表里点开 `资料/审核样例/限流通知截图.png`，右侧预览打开。停 5 秒。**标记 M1-1**。
3. 点开 `资料/审核样例/限流作品说明.md`，停在“怎么做的”一段（AI 换脸、标题写演员名）4 秒。**标记 M1-2**。
4. 滚动到“同期发布情况”（两天连发 6 条），停 4 秒。**标记 M1-3**。
5. 关闭两个预览标签，结束录制。

### S2 提交排查任务（原始片段 `6-2-S2.mp4`）

1. 开始录制。点左上角“新建任务”，确认输入框下方显示 `阿夏的AI片场`。
2. 点击输入框，粘贴（原样）：

```text
当前工作空间：阿夏的AI片场。
请使用 self-media-compliance-review 技能做账号风险排查。资料/审核样例/限流作品说明.md 记录了一条被限流的作品，资料/审核样例/限流通知截图.png 是后台通知。请：
1. 先逐字读出通知原文；
2. 列出这条作品被限制推荐的可能原因，按可能性从高到低排序，每条写明证据来自哪里：通知原文、作品说明、平台规则，还是创作者经验；
3. 平台规则和创作者经验分成两栏写，创作者经验只作排查线索，标“待验证”；
4. 给出整改动作（这条作品怎么处理、以后怎么避免）和申诉前要准备的材料清单。
报告保存到 成果/6-2/限流排查报告.md。报告里不要写出真实演员的姓名。
```

3. 停 3 秒。**标记 M2-1**。
4. 点发送，等待生成完成。出现 `限流排查报告.md` 文件卡片时，**标记 M2-2**。
5. 停 2 秒，结束录制。

### S3 读报告（原始片段 `6-2-S3.mp4`）

1. 开始录制。
2. 点击 `限流排查报告.md`，停在“通知原文”部分 4 秒。**标记 M3-1**。
3. 滚动到“可能原因”排序，停 5 秒。**标记 M3-2**。
4. 滚动到“平台规则 / 创作者经验”两栏，停在“连发相似内容”所在位置 5 秒。**标记 M3-3**。
5. 滚动到“整改动作”和“申诉材料清单”，停 5 秒。**标记 M3-4**。
6. 结束录制。

**此时按“C. 分支”判断是否录 S4。**

### S4 纠正（仅主线，原始片段 `6-2-S4.mp4`）

1. 开始录制，画面回到同一任务。
2. 点击输入框，粘贴（原样）：

```text
当前工作空间：阿夏的AI片场。
请修改 成果/6-2/限流排查报告.md：
1. 通知原文只提到“可能涉及侵犯他人肖像权”，所以肖像权是首要原因；
2. “两天连发 6 条、其中 3 条画面相似”没有通知或规则原文支撑，移到“创作者经验 / 待验证”，写清它为什么只是次要可能，以及怎么验证（比如看同期其他几条的播放有没有一起下降）；
3. 用 AI 换了知名演员的脸又没有授权，申诉成功的可能很低，请如实写明，并把“删除或下架这条作品、以后不再使用真人脸”放在申诉之前；
4. 另外写一份以后发布前用的自查清单，保存为 成果/6-2/肖像与换脸自查清单.md。
```

3. 停 3 秒。**标记 M4-1**。
4. 点发送，等待完成。
5. 打开更新后的报告，滚动到“创作者经验 / 待验证”，停 5 秒。**标记 M4-2**。
6. 滚动到整改与申诉部分，停 5 秒。**标记 M4-3**。
7. 点开 `肖像与换脸自查清单.md`，停 5 秒。**标记 M4-4**。
8. 结束录制。

### S4B 只生成自查清单（仅分支 B，原始片段 `6-2-S4B.mp4`）

报告已经写对时，不发纠正指令，只补自查清单。粘贴（原样）：

```text
当前工作空间：阿夏的AI片场。
请根据 成果/6-2/限流排查报告.md，写一份以后发布前用的肖像与换脸自查清单，保存为 成果/6-2/肖像与换脸自查清单.md。
```

发送、等待完成后点开清单，停 5 秒。**标记 M4B-1**。

## C. 分支

S3 结束后检查报告：

```sh
grep -n -E "连发|相似" "$WS/成果/6-2/限流排查报告.md"
grep -n -E "待验证|创作者经验" "$WS/成果/6-2/限流排查报告.md"
grep -n -E "申诉" "$WS/成果/6-2/限流排查报告.md"
```

- **主线**（录 S4）：满足任一条——“连发相似内容”写在平台规则一栏，或没有标“待验证”；它和肖像权并列第一；申诉建议没提成功率低，或申诉排在下架整改之前。
- **分支 B**（录 S4B，不录 S4）：肖像权排第一，连发相似明确标为创作者经验 / 待验证，整改在申诉之前且写明成功率低。剪辑时镜头 9–10 换成分支 B 镜头。
- **报告里出现了某个真实演员姓名**（Agent 自行联想）：这一条必须重录 S2，并在提示词后补一句“只用‘某知名女演员’指代”。不要把含真实姓名的画面剪进成片。
