# 6-1 成片发布前审核 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/6-1-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 5 分钟 – 6 分钟 |
| 前置产物 | `$WS/成果/5-2/` 里的最终版成片（文件名以实际为准） |
| 用到的素材 | `资料/发布资料/发布文案-草稿.md`、`资料/发布资料/制作记录.md`、5-2 成片 |
| 用到的技能 | self-media-compliance-review（01 课已安装） |
| 这一段要教会 | ① 审核范围不只是视频，标题、正文、话题、互动引导、BGM 都要审；② 每条风险必须有证据位置；③ 回到成片对应时间点亲眼确认；④ 导流是最高级，对照项不能误报；⑤ 改完必须复审 |

## 预期结果

按设计文档第十节，报告应出现：

| # | 风险点 | 预期等级 |
| --- | --- | --- |
| 1 | 标题“全网最强 AI 短剧，看完你也能月入过万” | High |
| 2 | 正文未声明“AI 生成” | High |
| 3 | “私信我领取全套提示词，加 V：axia_ai2026” | Blocker |
| 4 | 话题 #唐朝 #穿越 #AI视频 | Pass（对照项） |
| 5 | BGM 从音乐 App 下载、未购买授权 | High |
| 6 | 画面全部为 AI 原创角色 | Pass（对照项） |

另外很可能出现一条带视频时间点的画面风险（例如“00:00–00:03 首帧没有 AI 生成提示”）。这一条用来录“回到成片看画面”。复审后 #1、#2、#3 应降到 Pass 或 Low；#5 在成片音频没真正替换前，可能标“待核验”，这是正确结果，不是错误。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/阿夏的AI片场
rm -rf "$WS/成果/6-1"
# 5-2 成片缺失时：
ls "$WS/成果/5-2/"*.mp4 2>/dev/null || cp -R "$WS/参考结果/5-2" "$WS/成果/5-2"
mkdir -p 录屏方案/_work/6-1/raw
```

- 记下 5-2 成片的完整文件名，写入 report.md。S3 会用 QuickTime 打开它。
- 在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表清空或收起；确认模型为统一模型（README 3.4）。
- 确认 self-media-compliance-review 已安装且开关打开。
- 确认本机有 `ffmpeg`、`ffprobe`（技能抽帧要用）。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

### S1 提交审核任务（原始片段 `6-1-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点左上角“新建任务”。确认输入框下方显示 `阿夏的AI片场`。
3. 点击输入框，粘贴（原样）：

```text
请用 self-media-compliance-review 技能，帮我审一下阿夏准备发到抖音和小红书的这条 AI 短剧：5-2 做好的成片（没做的话用参考结果里的），连同发布文案和制作记录一起审。
画面、声音、字幕、标题、正文、话题、评论引导和 BGM 都要看。每条风险写清等级、证据在视频哪一秒或文案哪一句、怎么改；没审到的列为“待核验”，不要因为抽样看着没问题就判通过。平台规则和创作者经验分开写。报告放到 成果/6-1。
```

4. 停 3 秒。**标记 M1-1**。
5. 点发送。回复中出现抽帧 / 提取音轨等证据准备的提示时，**标记 M1-2**。
6. 等待生成完成。出现审核报告的文件卡片时，**标记 M1-3**。
7. 停 2 秒，结束录制。

### S2 读报告（原始片段 `6-1-S2.mp4`）

1. 开始录制。
2. 点击审核报告的文件卡片，右侧预览打开。停在报告开头“结论 / 最高风险”4 秒。**标记 M2-1**。
3. 滚动到“风险明细”表，停在“加 V：axia_ai2026”那一行 5 秒。**标记 M2-2**。
4. 继续停在标题“全网最强…月入过万”、正文未声明 AI、BGM 三行，每行至少 3 秒。**标记 M2-3**。
5. 找到带视频时间点的那一行（如“00:00–00:03 首帧”），停 4 秒。**标记 M2-4**。记下这个时间点，S3 要用。
6. 找到话题 #唐朝 #穿越 #AI视频 和“AI 原创角色”这两项的判定，停 4 秒。**标记 M2-5**（报告没单独列出对照项时，停在“待核验”或“已审范围”部分）。
7. 结束录制。

**此时按“C. 分支”判断是否录 S2b。**

### S2b 复核等级（仅分支 C，原始片段 `6-1-S2b.mp4`）

1. 开始录制，画面回到同一任务。
2. 点击输入框，粘贴（原样）：

```text
复核一下审核报告里的等级：“私信我领取全套提示词，加 V：axia_ai2026”是把人引到站外，应该是最高级 Blocker；话题 #唐朝 #穿越 #AI视频 和“画面全部为 AI 原创角色”没看到具体风险，不该判 Medium 或更高，真有问题请指出证据。改完在报告末尾写一段复核说明，列出改了什么、为什么。
```

3. 停 3 秒。**标记 M2b-1**。
4. 点发送，等待完成。
5. 打开更新后的报告，滚动到“复核说明”，停 5 秒。**标记 M2b-2**。
6. 结束录制。

### S3 回到成片看证据（原始片段 `6-1-S3.mp4`）

1. 在 Finder 里选中 A 节记下的 5-2 成片，右键 → 打开方式 → QuickTime Player，窗口调到 1440×900 左右，放在屏幕左上角。
2. 开始录制。停在第一帧 2 秒。
3. 把播放头拖到 S2 记下的时间点（例如 0 秒），暂停，停 5 秒。**标记 M3-1**。
4. 如果报告里的时间点是一段区间，从区间起点播放到终点，然后暂停。**标记 M3-2**。
5. 关闭 QuickTime（不保存），结束录制。

**注意**：如果画面和报告描述对不上（例如报告说 00:05 有某字样，画面上没有），照实录下来，在 report.md 写明，剪辑时用“分支 D”镜头。

### S4 修改并复审（原始片段 `6-1-S4.mp4`）

1. 开始录制，画面回到 WorkBuddy 同一任务。
2. 点击输入框，粘贴（原样）：

```text
按审核报告的建议改文案和制作记录，原文件别动，另存修改版：
1. 标题去掉“全网最强”和“月入过万”，给 3 个不夸大的备选；
2. 正文开头写明“本片画面和配音由 AI 生成，人物均为虚构”，发布清单里注明内容标注选“含有AI生成内容”；
3. 删掉“加 V”那句，换成不引导私信的互动问题；
4. BGM 换成平台音乐库或有商用授权的音乐，在制作记录里写明来源；
5. 报告如果提到画面缺 AI 生成提示，告诉我在哪一秒、加什么字。
改完用 self-media-compliance-review 复审一次，开头放一张修改前后的等级对照表。
```

3. 停 3 秒。**标记 M4-1**。
4. 点发送，等待生成完成。出现复审报告的文件卡片时，**标记 M4-2**。
5. 停 2 秒，结束录制。

### S5 看修改结果（原始片段 `6-1-S5.mp4`）

1. 开始录制。
2. 点击复审报告，停在开头的对照表 6 秒。**标记 M5-1**。
3. 点击修改版发布文案，停在新标题和正文开头的 AI 声明 5 秒。**标记 M5-2**。
4. 滚动到原来“加 V”所在位置（现在是互动问题），停 4 秒。**标记 M5-3**。
5. 结束录制。

## C. 分支

S2 结束后检查报告：

```sh
grep -n "axia_ai2026" "$WS/成果/6-1/"*.md
grep -n -E "Blocker" "$WS/成果/6-1/"*.md
grep -n -E "#唐朝|原创角色" "$WS/成果/6-1/"*.md
```

- **主线**（跳过 S2b）：“加 V”那一行是 Blocker，且 #4、#6 两个对照项没有被判成 Medium 或更高。
- **分支 C**（录 S2b）：“加 V”不是 Blocker，或者对照项被判成 Medium 及以上。剪辑时在镜头 7 后插入镜头 7C-1、7C-2。
- **报告没有带视频时间点的风险**：S3 改为拖到报告“已审证据”里列出的任意一个抽帧时间点（如开头 0 秒），旁白用镜头 8 的分支 B 版本。
- **复审后 #5 仍是 High 或“待核验”**：照实保留，旁白用镜头 13 的写法（已说明原因），不要再追加指令。

## F. 验收

- [ ] 输入框里的审核范围（成片、文案、制作记录）和“不要因为抽样看着没问题就判通过”被放大展示。
- [ ] “加 V：axia_ai2026”那一行和它的等级被红框标出；分支 C 时有复核前后对比。
- [ ] 标题极限词、未声明 AI、BGM 三项风险都在画面上出现。
- [ ] 有一段“报告时间点 ｜ 成片画面”的并排对照。
- [ ] 对照项（话题、AI 原创角色）被绿框展示。
- [ ] 复审对照表被放大，BGM 一项的“待核验 / 还差什么”被讲清。
- [ ] 画面里没有任何真实个人信息；`axia_ai2026` 是虚构的微信号，可以出现。
- [ ] 每个章节不短于 15 秒；没有无关会话、其他课标签页、弹窗。
- [ ] 时长在 5:00–6:00 之间。
