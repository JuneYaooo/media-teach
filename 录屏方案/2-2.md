# 2-2 单条诊断：这条为什么不爆 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/2-2-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 3 分 30 秒 – 4 分 30 秒 |
| 前置产物 | 无 |
| 用到的素材 | `资料/后台截图/赛博朋克重庆-作品数据.png`、`资料/自己账号-作品数据.csv`（ax-035） |
| 这一段要教会 | ① 先让 AI 把截图数字抄成表，核对后再分析；② 用漏斗找第一个掉得最厉害的地方；③ 改法只改一个变量，并写清验证指标 |

## 预期结果（标准答案）

- 截图数字：播放 380；封面点击率 2.3%；2 秒跳出率 61%；5 秒完播率 22%；完播率 4.1%；平均播放时长 3.2 秒；点赞 / 评论 / 分享 / 收藏 9 / 1 / 0 / 3；同类作品完播率参考 18%。
- 正确结论：主要卡在开头 2 秒（61% 跳出，平均只看 3.2 秒），不是发布时间。
- 预期错误：61% 与 4.1% 对调；3.2 秒读成 32 秒；把发布时间列为主因。

```sh
export WS=~/WorkBuddy录制/阿夏的AI片场
rm -rf "$WS/成果/2-2"

```

在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表清空或收起；确认模型为统一模型；确认 social-account-doctor 已开启。

## B. 录制步骤

### S1 先看一眼截图（原始片段 `2-2-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点“新建任务”，确认输入框下方显示 `阿夏的AI片场`。
3. 在工作区文件列表里点开 `资料/后台截图/赛博朋克重庆-作品数据.png`，右侧预览显示截图，停 5 秒。**标记 M1-1**。
4. 结束录制。

### S2 提交诊断任务（原始片段 `2-2-S2.mp4`）

1. 开始录制。
2. 点击输入框，粘贴（原样）：

```text
当前工作空间：阿夏的AI片场。
请使用 social-account-doctor 技能的诊断模式，看我这条为什么不爆：资料/后台截图/赛博朋克重庆-作品数据.png。作品信息：电影感短片，45 秒，标题“AI 生成的赛博朋克重庆，美到窒息”，2026-10-21 14:07 发布，明细见资料/自己账号-作品数据.csv 的 ax-035。
1. 先把截图里的每个数字逐项抄成一张表，一列“指标”，一列“截图原文”，看不清的写“看不清”，不要猜；
2. 再判断卡在哪一层：封面点击、开头留人、完播、互动，和截图里的同类参考值比；
3. 从封面、标题、开头 3 秒、发布时间、互动钩子逐项诊断；
4. 给出 3 个改法，每个改法写清楚下一条只改什么、看哪个数字验证。
本次只做第一层漏斗自检，不联网找对标，请在报告开头标注完整度。保存到成果/2-2/单条诊断.md。
```

3. 停 3 秒。**标记 M2-1**。
4. 点发送，等待生成完成。出现 `单条诊断.md` 文件卡片时，**标记 M2-2**。
5. 结束录制。

### S3 核对数字表（原始片段 `2-2-S3.mp4`）

1. 开始录制。
2. 点击 `单条诊断.md` 文件卡片，右侧预览打开，滚动到数字表，停 6 秒。**标记 M3-1**。
3. 在右侧预览区点“+”新标签页，打开截图 PNG；两个标签来回切换各停 3 秒，最后停在截图，**标记 M3-2**（若预览区支持分屏，改为左右并排）。
4. 回到报告，滚动到“卡在哪一层”的判断，停 5 秒。**标记 M3-3**。
5. 结束录制。

**此时按“C. 分支”判断是否录 S4。**

### S4 发纠正指令（仅主线，原始片段 `2-2-S4.mp4`）

1. 开始录制，画面回到 WorkBuddy 同一任务。
2. 点击输入框，粘贴（原样）：

```text
当前工作空间：阿夏的AI片场。
我对照截图核对了数字表，有抄错：截图上“2 秒跳出率”是 61%，“完播率”是 4.1%，“平均播放时长”是 3.2 秒（不是 32 秒）。请重新对照截图逐项抄一遍，凡是用到这几个数字的判断都重算：61% 的人 2 秒内就划走，平均只看 3.2 秒，说明问题首先在开头。发布时间如果没有数据支撑，不要列为主要原因。更新成果/2-2/单条诊断.md，在末尾写“修改记录”，列出改了哪些数字和结论。
```

3. 停 3 秒。**标记 M4-1**。
4. 点发送，等待完成。
5. 打开更新后的 `单条诊断.md`，停在数字表 5 秒。**标记 M4-2**。
6. 结束录制。

### S5 看改法（原始片段 `2-2-S5.mp4`）

1. 开始录制。
2. 滚动到“卡在哪一层”的结论，停 4 秒。**标记 M5-1**。
3. 滚动到 3 个改法，停 8 秒，让“只改什么”“看哪个数字”都在画面里。**标记 M5-2**。
4. 结束录制。

## C. 分支

S3 结束后检查：

```sh
grep -n -E "跳出" "$WS/成果/2-2/单条诊断.md" | head
grep -n -E "完播率" "$WS/成果/2-2/单条诊断.md" | head
grep -n -E "32 ?秒|发布时间.*(主要|首要)" "$WS/成果/2-2/单条诊断.md"
```

- **主线**（录 S4）：满足任一条——数字表里 2 秒跳出率不是 61% 或完播率不是 4.1%；出现“32 秒”；把发布时间列为主要原因。
- **分支 B**（跳过 S4）：数字表全部正确，卡点判断为开头 2 秒。剪辑表镜头 7–8 换成分支 B 镜头。
- 截图其他数字读错：照实录，纠正指令换成实际读错的那几项，在 report.md 写明。
