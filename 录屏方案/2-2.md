# 2-2 单条诊断：这条为什么不爆 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/2-2-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 3 分 30 秒 – 4 分 30 秒 |
| 前置产物 | 无 |
| 用到的素材 | `资料/后台截图/赛博朋克重庆-作品数据.png`（演示账号的一条作品） |
| 外部条件 | 多模态 Key 已配（读截图） |
| 这一段要教会 | ① 技能怎么工作：读图抄数 → 套平台阈值 → 找第一个跌破的层 → 对照复盘矩阵 → 只改一个变量；② 先核对数字表再看结论；③ 改法只改一处并写清验证指标 |

## 演示参考值（核对用）

- 截图数字：播放 380；封面点击率 2.3%；2 秒跳出率 61%；5 秒完播率 22%；完播率 4.1%；平均播放时长 3.2 秒；点赞 / 评论 / 分享 / 收藏 9 / 1 / 0 / 3；同类作品完播率参考 18%。
- 正确结论：主要卡在开头 2 秒（61% 跳出，平均只看 3.2 秒），不是发布时间。
- 读图常见错误（出现了才纠正）：61% 与 4.1% 对调；3.2 秒读成 32 秒；把发布时间列为主因。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

### S1 先看一眼截图（原始片段 `2-2-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点“新建任务”，确认输入框下方显示 `阿夏的AI片场`。
3. 在工作区文件列表里点开 `资料/后台截图/赛博朋克重庆-作品数据.png`，右侧预览显示截图，停 5 秒。**标记 M1-1**。
4. 结束录制。

### S2 提交诊断任务（原始片段 `2-2-S2.mp4`）

1. 开始录制。
2. 点击输入框，粘贴（原样）：

```text
用 social-account-doctor 帮我看看这条作品为什么不爆，后台截图是 资料里“赛博朋克重庆”那张。先把截图里的数字原样抄成一张表，看不清就写“看不清”，不要猜；再判断它卡在漏斗哪一层；最后给 3 个改法，每个只改一处，并写清下一条看哪个数字验证。结果放到 成果/2-2。
```

3. 停 3 秒。**标记 M2-1**。
4. 点发送，等待生成完成。出现诊断报告的文件卡片时，**标记 M2-2**。
5. 结束录制。

### S3 核对数字表（原始片段 `2-2-S3.mp4`）

1. 开始录制。
2. 点击诊断报告的文件卡片，右侧预览打开，滚动到数字表，停 6 秒。**标记 M3-1**。
3. 在右侧预览区点“+”新标签页，打开截图 PNG；两个标签来回切换各停 3 秒，最后停在截图，**标记 M3-2**（若预览区支持分屏，改为左右并排）。
4. 回到报告，滚动到“卡在哪一层”的判断，停 5 秒。**标记 M3-3**。
5. 结束录制。

**此时按“C. 分支”判断是否录 S4。**

### S4 让它重抄（仅主线，原始片段 `2-2-S4.mp4`）

1. 开始录制，画面回到 WorkBuddy 同一任务。
2. 点击输入框，粘贴（原样）：

```text
数字表有抄错：截图上 <指标> 是 <截图上的数>，不是 <报告里的数>。请对着截图重抄一遍，用到这几个数的判断都重算，并在报告末尾写一下改了什么。
```

把 `<>` 换成实际抄错的那几项（可以连写多项，用“；”隔开）。如果报告把发布时间当成主要原因，在末尾加一句：“发布时间没有数据支撑，别当主要原因。”

3. 停 3 秒。**标记 M4-1**。
4. 点发送，等待完成。
5. 打开更新后的诊断报告，停在数字表 5 秒。**标记 M4-2**。
6. 结束录制。

### S5 看改法（原始片段 `2-2-S5.mp4`）

1. 开始录制。
2. 滚动到“卡在哪一层”的结论，停 4 秒。**标记 M5-1**。
3. 滚动到 3 个改法，停 8 秒，让“只改什么”“看哪个数字”都在画面里。**标记 M5-2**。
4. 结束录制。

## C. 分支

S3 结束后检查：

```sh
grep -n -E "跳出" "$WS"/成果/2-2/*.md | head
grep -n -E "完播率" "$WS"/成果/2-2/*.md | head
grep -n -E "32 ?秒|发布时间.*(主要|首要)" "$WS"/成果/2-2/*.md
```

只纠正真实出现的问题，**不要为了配合脚本去诱导或伪造错误**。

- **主线**（录 S4）：数字表和截图有任何一项不一致，或把发布时间列为主要原因。S4 的追问按实际抄错的项填写，剪辑表镜头 6–8 的红框和旁白也改成实际那几项。
- **分支 B**（跳过 S4）：数字表全部正确，卡点判断为开头 2 秒。剪辑表镜头 6–8 换成分支 B 镜头。
- 走了哪条，在 report.md 写明。
