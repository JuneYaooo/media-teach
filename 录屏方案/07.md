# 07 结课：用你自己的账号跑一遍，变成每周循环 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/07-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 6 分钟 – 7 分钟 |
| 录制时间 | **1-2 录完后至少 7 天**再录，这样对标有新一周的作品，雷达能做“回收上期” |
| 前置产物 | `$WS/成果/1-1/`（选定的 3 个对标）、`$WS/成果/1-2/`（上周雷达周报）、`$WS/成果/4-2/`（阿夏版排行榜工作流）；`录屏方案/_work/1-1/report.md` 里“选定对标”的 3 个账号名和主页链接 |
| 用到的素材 | `资料/账号档案.md`（一句话定位、选题池）；实操 5 需要阿夏自己账号**至少两期**作品数据快照（见 C 节） |
| 用到的技能 | benchmark-outlier-radar、social-account-doctor、Hypit、self-media-compliance-review |
| 这一段要教会 | ① 整条链路每一步用上一步的结果；② 雷达带上期周报做“回收上期”；③ 套路一样就复用已有工作流，只换内容；④ 审核过了才打包，说明里写清来源；⑤ 自己账号的台账要攒期数 |

讲义：`自媒体教程/课程/07-结课：用自己的账号跑一遍.md`。录屏演示讲义里的实操 1–5，提示词中的 `<尖括号>` 已按下表换成演示值。

**画面原则**：对标是真实账号。录屏里只展示账号名、作品标题和公开数据，不播放对方视频、不做头像或封面特写；旁白不评价具体账号好坏。

## 预期结果（以实际为准）

- 雷达周报：本周异常爆款表；“上期回收”段逐条标出 1-2 那周的判断哪些被验证、哪些落空。
- 选题：一条“学内容套路”的爆款。
- 拆解：钩子、骨架、结尾互动；按阿夏定位写出 3 标题、3 封面大字和约 20 秒脚本。
- 成片：复用 4-2 工作流出的新排行榜视频，水印 @阿夏的AI片场。
- 审核：Low 或 Pass 后打包；作品包说明写清每个文件来自哪一步。
- 台账（有两期快照时）：阿夏每条作品这一期新增；本周复盘模板。

所有数字、账号、选题以实际输出为准，旁白照实改。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/阿夏的AI片场
rm -rf "$WS/成果/07"
for c in 1-1 1-2 4-2; do ls "$WS/成果/$c" >/dev/null || echo "缺 $c，先补录"; done
ls "$WS/资料/"自己账号-作品数据*.csv
mkdir -p 录屏方案/_work/07/raw
```

- 缺 1-1、1-2、4-2 任一产物时，停下补录，不要用其他数据替代。
- 把 1-1 选定的 3 个账号名和主页链接填进 S1 提示词，写入 report.md。
- 在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表清空或收起；确认模型为统一模型（README 3.4）；确认 4 个技能都已安装且开关打开。
- 在录制外先试跑一次 Hypit 渲染 4-2 工作流，避免录制中报错。
- 五段任务都在**同一个任务会话**里依次发送。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

### S1 雷达找本周爆款，回收上期（原始片段 `07-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点左上角“新建任务”。确认输入框下方显示 `阿夏的AI片场`。
3. 点击输入框，粘贴（原样，账号和日期按 A 节填好）：

```text
这是我 3 个对标 <账号A名（主页链接）>、<账号B名（主页链接）>、<账号C名（主页链接）> 的主页。帮我整理它们最近 20 条作品的公开点赞、评论、收藏，再用 benchmark-outlier-radar 生成本周雷达周报，以 <11 月 X 日> 为基准。上周的周报也在文件夹里，逐条看看上周的判断哪些被验证了、哪些落空了。选 1 条最值得做的，说明要学的是内容套路还是画面做法；互动率异常的先标“待核对”，不要选。这一课的结果都放到 成果/07。
```

4. 停 3 秒。**标记 M1-1**。
5. 点发送。Agent 打开对标主页整理数据时，**标记 M1-2**（画面只停 1.5 秒，不放大对方作品画面）。
6. 等待完成。点击雷达周报，停在异常爆款表 5 秒。**标记 M1-3**。
7. 滚动到“上期回收”，停 5 秒。**标记 M1-4**。
8. 停在选题和理由 4 秒。**标记 M1-5**。
9. 结束录制。

**此时按“C. 分支”检查选题类型。**

### S2 拆解并写阿夏的版本（原始片段 `07-S2.mp4`）

1. 开始录制，画面在同一任务。
2. 点击输入框，粘贴（原样）：

```text
拆一下刚选的这条：用 social-account-doctor 拆钩子和结构。然后按它的结构，用我的定位写下一条：我的账号是 用 AI 做电影感短片的人，偶尔发 AI 工具教程，这次想发 新手做 AI 视频的 3 个坑。给 3 个标题、3 个封面大字和完整脚本，不照抄原句，不夸大、不承诺收益、不留联系方式。
```

3. 停 3 秒。**标记 M2-1**。
4. 点发送，等待完成。打开拆解结果，停在钩子 / 骨架部分 4 秒。**标记 M2-2**。
5. 打开脚本，停在分段脚本和标题封面 5 秒。**标记 M2-3**。
6. 结束录制。

### S3 复用工作流出片（原始片段 `07-S3.mp4`）

1. 开始录制。
2. 点击输入框，粘贴（原样）：

```text
用 Hypit 复用我上次存的 4-2 做的阿夏版排行榜工作流，只把内容换成刚写的脚本，版式和动效不变。出片后逐字核对字幕和配音是否一致。
```

3. 停 3 秒。**标记 M3-1**。
4. 点发送。出现渲染进度时，**标记 M3-2**。等待完成，出现成片文件卡片时，**标记 M3-3**。
5. 在 Finder 里用 QuickTime 打开 `$WS/成果/07/` 里的成片，从头播放一遍。水印 @阿夏的AI片场 清楚可见时，**标记 M3-4**。
6. 关闭 QuickTime，结束录制。

### S4 审核并打包（原始片段 `07-S4.mp4`）

1. 开始录制，画面回到 WorkBuddy 同一任务。
2. 点击输入框，粘贴（原样）：

```text
用 self-media-compliance-review 审这条成片和发布文案，目标平台 抖音。有 High 或 Blocker 就先改再复审，不要打包。全部降到 Low 或 Pass 后，把成片、选定的标题和封面大字、发布文案、审核报告放成一个作品包，再写一份说明，列出每个文件来自哪一步。
```

3. 停 3 秒。**标记 M4-1**。
4. 点发送，等待完成（加速）。
5. 点击审核报告，停在结论 4 秒。**标记 M4-2**。
6. 点击作品包说明，停在文件来源清单 6 秒。**标记 M4-3**。
7. 在工作区文件列表里展开 `成果/07/`，停 4 秒。**标记 M4-4**。
8. 结束录制。

### S5 自己账号的台账（原始片段 `07-S5.mp4`）

1. 开始录制，画面在同一任务。
2. 点击输入框，粘贴（原样）：

```text
这是我账号最近几期导出的作品数据，用 benchmark-outlier-radar 帮我做一份台账：每条作品这一期新增了多少，哪些在涨、哪些停了。再和对标雷达放在一起，写一份本周复盘：本周做了什么、数据怎么样、下周做什么。复盘做成模板，下周我直接填。
```

3. 停 3 秒。**标记 M5-1**。
4. 点发送，等待完成。打开台账，停在“期间新增”表 5 秒。**标记 M5-2**。
5. 打开本周复盘，停 5 秒。**标记 M5-3**。
6. 结束录制。

## C. 分支

- **S1 选题是“画面做法”（例如短剧）**：不算错。在 S1 后补发一句（原样），录为 `07-S1b.mp4`，剪辑时插入镜头 5C：

```text
这周我先做教程类，换一条要学内容套路的，画面做法那条留到下周。
```

- **S1 选中了带 ⚠️ 或“待核对”的条目**：补发（原样），录为 `07-S1b.mp4`，插入镜头 5C（旁白用 5C 的第二种）：

```text
你选的这条互动率异常，雷达已经标了“待核对”，不能当本周选题，请改选一条。
```

- **雷达这周没有异常爆款**：照实录。补发“这周没有明显的爆款，就按我选题池里的‘新手做 AI 视频的 3 个坑’做，结构参考上周 1-2 选的那条教程类爆款。”，录为 `07-S1b.mp4`，旁白照实改。
- **“上期回收”缺失**：确认 `$WS/成果/1-2/` 有周报；有的话补发“请对照文件夹里上周的雷达周报，补上上期回收：上周的判断哪些被验证、哪些落空。”并录为 `07-S1c.mp4`。
- **Agent 读不出对标主页**：按它给的选项走（不用付费接口，不用 MediaCrawler）；仍不行就停录，记入 report.md 等人工处理。
- **审核出现 High 或 Blocker，Agent 自行修改复审**：照实录，加速 ×16；镜头 13 旁白改为“它先发现了一个高风险，改完复审通过，才开始打包。”并在 report.md 写明是哪条风险。
- **实操 5 的数据**：`$WS/资料/` 里有两期阿夏自己账号的快照：`自己账号-作品数据.csv`（10-31 导出，42 条）和 `自己账号-作品数据-2026-11-07.csv`（11-07 导出，44 条，新增 ax-043、ax-044）。台账应算出期间新增播放约 +13,817、新视频 2 条；只有两期，所以没有周环比，台账会如实说明。录屏照常录 S5。
- **Hypit 渲染失败**：重试一次；仍失败则停录，记入 report.md，不要用其他工具替代。

**禁止**：为了让结果符合预期去诱导 Agent。
