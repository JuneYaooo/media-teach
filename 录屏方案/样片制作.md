## 通用要求

- **人物全部 AI 原创，禁止真人肖像**：不用任何明星、网红、真实人物的照片做参考；生成后逐帧抽查，像某位真人就重做。
- **不出现任何真实平台 Logo、真实品牌、真实工具名**。样片 2 的工具名只用设计文档里的虚构名。
- 字体：中文字幕用 PingFang SC；标题卡用宋体（Songti SC）。
- 导出统一：

```sh
ffmpeg -i edit.mp4 -c:v libx264 -crf 22 -preset medium -pix_fmt yuv420p -r 30 \
  -c:a aac -b:a 128k -ar 48000 -movflags +faststart out.mp4
```

- 每条成片 ≤ 15MB（会进仓库）。超了把 crf 调到 25。
- 中间文件放 `录屏方案/_work/样片/`，不进仓库。
- 密钥（AutoDL Token、TTS Key）只放本机私有配置，不写进任何文件、命令历史截图或 report。

### 5. 生成流程（一次开机）

按 `minimax-h3` 技能“最快链路”执行：

1. 先跑一次 5 秒冒烟（`reference.md` 的单参考图最小验证），通过后再批量。
2. `autodl_app.py boot` 一次 → `discover_workflow.py` 生成 slot_map → **7 条任务全部提交进队列** → 并发轮询下载 → 每条 `ffprobe` 核对时长、分辨率、音轨。
3. 同一次开机内用 `minimax-music-gen` 生成配乐：古风、温暖、轻快，约 24 秒，无人声（第 4 镜起至结尾）。
4. 全部下载并校验后**立即** `autodl_app.py off --uuid <uuid> --wait`，到控制台确认已关机。
5. 抽帧验收（关机后做）：每镜 3 帧（首、中、尾）拼成接触表，检查小周黄衣黑盔、公主淡紫襦裙是否一致，有无重复人物、肢体变形、穿帮文字。不合格的镜头改提示词后**单独**重开机重做，不整批重来。

GPU 用时与费用记进 report。预计 7 镜 + 配乐总计 ¥3–6（以 AutoDL 实际计费为准）。

**没有 AutoDL 时**：改用 Capsule Cinema 的 H3 渠道调 API（`MINIMAX_API_KEY` 或 `RUNNINGHUB_API_KEY`，放本机私有配置）。提示词、镜头时长和验收标准都不变，跳过第 2、4 步的开关机；按次计费，第 1 步冒烟更不能省。费用按平台实际扣费写进 report。

| 26.0–30.0 | 配乐收尾，最后 1 秒淡出 |

响度统一到 -16 LUFS 左右（`loudnorm`）。

### 8. 合成思路（ffmpeg）

1. 每镜裁到成片时长（`-ss`/`-t`），统一 `scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30`。H3 输出尺寸按 32 对齐、时长按 17 帧块取整，必须先归一化。
2. 镜 8 最后 1 秒用 `tpad=stop_mode=clone` 定格。
3. 按顺序 `concat` 成 30.0 秒底片（镜 3 用 HyperFrames 渲染的 1.5 秒标题卡）。
4. 底片作为 HyperFrames 工程的背景视频，叠加第 6 节全部花字、字幕和水印后渲染。
5. 用 ffmpeg 混音（H3 原声 + TTS + 钟声 + 配乐），与画面合并，按“通用要求”的参数导出。

## 样片 2：AI工具铺子《AI 视频工具排行榜》

纯代码视频，**不调用任何视频或图片生成模型、不需要 GPU**。

### 1. 环境准备

- HyperFrames（`npx hyperframes skills update`），Node.js ≥ 22，ffmpeg。
- 配音：README 3.1 的 MiniMax TTS，选一个语速快、有活力的女声（音色 ID 写进 report），语速约 1.15。
- 配乐：轻快电子节拍，约 120 BPM，无人声。用 HyperFrames `media-use` 技能的免费本地素材；不要用任何流行歌曲。

### 2. 时间轴（以 `AI工具铺子-AI视频工具排行榜.srt` 逐字为准）

| 段 | 时间 | 画面 |
| --- | --- | --- |
| 钩子 | 0.0–**2.5** | 深色背景，大字幕“免费的 AI 视频工具，第一名居然是它？”逐词高亮（卡拉 OK）；说到“第一名”时这三个字放大 1.4 倍并变红（#FF3B30）；2.5s 硬切 |
| 快速过榜 | 2.5–15.0 | 排行榜卡片从下往上依次翻出：第 5 名“帧跃”（2.5–5.6）、第 4 名“流光”（5.6–8.8）、第 3 名“幻镜”（8.8–11.9）、第 2 名“影工坊”（11.9–15.0）。每张卡：名次大号数字 + 工具名 + 一行优点（绿色 ✓）+ 一行缺点（红色 ✗），文字与该句口播同步出现 |
| 转折 | 15.0–18.0 | 前四张卡缩小排成一列并变灰，屏幕中央大字“但第一名一分钱不花” |
| 揭晓 | 18.0–22.0 | 第 1 名卡片从中心放大弹出，金色边框：“开源 X1” + “自己的显卡就能跑”；伴随一个揭晓音效 |
| CTA | 22.0–25.0 | 底部大字“评论区扣 1，我把教程发你”，一个“1”字气泡上下弹跳 |
| 水印 | 0–25 全程 | **左上角** `@AI工具铺子`，距左 40px、距顶 120px，白色 36px，不透明度 60% |

字幕样式：底部居中，白字黑描边 4px，PingFang Semibold 56px，当前词黄色高亮。

### 3. 制作步骤

1. 先生成 TTS 配音（逐句，按 SRT 文本），用词级对齐（HyperFrames `media-use` 的转写能力或 WhisperX）得到每个词的时间，再按 SRT 时间微调——成片字幕时间以 SRT 为准，配音需要时用 `atempo` 轻微调速（0.9–1.1 之间）对齐。
2. 用 hyperframes 技能写一个 25 秒、1080×1920 的工程：排行榜卡片、卡拉 OK 字幕、转折与揭晓动效、CTA、水印。可以先查 `hyperframes-registry` 里的排行榜 / 字幕 / 文字动效区块再改。
3. 渲染，混入配音、配乐（对白时压低 8dB）、揭晓音效，响度约 -16 LUFS，按“通用要求”导出。

### 4. 验收

```sh
F="录屏方案/演示素材/爆款样片/AI工具铺子-AI视频工具排行榜.mp4"
ffprobe -v error -show_entries format=duration:stream=width,height,r_frame_rate,codec_name -of compact "$F"
for t in 1.0 2.4 2.6 16.0 20.0 23.5; do ffmpeg -y -v error -ss $t -i "$F" -frames:v 1 "录屏方案/_work/样片/s2-$t.png"; done
```

- [ ] 时长 25.0 ± 0.1 秒；1080×1920；30fps；H.264 + AAC。
- [ ] 1.0s 钩子字幕中“第一名”为红色放大；2.4s 仍是钩子画面，2.6s 已是第 5 名卡片（3-2 的核对点：钩子在 2.5 秒结束）。
- [ ] 16.0s 为转折画面，20.0s 为第 1 名“开源 X1”金框卡片，23.5s 为 CTA。
- [ ] **全程左上角 `@AI工具铺子` 水印**（4-2 的核对点，必须存在且清晰可辨）。
- [ ] 字幕与 SRT 逐字一致，时间误差 ≤ 0.2 秒。
- [ ] 画面里没有任何真实工具名、真实 Logo、真实人物。
- [ ] 没有调用视频或图片生成模型（report 里写明用到的服务：仅 TTS）。
