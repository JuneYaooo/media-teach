# 4-1 写我的版本：套用爆款结构写新选题 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/4-1-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 4 分 30 秒 – 5 分 30 秒 |
| 前置产物 | `$WS/成果/3-2/` 里的爆款拆解卡（文件名以实际为准；没有就先录 3-2） |
| 用到的素材 | `资料/账号档案.md`（定位）、`资料/阿夏实测笔记.md`（演示账号自己的素材） |
| 用到的技能 | social-account-doctor（adapt，带素材时先 compose） |
| 这一段要教会 | ① adapt 的三样输入：定位一句话、拆解卡、选题；② 素材模式：独家要素、信息缺口要问不能编；③ 每项命中公式并标“抄了什么 / 改了什么”；④ 数字和效果说法都要能回到素材里找到 |

## 演示参考值（核对用）

- 定位一句话：前广告剪辑师，用 AI 做电影感短片，也教新手用 AI 视频工具。
- 实测笔记：5 个模型，第 1 名 MiniMax H3 开源版，在 AutoDL 租卡跑，10 秒 1080p 约 ¥0.3（只付 GPU 租金，用完要关机）；其余 4 个约 ¥1.5–6/条或会员 ¥68/月。
- 素材撑得住的说法举例：“第一名 10 秒只要 3 毛钱”。撑不住的：“不到一块钱测完 5 个模型”“完全免费”“一分钱不花”“全网第一”“一键出大片”。
- 常见偏差（出现了才纠正）：沿用对标原句“第一名居然是它”；出现上面撑不住的说法；没标公式编号或“抄了什么 / 改了什么”。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/阿夏的AI片场
rm -rf "$WS/成果/4-1"
ls "$WS/成果/3-2/"   # 必须有 3-2 的拆解卡
mkdir -p 录屏方案/_work/4-1/raw
```

`$WS/资料/` 是 `录屏方案/演示素材/` 的副本。在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表清空或收起；确认统一模型；确认 social-account-doctor 已开启。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

### S1 提交仿写任务（原始片段 `4-1-S1.mp4`）

1. 开始录制。WorkBuddy 首页停 2 秒，点“新建任务”，确认工作空间 `阿夏的AI片场`。
2. 点击输入框，粘贴（原样）：

```text
用 social-account-doctor 帮我仿写下一条。我的定位：前广告剪辑师，用 AI 做电影感短片，也教新手用 AI 视频工具。对标是 3-2 拆过的那条爆款，我想发：2026 年 AI 视频生成模型排行榜，我自己实测了 5 个。素材在 资料里的阿夏实测笔记，素材里没有的数字和事实不要编，缺什么问我。给我 3 个标题、3 个封面大字、一段 50 字以内的开头和一句互动引导，每项标清用了哪个公式、抄了对标什么、改了什么。结果放到 成果/4-1。
```

3. 停 3 秒。**标记 M1-1**。
4. 点发送。如果它先列出素材画像或信息缺口并提问，停 4 秒，**标记 M1-2**，按笔记实际内容简短回答（回答内容写进 report.md）；没有提问则跳过。
5. 等待生成完成，出现结果文件卡片时，**标记 M1-3**。结束录制。

### S2 看仿写结果（原始片段 `4-1-S2.mp4`）

1. 开始录制。点结果文件卡片。
2. 停在 3 个标题和各自的公式编号 6 秒。**标记 M2-1**。
3. 滚到封面大字，停 4 秒。**标记 M2-2**。
4. 滚到开头和 CTA，停 5 秒。**标记 M2-3**。
5. 停在某一项的“抄了什么 / 改了什么 / 用了素材”标注上 5 秒。**标记 M2-4**。
6. 结束录制。

### S3 演示核对（原始片段 `4-1-S3.mp4`）

1. 开始录制。在右侧预览区新标签页打开 `资料/阿夏实测笔记.md`，停在表格 4 秒。**标记 M3-1**。
2. 切回结果，停在含数字或效果说法的标题 / 开头上 5 秒。**标记 M3-2**。
3. 结束录制。

**此时按“C. 分支”判断是否录 S4。**

### S4 让它改说法（仅主线，原始片段 `4-1-S4.mp4`）

1. 开始录制，回到同一任务。粘贴实际问题对应的追问（见 C），停 3 秒。**标记 M4-1**。
2. 发送，等待完成，打开更新后的结果，停在改过的那一项 5 秒。**标记 M4-2**。
3. 结束录制。

### S5 要整条脚本（原始片段 `4-1-S5.mp4`）

4-2 要用这份脚本，主线和分支 B 都要录。

1. 开始录制，回到同一任务。粘贴（把 `<N>` 换成选定的标题序号，优先选素材撑得住、不沿用对标原句的那个）：

```text
我选第 <N> 个标题和这个开头。按对标的骨架把整条脚本写出来，标好每段的起止时间和画面，素材里没有的事实标“待补”。
```

2. 停 3 秒。**标记 M5-1**。发送，等待完成。
3. 打开脚本，停在分段表 6 秒。**标记 M5-2**。
4. 结束录制。

## C. 分支（演示核对）

S3 时检查结果，只纠正真实出现的问题，**不要为了配合脚本去诱导或伪造错误**：

```sh
grep -n -E "居然是它" "$WS"/成果/4-1/*.md
grep -n -E "不到一块钱|完全免费|一分钱不花|零成本|全网第一|最强|一键(生成|出)大片" "$WS"/成果/4-1/*.md
```

| 检查 | 出现问题时的追问（把 `<>` 换成原文） |
| --- | --- |
| 数字或效果说法在笔记里找不到（如“不到一块钱测完”“完全免费”） | `“<那句说法>”在我的素材里找不到依据，<素材里实际是怎么写的>。请改成素材里能对上的说法，别的不动。` 例：`“完全免费”在我的素材里找不到依据，笔记里写的是开源但要付 AutoDL 的 GPU 租金，10 秒约 ¥0.3。请改成素材里能对上的说法，别的不动。` |
| 照搬对标原句“第一名居然是它” | `“第一名居然是它”是对标的原句，在我的素材里找不到依据，换成我实测得出的说法。请改成素材里能对上的说法，别的不动。` |
| 没标公式编号或“抄了什么 / 改了什么” | `每一项都补上用了哪个公式、抄了对标什么、改了什么。` |

- **主线**：上表任一项出现 → 录 S4，剪辑用镜头 9–10。
- **分支 B**：说法都能在笔记里找到、没有对标原句、每项有标注 → 不录 S4，剪辑用镜头 9B–10B。
- 走了哪条、发了哪句追问，在 report.md 写明。
