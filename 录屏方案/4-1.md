## 基本信息

| 目标时长 | 8 分钟 – 9 分钟（安装和渲染等待已加速） |

| 这一段要教会 | ① Capsule Cinema 的流程（讲义流程图：参考视频 → 拆成六样 → 分清内容和方法 → 你点头 → 换成你的 → 可审分镜 → 代表镜头 → 质检交付）；② 第一次用先装：用讲义的安装提示词让 WorkBuddy 装，到“已安装”确认开关开着；③ 配方草稿重点看“不带走”：原片的工具名、台词、水印不能进配方；④ 先出分镜不花钱，分镜里的数字回素材找出处；⑤ 花钱前先问：渠道和费用说清楚再做，先只做一个代表镜头；⑥ 整条过质量门，有问题只返工那一镜，最后拿到交付包；⑦ 字幕卡片类也可以走 Hypit（只提一句，不录操作） |

## 演示参考值（核对用）

- 配方名：工具排行榜。
- 草稿里应该有的方法（举例，措辞以实际为准）：前 2.5 秒抛悬念钩子、关键词放大变色；倒数过榜，一名一张卡、一句话讲一个优点一个缺点，每张约 3 秒；转折句后揭晓第一名，金框放大加音效；结尾评论区互动；逐词高亮字幕；竖屏 25 秒左右。
- 不该进配方的样片内容：`@AI工具铺子` 水印、工具名“帧跃”“流光”“幻镜”“影工坊”“开源 X1”、原句“第一名居然是它”“一分钱不花”“评论区扣 1，我把教程发你”、样片里的具体名次和优缺点。
- 阿夏版只能用实测笔记里的事实：5 个模型，第 1 名 MiniMax H3 开源版，在 AutoDL 租卡跑，10 秒 1080p 约 ¥0.3（只付 GPU 租金，用完要关机）；其余 4 个约 ¥1.5–6/条或会员 ¥68/月。撑不住的说法：“完全免费”“一分钱不花”“不到一块钱测完 5 个模型”“全网第一”“第一名居然是它”。
- 常见偏差（出现了才纠正）：草稿里混进样片的工具名或原句；分镜里出现笔记里没有的数字或夸大说法；Agent 打算调用图片或视频生成来做卡片。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/阿夏的AI片场
rm -rf "$WS/成果/4-1"
ls "$WS/成果/3-2/"   # 必须有 3-2 的拆解卡
ls "$WS/资料/爆款样片/AI工具铺子-AI视频工具排行榜.mp4"
mkdir -p 录屏方案/_work/4-1/raw
```

录前检查（都不录）：

1. `python3.12 --version`、`ffmpeg -version` 可用。
2. 配音渠道的 Key 已按 Capsule Cinema 安装说明写进本机私有配置。只检查“已设置”，**不要 cat、不要 echo 出值**。没有的话在镜头外让 WorkBuddy 告诉你变量名和写到哪，人只在它打开的文件里粘贴，整个过程不录。
3. 不录屏试跑时，确认“列出内置配方和能用的渠道”的回复里只显示渠道是否可用，不出现任何 Key 明文。出现了就不录 S0 第 6 步。
4. Capsule Cinema 配方目录里如已有“工具排行榜”（试跑留下的），先备份移走。
5. WorkBuddy：关闭预览标签页；任务列表只留本课；确认统一模型。“专家·技能·连接器”→“技能”→“已安装”：如果已有 `capsule-cinema`，先卸载（S0 要现场装）。只卸载 WorkBuddy 里的技能，Python 3.12 环境、FFmpeg、私有配置（Key 所在）都保留；`实践手册.md` 里旁白配音用的 Capsule Cinema 目录不动。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

### S0 安装 Capsule Cinema（原始片段 `4-1-S0.mp4`）

讲义“你要准备什么”里的安装提示词，原样演示一遍。安装等待在剪辑时加速。

1. 开始录制。点“新建任务”，确认工作空间为 `阿夏的AI片场`。
2. 点击输入框，粘贴（原样）：

```text
帮我安装 Capsule Cinema：https://raw.githubusercontent.com/JuneYaooo/cheap-claude-video/main/docs/install.md 。装之前先告诉我它要装哪些东西、会不会联网或花钱，我确认后再装。需要 Key 时停下来，告诉我写到哪，我自己填，不要在对话里显示。
```

3. 停 2 秒。**标记 M0-1**。发送。它列出要装的东西、会不会联网或花钱、等你确认时 **标记 M0-2**，停 2 秒。然后粘贴并发送：

```text
确认，装吧。
```

4. 等待安装（不动鼠标）。请求执行命令时点“允许”。出现“安装完成”一类说明时 **标记 M0-3**。
5. 镜头外重启 WorkBuddy（暂停录制）。恢复录制，左侧栏点“专家·技能·连接器”→“技能”→“已安装”，找到 `capsule-cinema`，鼠标停在开关旁 2 秒。**标记 M0-4**。
6. （A 节第 3 条确认安全时才录）回到任务，粘贴并发送（这句不在代码块里，讲义原文是“可以先让它列出内置配方和你现在能用的渠道”）：

```text
列一下内置配方和我现在能用的渠道。
```

   回复出现时停 3 秒。**标记 M0-5**。结束录制。

> 安装中途它停下来要 Key：**暂停录制**，镜头外照它说的位置填好，再恢复录制回复“填好了”。它要装缺的运行环境（如 Python 3.12）：同意。照实写进 report.md。

### S1 拆成配方草稿（原始片段 `4-1-S1.mp4`）

1. 开始录制。点“新建任务”，确认工作空间 `阿夏的AI片场`。
2. 点击输入框，粘贴（原样）：

```text
用 Capsule Cinema 拆这条参考视频：资料里那条 AI工具铺子 的排行榜样片。成果里 3-2 的拆解卡也一起参考。拆它的钩子、镜头节奏、文案结构、视觉、运动和声音，分清哪些是这条视频自己的内容、哪些是能复用的方法，整理成一份配方草稿。先告诉我准备保存哪些方法，我确认后再写入配方，配方叫“工具排行榜”。
```

3. 停 3 秒。**标记 M1-1**。
4. 点发送，等待完成。它列出“准备保存的方法”和“不带走的样片内容”、等你确认时，停在“方法”部分 5 秒（**标记 M1-2**），再滚到“不带走”部分停 5 秒（**标记 M1-3**）。草稿另存成文件的，点开文件卡片看。
5. 结束录制。

**此时按“C. 分支”检查草稿，再录 S1b。**

### S1b 确认写入（原始片段 `4-1-S1b.mp4`）

1. 开始录制，回到同一任务。粘贴 C 节对应的那句，停 3 秒。**标记 M1b-1**。
2. 发送，等待写入和配方校验完成。回复里出现“已写入 / 校验通过”一类说明时停 3 秒。**标记 M1b-2**。
3. 结束录制。
4. 镜头外把 Capsule Cinema 里的“工具排行榜”配方复制一份到 `录屏方案/_work/4-1/配方备份/`（4-2 重录时用来还原）。

### S2 换成阿夏的主题，先出分镜（原始片段 `4-1-S2.mp4`）

1. 开始录制，回到同一任务。
2. 粘贴（原样）：

```text
用“工具排行榜”配方做一条我的版本：2026 AI 视频生成模型排行榜，我自己实测了 5 个，素材是 资料里的阿夏实测笔记。原片的人物、台词、画面和水印都不用。先给我看分镜，不要生成图片、视频和配音，也不要调用任何计费接口。分镜我确认后，只试做一个代表镜头，动手前告诉我用哪个渠道、缺什么。
```

3. 停 3 秒。**标记 M2-1**。
4. 点发送，等待完成。打开分镜，停在分镜表（每镜时长、景别、画面、文案）6 秒。**标记 M2-2**。
5. 在右侧预览区新标签页打开 `资料/阿夏实测笔记.md`，停在表格 4 秒。**标记 M2-3**。
6. 切回分镜，停在第 1 名揭晓那一镜（含费用说法）5 秒。**标记 M2-4**。
7. 结束录制。

**此时按“C. 分支”检查分镜，决定是否录 S2b。**

### S2b 让它改说法（仅主线，原始片段 `4-1-S2b.mp4`）

1. 开始录制，回到同一任务。粘贴 C 节对应的那句，停 3 秒。**标记 M2b-1**。
2. 发送，等待完成，打开更新后的分镜，停在改过的那一镜 5 秒。**标记 M2b-2**。
3. 结束录制。

### S3 试一个代表镜头（原始片段 `4-1-S3.mp4`）

先问再花钱。下面两句都不在讲义里，是学员看完分镜后的自然回复。

1. 开始录制，回到同一任务。
2. 如果它在 S2 已经说明了代表镜头的渠道（本地渲染 + 哪个配音渠道）并报了预计费用：跳到第 4 步。否则粘贴并发送：

```text
分镜可以。代表镜头的卡片和字幕用本地渲染，不调用图片和视频生成；配音用已经配好的 <配音渠道>。先告诉我这一镜大概花多少钱，我同意再做。
```

   （`<配音渠道>` 换成 A 节配好的那个，写进 report.md。）**标记 M3-1**。
3. 等它说明渠道、缺什么、预计费用。停在这段说明上 4 秒。**标记 M3-2**。它说缺 Key：暂停录制，镜头外按 A 节第 2 条处理，恢复后继续。
4. 粘贴并发送：

```text
可以，按你报的费用做。
```

5. 等待完成（加速）。出现代表镜头文件卡片时，点开在右侧预览播放一遍，停在最后一帧 3 秒。**标记 M3-3**。
6. 结束录制。

代表镜头的检查（不录，写进 report.md）：画面和分镜那一镜对得上；文字里的数字能在实测笔记里找到；没有 `@AI工具铺子` 和样片工具名；没有调用图片、视频生成（看它的渠道说明）。有问题时按 C 节处理，先改这一镜，确认了再录 S4。

### S4 做整条、质检（原始片段 `4-1-S4.mp4`）

1. 开始录制，回到同一任务。
2. 粘贴（原样）：

```text
分镜和代表镜头我都确认了，做整条。做完跑一遍质检，哪一镜有问题只返工那一镜，其他镜头和音频不动，改完再检查一次。交付包放到 成果/4-1，告诉我用了哪些渠道、花了多少钱、返工了哪几镜。
```

3. 停 3 秒。**标记 M4-1**。
4. 点发送。整条配音前如果又报费用，停 3 秒（**标记 M4-2**），回复“可以，按你报的费用做。”。没报就不发。
5. 等待完成（加速）。回复里出现“渠道、花费、返工了哪几镜”的段落时停 4 秒。**标记 M4-3**。
6. 结束录制。

### S5 看成片、质检记录和交付包（原始片段 `4-1-S5.mp4`）

1. 开始录制。点成片文件卡片，在右侧预览从头播放到结尾。播放到第 1 名揭晓时暂停 3 秒。**标记 M5-1**。
2. 打开质检记录，停在检查项和结果（画幅、黑帧、响度、字幕、安全区等）5 秒。**标记 M5-2**。有返工的，再停在返工记录 4 秒。**标记 M5-3**。
3. 在工作区文件列表展开 `成果/4-1/` 里的交付包，停 4 秒。**标记 M5-4**。
4. 结束录制。
5. 另在终端生成剪辑素材（不录）：

```sh
V="$WS/成果/4-1/<阿夏版成片>.mp4"   # 换成 Agent 实际生成的文件名
ffmpeg -y -i "$WS/资料/爆款样片/AI工具铺子-AI视频工具排行榜.mp4" -i "$V" \
  -filter_complex "[0:v]scale=-2:900[a];[1:v]scale=-2:900[b];[a][b]hstack=inputs=2[v]" \
  -map "[v]" -t 8 录屏方案/_work/4-1/原片-阿夏版.mp4
```

### S4b 只返工一镜（视情况，原始片段 `4-1-S4b.mp4`）

只在 S5 看片时**真的发现了质检没拦下的问题**才录（例如某张卡的数字和笔记对不上、字被平台按钮区域挡住、出现样片工具名）。用讲义常见问题里的说法：

```text
第 <N> 个镜头 <哪里不对>，只改这个镜头，其他镜头和音频保持不动，改完重新质检。
```

开始录制，粘贴，停 3 秒（**标记 M4b-1**），发送，等待完成，打开返工后的质检记录停 4 秒（**标记 M4b-2**），结束录制。

## C. 分支

只纠正真实出现的问题，**不要为了配合脚本去诱导或伪造错误**。

S1 后检查草稿（看回复和草稿文件）：

```sh
grep -rn -E "AI工具铺子|帧跃|流光|幻镜|影工坊|开源 ?X1|居然是它|一分钱不花|扣 ?1" "$WS/成果/4-1" 2>/dev/null
```

（草稿只在对话里、没有文件时，人工看“准备保存的方法”那一段。）

| S1 草稿 | S1b 发的那句 |
| --- | --- |
| 方法里混进了样片内容 | `准备保存的方法里还有原片的内容：<具体项>。这些删掉，只留方法，其余确认。` |
| 都是方法，没有样片内容 | `确认，按这个草稿写入配方。` |

S2 后检查分镜：

```sh
grep -rn -E "完全免费|一分钱不花|零成本|不到一块钱|全网第一|最强|居然是它|一键(生成|出)大片" "$WS/成果/4-1" 2>/dev/null
grep -rn -E "AI工具铺子|帧跃|流光|幻镜|影工坊|开源 ?X1" "$WS/成果/4-1" 2>/dev/null
```

| 检查 | S2b 追问（把 `<>` 换成原文） |
| --- | --- |
| 数字或效果说法在笔记里找不到 | `分镜里“<那句说法>”在我的实测笔记里找不到依据，笔记里写的是 <笔记原文>。改成笔记里能对上的说法，别的不动。` 例：`分镜里“完全免费”在我的实测笔记里找不到依据，笔记里写的是开源但要付 AutoDL 的 GPU 租金，10 秒约 ¥0.3。改成笔记里能对上的说法，别的不动。` |
| 出现样片的工具名、原句或水印 | `分镜里还有原片的 <具体项>，换成我自己的内容，别的不动。` |

- **主线**：S2 任一项出现 → 录 S2b，剪辑用镜头 11–12。
- **分支 B**：分镜的数字都能在笔记里找到、没有样片内容 → 不录 S2b，剪辑用镜头 11B–12B。
- **Agent 打算用图片或视频生成做卡片**：这不是错，是没说清路线。S3 第 2 步那句已经说明本地渲染；它仍坚持要调用生成，照实录，写进 report.md，交给人决定。
- **质检**：S4 质检报告了问题并自己只返工了那一镜 → 剪辑用镜头 19（主线）；质检全过、S5 看片也没发现问题 → 不录 S4b，用镜头 19B；S5 发现质检没拦下的问题 → 录 S4b，用镜头 19（画面换成 S4b）。
- 走了哪条、发了哪句追问、实际花费，在 report.md 写明。

### Hypit 一节为什么不录

讲义 4-1 后半有一节“另一条路：字幕卡片、榜单、知识类用 Hypit”。录屏只用镜头 21 提一句，不录安装和操作，原因：

1. 同一条样片已经用 Capsule Cinema 从拆配方做到交付，再用 Hypit 做一遍，内容重复。
2. Hypit 要现场装 Node.js 22、WhisperX，等待长；本课已接近 9 分钟上限。
3. 4-2 批量和 07 都只用 Capsule Cinema，Hypit 的产物后面的课用不到。

不录屏试跑时仍按讲义把 Hypit 的安装提示词跑一遍，确认能装上，结果写进 `录屏方案/_work/兼容性.md`。
