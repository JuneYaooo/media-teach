# 4-1 换选题，写出我的版本 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `自媒体教程/录屏/4-1-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 4 分 30 秒 – 5 分 30 秒 |
| 前置产物 | `$WS/成果/3-2/` 里的爆款拆解卡、`$WS/成果/2-1/` 里的账号体检报告（文件名以实际为准） |
| 用到的素材 | `资料/账号档案.md`、`资料/爆款样片/AI工具铺子-AI视频工具排行榜.srt`、`资料/爆款样片/AI工具铺子-标题封面.md` |
| 用到的技能 | social-account-doctor（仿写 adapt） |
| 这一段要教会 | ① 爆款复刻学的是结构，不是原句；② 排行榜里每条事实都要有出处，没有就标“待补”；③ 标题不用极限词；④ “开源免费”不等于“完全免费” |

## 预期结果

- `成果/4-1/` 下有脚本、标题封面、对照表（文件名以实际生成为准，下文用 `脚本.md`、`标题封面.md`、`对照表.md` 示意）。
- 脚本五段：钩子 0–2.5 秒、过榜 2.5–15 秒、转折 15–18 秒、揭晓 18–22 秒、互动 22–25 秒，合计 25 秒。
- 设计中预期的错误（来自设计文档第八节）：钩子沿用对标原句“第一名居然是它”；标题出现“全网第一”或“一键生成大片”；第 1 名 MiniMax H3 被写成“完全免费”。

## B. 录制步骤

产物文件名以 Agent 实际生成为准，下文用的是示意名。

### S1 提交仿写任务（原始片段 `4-1-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点“新建任务”，确认输入框下方显示 `阿夏的AI片场`。
3. 点击输入框，粘贴（原样）：

```text
请用 social-account-doctor 的仿写（adapt）流程，照着 3-2 拆好的那条排行榜爆款，给阿夏写一条自己的版本。选题用账号档案里的“2026 AI 视频生成模型排行榜”，也参考 2-1 体检给的建议。
沿用对标的结构和节奏（钩子 → 快速过榜 → 转折 → 揭晓 → 结尾互动），竖屏 25 秒，每段标清秒数；只学结构，不照抄对标的原句、工具名和角色设定。榜单内容只能用阿夏的实测笔记，笔记里没有的写“【待补：阿夏实测】”，不要自己编。
我需要：逐段脚本（口播、画面、屏幕文字），3 个标题和 3 个封面大字，发布文案初稿，再加一张和对标逐段对照的表。放到 成果/4-1。
```

4. 停 3 秒。**标记 M1-1**（提示词完整可见）。
5. 点发送。回复中出现读取 3-2 拆解卡的提示时，**标记 M1-2**。
6. 等待生成完成，出现 `脚本.md` 等文件卡片时 **标记 M1-3**。停 2 秒，结束录制。

### S2 看脚本和对照表（原始片段 `4-1-S2.mp4`）

1. 开始录制。点击 `脚本.md` 文件卡片，右侧预览打开。
2. 停在钩子段 4 秒。**标记 M2-1**。
3. 滚动到过榜段，停在第 5 到第 2 名 5 秒。**标记 M2-2**。
4. 滚动到揭晓段（第 1 名 MiniMax H3），停 4 秒。**标记 M2-3**。
5. 点击 `对照表.md`，停在表格 5 秒。**标记 M2-4**。
6. 结束录制。

### S3 和对标原文对一对（原始片段 `4-1-S3.mp4`）

1. 开始录制。在右侧预览区打开 `资料/爆款样片/AI工具铺子-AI视频工具排行榜.srt`（点“查看所有产物”或从工作区文件列表打开），停在第 1 条字幕 3 秒。**标记 M3-1**。
2. 切到 `脚本.md` 钩子段，停 3 秒。**标记 M3-2**。
3. 点击 `标题封面.md`，停在 3 个标题和 3 个封面大字 5 秒。**标记 M3-3**。
4. 结束录制。

**此时按“C. 分支”判断是否录 S4–S5。**

### S4 发纠正指令（仅主线，原始片段 `4-1-S4.mp4`）

1. 开始录制，回到同一任务。
2. 点击输入框，粘贴（原样）：

```text
请按下面三点修改脚本和标题封面，并在对照表里标出改了哪几句：
1. 钩子“第一名居然是它”是对标原句，换成阿夏自己的说法，可以从“第一名 10 秒只要 3 毛钱”这类她自己的实测数字切入；
2. 标题和封面不要出现“全网第一”“最强”“一键生成大片”这类说法，也不要承诺看完就能做出爆款；
3. 第 1 名不能说成“完全免费”或“一分钱不花”，要说清模型开源免费，但要付 AutoDL 的 GPU 租金，10 秒约 ¥0.3，用完要关机。
改完总长还是 25 秒。
```

3. 停 3 秒。**标记 M4-1**。
4. 点发送，等待完成。**标记 M4-2**（新文件卡片出现）。结束录制。

### S5 看改后结果（仅主线，原始片段 `4-1-S5.mp4`）

1. 开始录制。打开更新后的 `脚本.md`，停在钩子段 4 秒。**标记 M5-1**。
2. 滚动到揭晓段，停 4 秒（应看到 GPU 租金、约 ¥0.3、关机）。**标记 M5-2**。
3. 打开 `标题封面.md`，停 4 秒。**标记 M5-3**。
4. 打开 `对照表.md`，停在“改了哪几句”和总时长 4 秒。**标记 M5-4**。
5. 结束录制。

## C. 分支

S3 结束后在终端检查：

```sh
grep -n "居然是它" $(ls "$WS"/成果/4-1/*.md | grep -v 对照)
grep -n -E "全网第一|最强|一键生成大片|一键出大片|月入" $(ls "$WS"/成果/4-1/*.md | grep -v 对照)
grep -n -E "完全免费|一分钱不花|零成本|不要钱" $(ls "$WS"/成果/4-1/*.md | grep -v 对照)
```

- **主线**（录 S4、S5）：三条命令任意一条有输出。剪辑时只框出实际命中的项，没命中的项旁白里不提。
- **分支 B**（跳过 S4、S5）：三条都没有输出。剪辑表镜头 9–13 换成分支 B 镜头。
- 另查：脚本里出现实测笔记以外的价格或速度数字（如“¥3/条”而笔记没有），照实录下并写进 report.md；不要临时发额外纠正指令。
